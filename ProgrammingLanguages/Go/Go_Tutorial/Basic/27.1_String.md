## 1. String là gì?

**String** trong Go là một **read-only slice of bytes** (mảng byte chỉ đọc).

### 🎯 Đặc điểm

![String Structure](https://zalopay-oss.github.io/go-advanced/images/ch1-string.png)

- ✅ Immutable (không thể thay đổi)
- ✅ UTF-8 encoded
- ✅ Có thể chứa bất kỳ byte nào
- ✅ Hỗ trợ slicing

### 💡 Ví dụ cơ bản

```go
package main

import "fmt"

func main() {
    s := "Hello, World!"
    
    fmt.Printf("String: %s\n", s)
    fmt.Printf("Length: %d\n", len(s))
    fmt.Printf("Type: %T\n", s)
}
```

**Output:**

```
String: Hello, World!
Length: 13
Type: string
```

## 2. Internal Structure của String

### 2.1. StringHeader

String được biểu diễn bởi struct `reflect.StringHeader`:

```go
type StringHeader struct {
    Data uintptr  // Pointer đến underlying byte array
    Len  int      // Chiều dài của string
}
```

**Giải thích:**

- `Data`: Địa chỉ bộ nhớ của byte array
- `Len`: Số bytes trong string

### 2.2. Memory Layout

![String Memory Layout](https://zalopay-oss.github.io/go-advanced/images/ch1-8-string-1.ditaa.png)

**Ví dụ với "Hello World":**

```go
package main

import (
    "fmt"
    "reflect"
    "unsafe"
)

func main() {
    s := "Hello World"
    
    // Lấy StringHeader
    header := (*reflect.StringHeader)(unsafe.Pointer(&s))
    
    fmt.Printf("String: %s\n", s)
    fmt.Printf("Data address: %x\n", header.Data)
    fmt.Printf("Length: %d\n", header.Len)
    
    // Kiểm tra size
    fmt.Printf("Size of string variable: %d bytes\n", unsafe.Sizeof(s))
}
```

**Output:**

```
String: Hello World
Data address: c00008e040
Length: 11
Size of string variable: 16 bytes  (8 bytes pointer + 8 bytes int)
```

### 2.3. Underlying Byte Array

String "Hello World" thực chất là:

```go
var data = [...]byte{
    'H', 'e', 'l', 'l', 'o', ' ', 
    'W', 'o', 'r', 'l', 'd',
}
```

**Diagram:**

```
String variable (16 bytes)
┌──────────────────────────┐
│ Data: 0xc00008e040 (8B) │ ──→ ['H','e','l','l','o',' ','W','o','r','l','d']
│ Len:  11           (8B) │
└──────────────────────────┘
```

## 3. String là Immutable

### 3.1. Immutable nghĩa là gì?

**Immutable** = Không thể thay đổi sau khi tạo.

**Ví dụ: Thử thay đổi string (lỗi)**

```go
package main

func main() {
    s := "Hello"
    
    // ❌ COMPILE ERROR - cannot assign to s[0]
    // s[0] = 'h'
    
    // ✅ Phải tạo string mới
    s = "hello"  // OK - gán string mới
}
```

### 3.2. Tại sao Immutable?

**Lợi ích:**

**1. Thread-safe:**

```go
// Nhiều goroutines đọc cùng string - An toàn
go func() { fmt.Println(s) }()
go func() { fmt.Println(s) }()
```

**2. Memory sharing:**

```go
s1 := "Hello World"
s2 := s1[:5]  // "Hello"

// s1 và s2 share cùng underlying array
// Không tốn thêm bộ nhớ copy
```

**3. String interning:**

```go
s1 := "hello"
s2 := "hello"

// Go có thể dùng chung bộ nhớ cho cùng literal
```

### 3.3. Copy vs Assignment

**Assignment (không copy data):**

```go
package main

import (
    "fmt"
    "reflect"
    "unsafe"
)

func main() {
    s1 := "Hello World"
    s2 := s1  // Chỉ copy StringHeader (16 bytes)
    
    h1 := (*reflect.StringHeader)(unsafe.Pointer(&s1))
    h2 := (*reflect.StringHeader)(unsafe.Pointer(&s2))
    
    fmt.Printf("s1 Data address: %x\n", h1.Data)
    fmt.Printf("s2 Data address: %x\n", h2.Data)
    
    if h1.Data == h2.Data {
        fmt.Println("✅ s1 và s2 share cùng underlying array!")
    }
}
```

**Output:**

```
s1 Data address: c00008e040
s2 Data address: c00008e040
✅ s1 và s2 share cùng underlying array!
```

**Diagram:**

```
s1 ──→ ['H','e','l','l','o',' ','W','o','r','l','d']
       ↑
s2 ────┘  (Share cùng data)
```

## 4. String Slicing

### 4.1. Slicing Syntax

**Cú pháp:**

```go
s[start:end]     // Từ start đến end-1
s[:end]          // Từ đầu đến end-1
s[start:]        // Từ start đến hết
s[:]             // Toàn bộ
```

### 4.2. Ví dụ Slicing

```go
package main

import "fmt"

func main() {
    s := "Hello World"
    
    // Các cách slice
    hello := s[:5]      // "Hello"
    world := s[6:]      // "World"
    lo := s[3:5]        // "lo"
    
    fmt.Printf("Original: %s\n", s)
    fmt.Printf("s[:5]:    %s\n", hello)
    fmt.Printf("s[6:]:    %s\n", world)
    fmt.Printf("s[3:5]:   %s\n", lo)
    
    // Slice trực tiếp
    fmt.Printf("Direct:   %s\n", "Hello World"[:5])
}
```

**Output:**

```
Original: Hello World
s[:5]:    Hello
s[6:]:    World
s[3:5]:   lo
Direct:   Hello
```

### 4.3. Slicing không copy data

```go
package main

import (
    "fmt"
    "reflect"
    "unsafe"
)

func main() {
    s := "Hello World"
    hello := s[:5]
    
    h1 := (*reflect.StringHeader)(unsafe.Pointer(&s))
    h2 := (*reflect.StringHeader)(unsafe.Pointer(&hello))
    
    fmt.Printf("s Data:     %x (len=%d)\n", h1.Data, h1.Len)
    fmt.Printf("hello Data: %x (len=%d)\n", h2.Data, h2.Len)
    
    if h1.Data == h2.Data {
        fmt.Println("✅ Share cùng underlying array!")
    }
}
```

**Output:**

```
s Data:     c00008e040 (len=11)
hello Data: c00008e040 (len=5)
✅ Share cùng underlying array!
```

**Diagram:**

```
s     ──→ ['H','e','l','l','o',' ','W','o','r','l','d']
           ↑                                          ↑
           len=11                                    
           
hello ──→ ['H','e','l','l','o',...]
           ↑                    ↑
           len=5
```

## 5. String và Byte Array

### 5.1. String to []byte

```go
package main

import "fmt"

func main() {
    s := "Hello"
    
    // String → []byte (copy data)
    b := []byte(s)
    
    fmt.Printf("String: %s\n", s)
    fmt.Printf("Bytes:  %v\n", b)
    
    // Sửa byte array
    b[0] = 'h'
    
    fmt.Printf("Modified bytes: %v (%s)\n", b, string(b))
    fmt.Printf("Original string: %s\n", s)  // Không đổi
}
```

**Output:**

```
String: Hello
Bytes:  [72 101 108 108 111]
Modified bytes: [104 101 108 108 111] (hello)
Original string: Hello
```

**⚠️ Lưu ý:** Conversion `[]byte(s)` **copy data**, không share!

### 5.2. []byte to String

```go
package main

import "fmt"

func main() {
    b := []byte{'H', 'e', 'l', 'l', 'o'}
    
    // []byte → String (copy data)
    s := string(b)
    
    fmt.Printf("Bytes:  %v\n", b)
    fmt.Printf("String: %s\n", s)
    
    // Sửa bytes
    b[0] = 'h'
    
    fmt.Printf("Modified bytes: %v\n", b)
    fmt.Printf("String: %s\n", s)  // Không đổi
}
```

**Output:**

```
Bytes:  [72 101 108 108 111]
String: Hello
Modified bytes: [104 101 108 108 111]
String: Hello
```

### 5.3. Unsafe Conversion (zero-copy)

**⚠️ Advanced - Không khuyến nghị dùng thường xuyên**

```go
package main

import (
    "fmt"
    "reflect"
    "unsafe"
)

// Zero-copy: []byte → string (UNSAFE!)
func BytesToString(b []byte) string {
    return *(*string)(unsafe.Pointer(&b))
}

// Zero-copy: string → []byte (UNSAFE!)
func StringToBytes(s string) []byte {
    sh := (*reflect.StringHeader)(unsafe.Pointer(&s))
    bh := reflect.SliceHeader{
        Data: sh.Data,
        Len:  sh.Len,
        Cap:  sh.Len,
    }
    return *(*[]byte)(unsafe.Pointer(&bh))
}

func main() {
    s := "Hello"
    b := StringToBytes(s)
    
    fmt.Printf("String: %s\n", s)
    fmt.Printf("Bytes:  %v\n", b)
    
    // ⚠️ NGUY HIỂM - Vi phạm immutability!
    // b[0] = 'h'  // Có thể crash hoặc undefined behavior
}
```

## 6. String và Rune

### 6.1. Rune là gì?

**Rune** = `int32` = Unicode code point

**Tại sao cần Rune?**

```go
package main

import "fmt"

func main() {
    s := "Hello, 世界"
    
    fmt.Printf("String: %s\n", s)
    fmt.Printf("len(s): %d\n", len(s))  // Số bytes, không phải số ký tự!
    
    // Iterate bytes
    fmt.Println("\nBytes:")
    for i := 0; i < len(s); i++ {
        fmt.Printf("%d: %c (byte: %d)\n", i, s[i], s[i])
    }
    
    // Iterate runes
    fmt.Println("\nRunes:")
    for i, r := range s {
        fmt.Printf("%d: %c (rune: %U)\n", i, r, r)
    }
}
```

**Output:**

```
String: Hello, 世界
len(s): 13  ← 13 bytes, không phải 8 ký tự!

Bytes:
0: H (byte: 72)
1: e (byte: 101)
...
7: � (byte: 228)  ← Sai! Byte giữa của 世
8: � (byte: 184)
...

Runes:
0: H (rune: U+0048)
1: e (rune: U+0065)
...
7: 世 (rune: U+4E16)  ← Đúng!
10: 界 (rune: U+754C)
```

### 6.2. String to []rune

```go
package main

import "fmt"

func main() {
    s := "Hello, 世界"
    
    // String → []rune
    runes := []rune(s)
    
    fmt.Printf("String: %s\n", s)
    fmt.Printf("Bytes count: %d\n", len(s))
    fmt.Printf("Runes count: %d\n", len(runes))
    
    fmt.Println("\nRunes:")
    for i, r := range runes {
        fmt.Printf("%d: %c (U+%04X)\n", i, r, r)
    }
}
```

**Output:**

```
String: Hello, 世界
Bytes count: 13
Runes count: 8

Runes:
0: H (U+0048)
1: e (U+0065)
2: l (U+006C)
3: l (U+006C)
4: o (U+006F)
5: , (U+002C)
6:   (U+0020)
7: 世 (U+4E16)
8: 界 (U+754C)
```

### 6.3. UTF-8 Encoding

```go
package main

import "fmt"

func main() {
    // 1 byte (ASCII)
    s1 := "A"
    fmt.Printf("%s: %d bytes\n", s1, len(s1))
    
    // 2 bytes
    s2 := "ñ"
    fmt.Printf("%s: %d bytes\n", s2, len(s2))
    
    // 3 bytes
    s3 := "世"
    fmt.Printf("%s: %d bytes\n", s3, len(s3))
    
    // 4 bytes
    s4 := "𝕳"
    fmt.Printf("%s: %d bytes\n", s4, len(s4))
}
```

**Output:**

```
A: 1 bytes
ñ: 2 bytes
世: 3 bytes
𝕳: 4 bytes
```

## 7. String Operations

### 7.1. Package strings

```go
package main

import (
    "fmt"
    "strings"
)

func main() {
    s := "Hello, World!"
    
    // Contains
    fmt.Println(strings.Contains(s, "World"))  // true
    
    // Count
    fmt.Println(strings.Count(s, "l"))  // 3
    
    // HasPrefix/HasSuffix
    fmt.Println(strings.HasPrefix(s, "Hello"))  // true
    fmt.Println(strings.HasSuffix(s, "!"))      // true
    
    // Index
    fmt.Println(strings.Index(s, "World"))  // 7
    
    // Replace
    fmt.Println(strings.Replace(s, "World", "Go", 1))  // Hello, Go!
    
    // Split
    fmt.Println(strings.Split(s, ", "))  // [Hello World!]
    
    // ToLower/ToUpper
    fmt.Println(strings.ToLower(s))  // hello, world!
    fmt.Println(strings.ToUpper(s))  // HELLO, WORLD!
    
    // Trim
    fmt.Println(strings.Trim("  hello  ", " "))  // hello
}
```

### 7.2. String Concatenation

**Cách 1: + operator (inefficient)**

```go
s := "Hello"
s = s + " "
s = s + "World"  // Tạo 2 string mới!
```

**Cách 2: strings.Builder (efficient)**

```go
package main

import (
    "fmt"
    "strings"
)

func main() {
    var builder strings.Builder
    
    builder.WriteString("Hello")
    builder.WriteString(" ")
    builder.WriteString("World")
    
    s := builder.String()
    fmt.Println(s)  // Hello World
}
```

**Cách 3: fmt.Sprintf**

```go
s := fmt.Sprintf("%s %s", "Hello", "World")
```

### 7.3. Performance Comparison

```go
package main

import (
    "fmt"
    "strings"
    "time"
)

func concatWithPlus(n int) string {
    s := ""
    for i := 0; i < n; i++ {
        s += "a"
    }
    return s
}

func concatWithBuilder(n int) string {
    var builder strings.Builder
    for i := 0; i < n; i++ {
        builder.WriteString("a")
    }
    return builder.String()
}

func main() {
    n := 10000
    
    // + operator
    start := time.Now()
    concatWithPlus(n)
    fmt.Printf("+ operator: %v\n", time.Since(start))
    
    // strings.Builder
    start = time.Now()
    concatWithBuilder(n)
    fmt.Printf("Builder:    %v\n", time.Since(start))
}
```

**Output:**

```
+ operator: 15.2ms  ← Chậm
Builder:    0.3ms   ← Nhanh gấp 50 lần!
```

## 8. Performance Tips

### 8.1. Tránh String Concatenation trong Loop

**❌ Chậm:**

```go
s := ""
for i := 0; i < 1000; i++ {
    s += "a"  // Tạo 1000 string mới!
}
```

**✅ Nhanh:**

```go
var builder strings.Builder
for i := 0; i < 1000; i++ {
    builder.WriteString("a")
}
s := builder.String()
```

### 8.2. Pre-allocate Builder

```go
var builder strings.Builder
builder.Grow(1000)  // Pre-allocate 1000 bytes

for i := 0; i < 1000; i++ {
    builder.WriteString("a")
}
```

### 8.3. Tránh []byte(string) conversion không cần thiết

**❌ Chậm:**

```go
for _, b := range []byte(s) {  // Convert mỗi lần loop!
    // ...
}
```

**✅ Nhanh:**

```go
bytes := []byte(s)  // Convert 1 lần
for _, b := range bytes {
    // ...
}
```

### 8.4. Use string slicing thay vì substring

**❌ Chậm (nếu dùng library):**

```go
sub := someSubstringFunc(s, 0, 5)  // Có thể allocate
```

**✅ Nhanh:**

```go
sub := s[:5]  // No allocation
```

## 9. Best Practices

### 9.1. String là Immutable

```go
// ✅ Đúng
s := "Hello"
s = s + " World"  // Tạo string mới, OK

// ❌ Sai
// s[0] = 'h'  // Compile error
```

### 9.2. Dùng strings.Builder cho concatenation

```go
// ❌ Chậm
result := ""
for _, word := range words {
    result += word + " "
}

// ✅ Nhanh
var builder strings.Builder
for _, word := range words {
    builder.WriteString(word)
    builder.WriteString(" ")
}
result := builder.String()
```

### 9.3. Range over runes, không phải bytes

```go
s := "Hello, 世界"

// ❌ Sai - iterate bytes
for i := 0; i < len(s); i++ {
    fmt.Printf("%c", s[i])  // Sai với Unicode
}

// ✅ Đúng - iterate runes
for _, r := range s {
    fmt.Printf("%c", r)  // Đúng với Unicode
}
```

### 9.4. Check empty string

```go
// ✅ Nhanh
if len(s) == 0 { }

// ✅ Rõ ràng
if s == "" { }

// ❌ Không cần thiết
if len(strings.TrimSpace(s)) == 0 { }  // Chậm hơn
```

### 9.5. Constant strings

```go
const (
    StatusOK    = "OK"
    StatusError = "ERROR"
)

// Reuse constants
func getStatus() string {
    return StatusOK  // Không tạo string mới
}
```

## 📚 Tổng kết

### String Structure

```go
type StringHeader struct {
```

### Key Points

1. **Immutable**: Không thể thay đổi sau khi tạo
2. **UTF-8**: Encoded theo UTF-8
3. **Slicing**: Không copy data
4. **[]byte conversion**: Copy data
5. **Rune**: int32, Unicode code point

### Performance

```
✅ strings.Builder    - Nhanh nhất cho concatenation
✅ Slicing            - Zero-copy
✅ Range over runes   - Đúng với Unicode

❌ + operator         - Chậm trong loop
❌ []byte conversion  - Copy overhead
❌ Range over bytes   - Sai với Unicode
```

### Best Practices

1. ✅ Dùng `strings.Builder` cho concatenation
2. ✅ Range over runes cho Unicode
3. ✅ Pre-allocate builder khi biết size
4. ✅ Reuse string constants
5. ❌ Tránh + operator trong loop
