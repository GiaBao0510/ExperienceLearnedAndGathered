## 1. Method là gì?

### 1.1. Định nghĩa

**Method** là một function có **receiver** (đối số đặc biệt liên kết với type).

**Go không có class, nhưng có methods!**

### 1.2. Cú pháp

```go
func (receiver ReceiverType) MethodName(params) returnType {
    // Method body
}
```

### 1.3. Ví dụ cơ bản

```go
package main

import (
    "fmt"
    "math"
)

type Vertex struct {
    X, Y float64
}

// Method Abs() với receiver 'v' kiểu Vertex
func (v Vertex) Abs() float64 {
    return math.Sqrt(v.X*v.X + v.Y*v.Y)
}

func main() {
    v := Vertex{3, 4}
    fmt.Println(v.Abs())  // 5
}
```

**Output:**

```
5
```

### 1.4. So sánh với OOP

|Language|Feature|Go Equivalent|
|---|---|---|
|**Java/C++**|Class|Struct + Methods|
|**Java/C++**|Member function|Method|
|**Java/C++**|this/self|Receiver|
|**Java/C++**|Inheritance|Embedding|
|**Java/C++**|Polymorphism|Interfaces|

## 2. Receiver Types

### 2.1. Method trên bất kỳ type nào

**Go cho phép định nghĩa method trên bất kỳ type nào (không chỉ struct).**

```go
package main

import "fmt"

// Custom type
type MyInt int

// Method trên MyInt
func (m MyInt) Double() MyInt {
    return m * 2
}

func (m MyInt) IsEven() bool {
    return m%2 == 0
}

func main() {
    var num MyInt = 5
    
    fmt.Println(num.Double())  // 10
    fmt.Println(num.IsEven())  // false
    
    var num2 MyInt = 6
    fmt.Println(num2.IsEven()) // true
}
```

### 2.2. Quy tắc

**✅ Có thể:**

- Struct type
- Custom type (type alias)
- Pointer type

**❌ Không thể:**

- Built-in types trực tiếp (`int`, `string`)
- Pointer to built-in types
- Interface types

```go
// ❌ COMPILE ERROR - Không thể method trên built-in type
// func (i int) Double() int {
//     return i * 2
// }

// ✅ OK - Tạo custom type
type MyInt int

func (i MyInt) Double() MyInt {
    return i * 2
}
```

## 3. Value Receiver vs Pointer Receiver

### 3.1. Value Receiver

**Value receiver** nhận **bản copy** của value.

```go
package main

import "fmt"

type Counter struct {
    count int
}

// Value receiver - Không modify được gốc
func (c Counter) Increment() {
    c.count++  // Chỉ modify bản copy
    fmt.Println("Inside:", c.count)
}

func main() {
    counter := Counter{count: 0}
    
    counter.Increment()
    fmt.Println("Outside:", counter.count)
}
```

**Output:**

```
Inside: 1
Outside: 0  ← Không thay đổi!
```

### 3.2. Pointer Receiver

**Pointer receiver** nhận **địa chỉ** của value.

```go
package main

import "fmt"

type Counter struct {
    count int
}

// Pointer receiver - Modify được gốc
func (c *Counter) Increment() {
    c.count++  // Modify struct gốc
    fmt.Println("Inside:", c.count)
}

func main() {
    counter := Counter{count: 0}
    
    counter.Increment()
    fmt.Println("Outside:", counter.count)
}
```

**Output:**

```
Inside: 1
Outside: 1  ← Đã thay đổi!
```

### 3.3. Khi nào dùng gì?

**Dùng Pointer Receiver khi:**

- ✅ Method cần **modify** receiver
- ✅ Struct **lớn** (tiết kiệm bộ nhớ)
- ✅ **Consistency** - nếu có 1 method dùng pointer, nên dùng pointer cho tất cả

**Dùng Value Receiver khi:**

- ✅ Method **chỉ đọc** dữ liệu
- ✅ Struct **nhỏ** (int, bool, small structs)
- ✅ Immutable semantics

### 3.4. Ví dụ so sánh

```go
package main

import "fmt"

type Rectangle struct {
    Width  float64
    Height float64
}

// Value receiver - Đọc dữ liệu
func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

// Pointer receiver - Modify dữ liệu
func (r *Rectangle) Scale(factor float64) {
    r.Width *= factor
    r.Height *= factor
}

func main() {
    rect := Rectangle{Width: 10, Height: 5}
    
    fmt.Println("Area:", rect.Area())  // 50
    
    rect.Scale(2)
    
    fmt.Println("Area after scale:", rect.Area())  // 200
}
```

**Output:**

```
Area: 50
Area after scale: 200
```

### 3.5. Go tự động dereference/reference

```go
package main

import "fmt"

type Point struct {
    X, Y int
}

func (p *Point) Move(dx, dy int) {
    p.X += dx
    p.Y += dy
}

func main() {
    p := Point{X: 0, Y: 0}
    
    // Go tự động lấy địa chỉ: p.Move() → (&p).Move()
    p.Move(10, 20)
    
    fmt.Printf("Point: (%d, %d)\n", p.X, p.Y)
    
    // Hoặc dùng pointer trực tiếp
    ptr := &Point{X: 5, Y: 5}
    ptr.Move(3, 7)
    
    fmt.Printf("Point: (%d, %d)\n", ptr.X, ptr.Y)
}
```

**Output:**

```
Point: (10, 20)
Point: (8, 12)
```

## 4. Method vs Function

### 4.1. Method là Function với Receiver

```go
package main

import "fmt"

type Rectangle struct {
    Width, Height float64
}

// Method
func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

// Function tương đương
func Area(r Rectangle) float64 {
    return r.Width * r.Height
}

func main() {
    rect := Rectangle{Width: 10, Height: 5}
    
    // Gọi method
    fmt.Println(rect.Area())  // 50
    
    // Gọi function
    fmt.Println(Area(rect))   // 50
}
```

### 4.2. Method chaining

**Methods cho phép chaining (fluent interface).**

```go
package main

import "fmt"

type Calculator struct {
    value int
}

func (c *Calculator) Add(n int) *Calculator {
    c.value += n
    return c  // Return pointer cho chaining
}

func (c *Calculator) Multiply(n int) *Calculator {
    c.value *= n
    return c
}

func (c *Calculator) GetValue() int {
    return c.value
}

func main() {
    calc := &Calculator{value: 0}
    
    // Method chaining
    result := calc.Add(5).Multiply(3).Add(2).GetValue()
    
    fmt.Println("Result:", result)  // (0 + 5) * 3 + 2 = 17
}
```

**Output:**

```
Result: 17
```

## 5. Method với Embedded Structs

### 5.1. Embedding (Composition)

**Go không có inheritance, nhưng có embedding (composition).**

```go
package main

import "fmt"

type Point struct {
    X, Y float64
}

// Method của Point
func (p Point) Distance() float64 {
    return p.X*p.X + p.Y*p.Y
}

type ColoredPoint struct {
    Point        // Embedded struct
    Color string
}

func main() {
    cp := ColoredPoint{
        Point: Point{X: 3, Y: 4},
        Color: "red",
    }
    
    // Truy cập field của Point
    fmt.Println("X:", cp.X)  // cp.Point.X
    fmt.Println("Y:", cp.Y)  // cp.Point.Y
    
    // Gọi method của Point
    fmt.Println("Distance:", cp.Distance())  // cp.Point.Distance()
    
    // Truy cập field riêng
    fmt.Println("Color:", cp.Color)
}
```

**Output:**

```
X: 3
Y: 4
Distance: 25
Color: red
```

### 5.2. Method Promotion

**Methods của embedded struct được "promoted" lên outer struct.**

```go
package main

import (
    "fmt"
    "sync"
)

type Cache struct {
    m map[string]string
    sync.Mutex  // Embedded
}

func (c *Cache) Get(key string) string {
    c.Lock()           // c.Mutex.Lock()
    defer c.Unlock()   // c.Mutex.Unlock()
    
    return c.m[key]
}

func (c *Cache) Set(key, value string) {
    c.Lock()
    defer c.Unlock()
    
    if c.m == nil {
        c.m = make(map[string]string)
    }
    c.m[key] = value
}

func main() {
    cache := &Cache{}
    
    cache.Set("user", "John")
    fmt.Println(cache.Get("user"))  // John
}
```

### 5.3. Override Methods

**Outer struct có thể "override" method của embedded struct.**

```go
package main

import "fmt"

type Animal struct {
    Name string
}

func (a Animal) Speak() string {
    return "..."
}

type Dog struct {
    Animal  // Embedded
}

// Override method Speak
func (d Dog) Speak() string {
    return "Woof!"
}

type Cat struct {
    Animal  // Embedded
}

// Override method Speak
func (c Cat) Speak() string {
    return "Meow!"
}

func main() {
    dog := Dog{Animal: Animal{Name: "Buddy"}}
    cat := Cat{Animal: Animal{Name: "Whiskers"}}
    
    fmt.Println(dog.Name, "says:", dog.Speak())  // Buddy says: Woof!
    fmt.Println(cat.Name, "says:", cat.Speak())  // Whiskers says: Meow!
    
    // Vẫn truy cập được method gốc
    fmt.Println(dog.Animal.Speak())  // ...
}
```

**Output:**

```
Buddy says: Woof!
Whiskers says: Meow!
...
```

## 6. Method Values và Method Expressions

### 6.1. Method Values

**Method value** là method được bind với một instance cụ thể.

```go
package main

import "fmt"

type Point struct {
    X, Y int
}

func (p *Point) Move(dx, dy int) {
    p.X += dx
    p.Y += dy
}

func main() {
    p := &Point{X: 0, Y: 0}
    
    // Method value - bind với instance p
    moveFunc := p.Move
    
    // Gọi như function (không cần receiver)
    moveFunc(10, 20)
    
    fmt.Printf("Point: (%d, %d)\n", p.X, p.Y)
}
```

**Output:**

```
Point: (10, 20)
```

### 6.2. Method Expressions

**Method expression** là function cần truyền receiver.

```go
package main

import "fmt"

type Point struct {
    X, Y int
}

func (p *Point) Move(dx, dy int) {
    p.X += dx
    p.Y += dy
}

func main() {
    // Method expression - chưa bind
    moveFunc := (*Point).Move
    
    // Phải truyền receiver
    p := &Point{X: 0, Y: 0}
    moveFunc(p, 10, 20)  // Truyền p làm receiver
    
    fmt.Printf("Point: (%d, %d)\n", p.X, p.Y)
}
```

**Output:**

```
Point: (10, 20)
```

### 6.3. Ví dụ thực tế

```go
package main

import (
    "fmt"
    "os"
)

type File struct {
    fd int
}

func OpenFile(name string) (*File, error) {
    fmt.Println("Opening file:", name)
    return &File{fd: 1}, nil
}

func (f *File) Close() error {
    fmt.Println("Closing file")
    return nil
}

func (f *File) Read(offset int64, data []byte) int {
    fmt.Println("Reading file")
    return len(data)
}

func main() {
    var data []byte
    
    // Mở file
    f, _ := OpenFile("foo.dat")
    
    // Method values - bind với instance f
    var Close = f.Close
    var Read = f.Read
    
    // Gọi như function
    Read(0, data)
    Close()
}
```

**Output:**

```
Opening file: foo.dat
Reading file
Closing file
```

## 7. Polymorphism với Interfaces

### 7.1. Vấn đề với Embedding

**Embedding KHÔNG hỗ trợ polymorphism.**

```go
package main

import "fmt"

type Base struct{}

func (b Base) Method() {
    fmt.Println("Base.Method()")
}

type Derived struct {
    Base
}

func CallMethod(b Base) {
    b.Method()
}

func main() {
    d := Derived{}
    
    // Gọi trực tiếp
    d.Method()  // Base.Method() - OK
    
    // Truyền vào function
    CallMethod(d.Base)  // Base.Method() - Cần explicit
}
```

### 7.2. Giải pháp: Interface

**Interface cho phép polymorphism.**

```go
package main

import "fmt"

// Interface
type Speaker interface {
    Speak() string
}

// Implementations
type Dog struct {
    Name string
}

func (d Dog) Speak() string {
    return "Woof!"
}

type Cat struct {
    Name string
}

func (c Cat) Speak() string {
    return "Meow!"
}

// Function nhận interface
func MakeSpeak(s Speaker) {
    fmt.Println(s.Speak())
}

func main() {
    dog := Dog{Name: "Buddy"}
    cat := Cat{Name: "Whiskers"}
    
    // Polymorphism
    MakeSpeak(dog)  // Woof!
    MakeSpeak(cat)  // Meow!
}
```

**Output:**

```
Woof!
Meow!
```

### 7.3. Ví dụ thực tế: Shape

```go
package main

import (
    "fmt"
    "math"
)

// Interface
type Shape interface {
    Area() float64
    Perimeter() float64
}

// Rectangle
type Rectangle struct {
    Width, Height float64
}

func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

func (r Rectangle) Perimeter() float64 {
    return 2 * (r.Width + r.Height)
}

// Circle
type Circle struct {
    Radius float64
}

func (c Circle) Area() float64 {
    return math.Pi * c.Radius * c.Radius
}

func (c Circle) Perimeter() float64 {
    return 2 * math.Pi * c.Radius
}

// Function nhận interface
func PrintShapeInfo(s Shape) {
    fmt.Printf("Area: %.2f\n", s.Area())
    fmt.Printf("Perimeter: %.2f\n", s.Perimeter())
}

func main() {
    rect := Rectangle{Width: 10, Height: 5}
    circle := Circle{Radius: 7}
    
    fmt.Println("Rectangle:")
    PrintShapeInfo(rect)
    
    fmt.Println("\nCircle:")
    PrintShapeInfo(circle)
}
```

**Output:**

```
Rectangle:
Area: 50.00
Perimeter: 30.00

Circle:
Area: 153.94
Perimeter: 43.98
```

## 8. Best Practices

### 8.1. Naming

```go
// ✅ Good - Method names ngắn gọn
func (p *Point) Move(dx, dy int) {}
func (r Rectangle) Area() float64 {}
func (c *Cache) Get(key string) string {}

// ❌ Bad - Redundant
func (p *Point) MovePoint(dx, dy int) {}  // "Point" thừa
func (r Rectangle) CalculateRectangleArea() float64 {}
```

### 8.2. Receiver Naming

```go
// ✅ Good - 1-2 ký tự, lowercase
func (p *Point) Move() {}
func (r Rectangle) Area() {}
func (db *Database) Query() {}

// ❌ Bad
func (this *Point) Move() {}      // Đừng dùng "this"
func (self Rectangle) Area() {}   // Đừng dùng "self"
func (point Point) Move() {}      // Quá dài
```

### 8.3. Pointer vs Value Receiver

```go
// ✅ Good - Consistent
type Counter struct {
    count int
}

func (c *Counter) Increment() { c.count++ }
func (c *Counter) Decrement() { c.count-- }
func (c *Counter) Value() int { return c.count }

// ❌ Bad - Inconsistent
type Counter struct {
    count int
}

func (c *Counter) Increment() { c.count++ }  // Pointer
func (c Counter) Decrement() { c.count-- }   // Value - ❌
func (c *Counter) Value() int { return c.count }
```

### 8.4. Interface Satisfaction

```go
// ✅ Good - Implement interface methods với pointer receiver
type Writer interface {
    Write(p []byte) (n int, err error)
}

type FileWriter struct {
    file *os.File
}

func (fw *FileWriter) Write(p []byte) (n int, err error) {
    return fw.file.Write(p)
}

// Check interface satisfaction
var _ Writer = (*FileWriter)(nil)  // ✅ Compile-time check
```

### 8.5. Method Sets

```go
package main

import "fmt"

type Counter struct {
    count int
}

// Value receiver
func (c Counter) GetValue() int {
    return c.count
}

// Pointer receiver
func (c *Counter) Increment() {
    c.count++
}

func main() {
    // Value
    c := Counter{count: 0}
    c.GetValue()   // ✅ OK
    c.Increment()  // ✅ OK - Go tự động &c
    
    // Pointer
    p := &Counter{count: 0}
    p.GetValue()   // ✅ OK - Go tự động *p
    p.Increment()  // ✅ OK
}
```

**Method Set Rules:**

- Type `T` có methods với receiver `T` và `*T`
- Type `*T` chỉ có methods với receiver `*T`

### Best Practices

1. ✅ Pointer receiver cho modifications
2. ✅ Value receiver cho read-only
3. ✅ Consistent receiver types
4. ✅ Short receiver names (1-2 chars)
5. ✅ Interface cho polymorphism
6. ❌ Không dùng "this" hoặc "self"
7. ❌ Không mix pointer/value receivers
