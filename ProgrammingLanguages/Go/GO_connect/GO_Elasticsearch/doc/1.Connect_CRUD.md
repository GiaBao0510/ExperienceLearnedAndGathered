# Hướng Dẫn Sử Dụng Golang Với Elasticsearch (CRUD Tutorial)

## 📚 Kiến Thức Nền Tảng

### Golang tương tác với Elasticsearch như thế nào?

Elasticsearch (ES) là một search engine hoạt động qua **REST API** — tức là mọi thao tác (tạo, đọc, cập nhật, xóa) đều được thực hiện thông qua các HTTP request (`GET`, `POST`, `PUT`, `DELETE`).

Golang giao tiếp với ES thông qua thư viện chính thức **`go-elasticsearch`**. Thư viện này đóng gói các HTTP call thành các hàm Go tiện lợi, giúp bạn không cần tự viết HTTP request thủ công.

```
Client Golang  →  go-elasticsearch  →  HTTP/REST  →  Elasticsearch
```

|Tệp / Thư mục|Vai trò|Mô tả|
|---|---|---|
|`cmd/main.go`|**Khởi động app**|Gọi config, tạo ES client, đăng ký route, lắng nghe port|

|`internal/repository`|**Data access**|Nhận ES client qua Dependency Injection, chỉ lo CRUD|

### 1. Tầng Config — Đọc Biến Môi Trường

**Tệp:** `internal/config/config.go`

```go
package config

import (
	"fmt"
	"os"

	"github.com/joho/godotenv"
)

// Config chứa toàn bộ cấu hình của ứng dụng,
// được đọc từ file .env thông qua hàm Load()
type Config struct {
	ES_Address       string // Địa chỉ đầy đủ, ví dụ: http://localhost:9200
	ES_Port          string // Port của ES, ví dụ: 9200
	ES_INDEX_PRODUCTS string // Tên index trong ES để lưu products
	APP_Port         string // Port của HTTP server, ví dụ: 8080
}

// Load đọc file .env và trả về struct Config đã được điền đầy đủ.
// Trả về lỗi nếu không tìm thấy hoặc không đọc được file .env.
func Load() (*Config, error) {
	// godotenv.Load() đọc file .env và nạp vào os.Getenv
	if err := godotenv.Load(); err != nil {
		return nil, fmt.Errorf("lỗi, không đọc được .env: %v", err)
	}

	return &Config{
		ES_Address:        os.Getenv("ES_HOST") + ":" + os.Getenv("ES_PORT"),
		ES_Port:           os.Getenv("ES_PORT"),
		ES_INDEX_PRODUCTS: os.Getenv("ES_INDEX_PRODUCTS"),
		APP_Port:          os.Getenv("APP_PORT"),
	}, nil
}
```

### 2. Tầng Model — Định Nghĩa Cấu Trúc Dữ Liệu

**Tệp:** `internal/model/model.go`

> ⚠️ **Lỗi thường gặp:** Package phải là `model`, KHÔNG phải `main`.

```go
package model

// Product đại diện cho một sản phẩm trong hệ thống.
// Các json tag (ví dụ: `json:"name"`) xác định tên field khi chuyển đổi sang JSON.
type Product struct {
	ID          string  `json:"id"`
	Name        string  `json:"name"`
	Description string  `json:"description"` // Lưu ý: phải là "json", không phải "jaon"
	Price       float64 `json:"price"`
	Category    string  `json:"category"`
	InStock     bool    `json:"in_stock"`
}

// SearchResult ánh xạ cấu trúc JSON trả về từ ES khi tìm kiếm.
// ES luôn trả về dạng: { "hits": { "total": {...}, "hits": [...] } }
type SearchResult struct {
	Hits struct {
		Total struct {
			Value int `json:"value"`
		} `json:"total"`
		Hits []struct {
			ID     string  `json:"_id"`
			Source Product `json:"_source"`
		} `json:"hits"` // Quan trọng: cần có json tag "hits" ở đây
	} `json:"hits"`
}

// SearchRequest là cấu trúc dữ liệu nhận từ client khi gọi API tìm kiếm.
// Ví dụ: { "field": "name", "query": "iPhone" }
type SearchRequest struct {
	Query string `json:"query"`
	Field string `json:"field"`
}

// APIResponse là cấu trúc phản hồi chuẩn cho tất cả các API endpoint.
// - Success: true/false cho biết thao tác có thành công không
// - Message: mô tả ngắn gọn kết quả
// - Data: dữ liệu trả về (nếu có), omitempty = bỏ qua nếu nil
type APIResponse struct {
	Success bool        `json:"status"`
	Message string      `json:"message"`
	Data    interface{} `json:"data,omitempty"`
}
```

### 3. Tầng Infrastructure — Khởi Tạo Kết Nối ES

**Tệp:** `internal/infrastructure/elasticsearch/client.go`

```go
package elasticsearch

import (
	"context"
	"fmt"
	"time"

	"github.com/elastic/go-elasticsearch/v8"
)

// NewESClient khởi tạo Elasticsearch client và kiểm tra kết nối bằng ping.
// Tham số address: địa chỉ đầy đủ của ES, ví dụ "http://localhost:9200"
// Trả về *elasticsearch.Client nếu thành công, hoặc error nếu thất bại.
func NewESClient(address string) (*elasticsearch.Client, error) {

	// elasticsearch.Config cho phép cấu hình địa chỉ, retry, timeout, auth,...
	cfg := elasticsearch.Config{
		Addresses: []string{address},
	}

	// elasticsearch.NewClient() tạo client mới nhưng CHƯA thực sự kết nối.
	// Nó chỉ validate config và chuẩn bị HTTP transport.
	client, err := elasticsearch.NewClient(cfg)
	if err != nil {
		return nil, fmt.Errorf("lỗi tạo ES client: %v", err)
	}

	// Tạo context với timeout 5 giây để ping không bị treo vô hạn
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel() // Đảm bảo giải phóng tài nguyên sau khi hàm kết thúc

	// Ping đến ES để kiểm tra kết nối thực sự
	res, err := client.Ping(client.Ping.WithContext(ctx))
	if err != nil {
		return nil, fmt.Errorf("lỗi ping ES: %v", err)
	}
	defer res.Body.Close()

	// res.IsError() trả về true nếu HTTP status code >= 400
	if res.IsError() {
		return nil, fmt.Errorf("ping ES trả về lỗi: %s", res.String())
	}

	fmt.Println("✅ Kết nối Elasticsearch thành công!")
	return client, nil
}
```

### 4. Tầng Repository — Giao Tiếp Với Elasticsearch (CRUD)

> **Dependency Injection là gì?**  
> Thay vì để Repository tự tạo ES client bên trong, ta **truyền client từ bên ngoài vào** (qua constructor). Lợi ích:
> 
> - Dễ test: có thể mock client
> - Tái sử dụng: một client cho nhiều repository
> - Tách biệt rõ ràng: Repository chỉ lo CRUD, không lo việc kết nối

**Tệp:** `internal/repository/product_repo.go`

```go
package repository

import (
	"bytes"
	"context"
	"encoding/json"
	"fmt"

	"github.com/elastic/go-elasticsearch/v8"
	"github.com/elastic/go-elasticsearch/v8/esapi"

	"github.com/your-username/golang-elasticsearch-demo/internal/model"
)

// ProductRepository chứa ES client và tên index để thực hiện CRUD.
type ProductRepository struct {
	client *elasticsearch.Client // Nhận từ bên ngoài, không tự khởi tạo (Dependency Injection)
	index  string                // Tên index ES, ví dụ: "products"
}

// NewProductRepository là constructor, nhận ES client đã được khởi tạo sẵn.
func NewProductRepository(client *elasticsearch.Client, index string) *ProductRepository {
	return &ProductRepository{
		client: client,
		index:  index,
	}
}

// ─────────────────────────────────────────────
// CREATE — Thêm mới một document vào ES
// Tương đương: POST /products/_doc
// ─────────────────────────────────────────────
func (r *ProductRepository) Create(ctx context.Context, product *model.Product) (string, error) {

	// Bước 1: Chuyển struct Product thành JSON bytes
	data, err := json.Marshal(product)
	if err != nil {
		return "", fmt.Errorf("lỗi khi chuyển đổi product thành JSON: %v", err)
	}

	// Bước 2: Gọi ES Index API
	// bytes.NewReader(data) tạo io.Reader từ JSON bytes (ES yêu cầu kiểu io.Reader)
	res, err := r.client.Index(
		r.index,               // Tên index
		bytes.NewReader(data), // Body là JSON của document
	)
	if err != nil {
		return "", fmt.Errorf("lỗi khi gọi ES Index API: %v", err)
	}
	defer res.Body.Close() // Luôn đóng body sau khi dùng xong để tránh rò rỉ bộ nhớ

	// Bước 3: Kiểm tra lỗi HTTP từ ES
	if res.IsError() {
		return "", fmt.Errorf("ES Index API trả về lỗi: %s", res.String())
	}

	// Bước 4: Giải mã response để lấy ID tự động của document vừa tạo
	var result map[string]interface{}
	if err := json.NewDecoder(res.Body).Decode(&result); err != nil {
		return "", fmt.Errorf("lỗi khi phân tích kết quả ES: %v", err)
	}

	// ES trả về field "_id" chứa ID tự sinh của document
	id, _ := result["_id"].(string)
	return id, nil
}

// ─────────────────────────────────────────────
// READ — Tìm kiếm document theo field và giá trị (Match query)
// Tương đương: GET /products/_search với body chứa match query
// ─────────────────────────────────────────────
func (r *ProductRepository) Search(ctx context.Context, field, query string) ([]*model.Product, error) {

	// Bước 1: Xây dựng ES Query DSL dạng match
	// match query cho phép tìm kiếm full-text, có thể gần đúng
	searchBody := map[string]interface{}{
		"query": map[string]interface{}{
			"match": map[string]interface{}{
				field: query, // field: tên field cần tìm, query: giá trị cần tìm
			},
		},
	}

	// Bước 2: Chuyển query thành JSON bytes
	data, err := json.Marshal(searchBody)
	if err != nil {
		return nil, fmt.Errorf("lỗi khi chuyển đổi searchBody thành JSON: %v", err)
	}

	// Bước 3: Gọi ES Search API
	res, err := r.client.Search(
		r.client.Search.WithContext(ctx),
		r.client.Search.WithIndex(r.index),       // Chỉ tìm trong index đã cấu hình
		r.client.Search.WithBody(bytes.NewReader(data)),
		r.client.Search.WithPretty(),              // Tùy chọn: ES trả về JSON dễ đọc hơn (dùng khi debug)
	)
	if err != nil {
		return nil, fmt.Errorf("lỗi khi gọi ES Search API: %v", err)
	}
	defer res.Body.Close()

	if res.IsError() {
		return nil, fmt.Errorf("ES Search API trả về lỗi: %s", res.String())
	}

	// Bước 4: Parse kết quả — ES trả về dạng hits.hits[]
	var result map[string]interface{}
	if err := json.NewDecoder(res.Body).Decode(&result); err != nil {
		return nil, fmt.Errorf("lỗi khi phân tích kết quả ES: %v", err)
	}

	// Trích xuất mảng hits từ response
	hits := result["hits"].(map[string]interface{})["hits"].([]interface{})

	var products []*model.Product
	for _, hit := range hits {
		hitMap := hit.(map[string]interface{})

		// Re-serialize _source (dữ liệu gốc của document) thành JSON bytes
		sourceBytes, _ := json.Marshal(hitMap["_source"])

		// Deserialize JSON bytes thành struct Product
		var product model.Product
		json.Unmarshal(sourceBytes, &product)

		// Gán _id của document vào struct (ES không tự đặt _id vào _source)
		product.ID = hitMap["_id"].(string)
		products = append(products, &product)
	}

	return products, nil
}

// ─────────────────────────────────────────────
// GET ALL — Lấy tất cả document trong index
// Tương đương: GET /products/_search với match_all query
// ─────────────────────────────────────────────
func (r *ProductRepository) GetAll(ctx context.Context) ([]*model.Product, error) {

	// match_all: query lấy tất cả document, không lọc gì cả
	searchBody := map[string]interface{}{
		"query": map[string]interface{}{
			"match_all": map[string]interface{}{},
		},
	}

	data, err := json.Marshal(searchBody)
	if err != nil {
		return nil, fmt.Errorf("lỗi khi chuyển đổi searchBody thành JSON: %v", err)
	}

	res, err := r.client.Search(
		r.client.Search.WithContext(ctx),
		r.client.Search.WithIndex(r.index),
		r.client.Search.WithBody(bytes.NewReader(data)),
		r.client.Search.WithPretty(),
	)
	if err != nil {
		return nil, fmt.Errorf("lỗi khi gọi ES Search API: %v", err)
	}
	defer res.Body.Close()

	if res.IsError() {
		return nil, fmt.Errorf("ES Search API trả về lỗi: %s", res.String())
	}

	// Parse kết quả — tương tự hàm Search ở trên
	var result map[string]interface{}
	if err := json.NewDecoder(res.Body).Decode(&result); err != nil {
		return nil, fmt.Errorf("lỗi khi phân tích kết quả ES: %v", err)
	}

	hits := result["hits"].(map[string]interface{})["hits"].([]interface{})

	var products []*model.Product
	for _, hit := range hits {
		hitMap := hit.(map[string]interface{})
		sourceBytes, _ := json.Marshal(hitMap["_source"])
		var product model.Product
		json.Unmarshal(sourceBytes, &product)
		product.ID = hitMap["_id"].(string)
		products = append(products, &product)
	}

	return products, nil
}

// ─────────────────────────────────────────────
// UPDATE — Cập nhật một phần document theo ID
// Tương đương: POST /products/_update/{id}
// ─────────────────────────────────────────────
func (r *ProductRepository) Update(ctx context.Context, id string, updates map[string]interface{}) error {

	// ES update API yêu cầu body có dạng {"doc": {field: value}}
	// Điều này cho phép cập nhật từng phần (partial update),
	// không cần gửi lại toàn bộ document
	body := map[string]interface{}{"doc": updates}

	data, err := json.Marshal(body)
	if err != nil {
		return fmt.Errorf("lỗi khi chuyển đổi update body thành JSON: %v", err)
	}

	// esapi.UpdateRequest: cấu trúc để gọi ES update API
	req := esapi.UpdateRequest{
		Index:      r.index,
		DocumentID: id,
		Body:       bytes.NewReader(data),
		Refresh:    "true", // "true": ES refresh ngay lập tức sau update (dùng khi cần nhất quán tức thì)
	}

	// req.Do() thực thi request và nhận response từ ES
	res, err := req.Do(ctx, r.client)
	if err != nil {
		return fmt.Errorf("lỗi khi gọi ES Update API: %v", err)
	}
	defer res.Body.Close()

	if res.IsError() {
		return fmt.Errorf("ES Update API trả về lỗi: %s", res.String())
	}

	return nil
}

// ─────────────────────────────────────────────
// DELETE — Xóa document theo ID
// Tương đương: DELETE /products/_doc/{id}
// ─────────────────────────────────────────────
func (r *ProductRepository) Delete(ctx context.Context, id string) error {

	res, err := r.client.Delete(
		r.index,                              // Tên index
		id,                                   // ID của document cần xóa
		r.client.Delete.WithContext(ctx),     // Context để quản lý timeout
	)
	if err != nil {
		return fmt.Errorf("lỗi khi gọi ES Delete API: %v", err)
	}
	defer res.Body.Close()

	if res.IsError() {
		return fmt.Errorf("ES Delete API trả về lỗi: %s", res.String())
	}

	return nil
}
```

### 5. Tầng Handler — Xử Lý HTTP Request

Handler nhận HTTP request từ client, gọi Repository để thao tác với ES, rồi trả về JSON response.

**Tệp:** `internal/handler/product_handler.go`

```go
package handler

import (
	"encoding/json"
	"net/http"
	"strings"

	"github.com/your-username/golang-elasticsearch-demo/internal/model"
	"github.com/your-username/golang-elasticsearch-demo/internal/repository"
)

// ProductHandler chứa reference đến repository để gọi các hàm CRUD
type ProductHandler struct {
	repo *repository.ProductRepository
}

// NewProductHandler là constructor, nhận repository đã được tạo sẵn (Dependency Injection)
func NewProductHandler(repo *repository.ProductRepository) *ProductHandler {
	return &ProductHandler{repo: repo}
}

// responseJSON là hàm tiện ích dùng chung để trả về JSON response.
// Tham số: w = response writer, code = HTTP status code, payload = dữ liệu cần trả về
func responseJSON(w http.ResponseWriter, code int, payload interface{}) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(code)
	json.NewEncoder(w).Encode(payload)
}

// ─────────────────────────────────────────────
// CREATE — HTTP POST /api/products
// ─────────────────────────────────────────────
func (h *ProductHandler) Create(w http.ResponseWriter, r *http.Request) {
	var product model.Product

	// Bước 1: Giải mã JSON body từ request thành struct Product
	if err := json.NewDecoder(r.Body).Decode(&product); err != nil {
		responseJSON(w, http.StatusBadRequest, model.APIResponse{
			Success: false, Message: "Đầu vào không hợp lệ",
		})
		return
	}

	// Bước 2: Gọi repository để tạo mới document trong ES
	id, err := h.repo.Create(r.Context(), &product)
	if err != nil {
		responseJSON(w, http.StatusInternalServerError, model.APIResponse{
			Success: false, Message: "Lỗi khi tạo sản phẩm",
		})
		return
	}

	// Bước 3: Trả về response thành công với ID của document vừa tạo
	responseJSON(w, http.StatusCreated, model.APIResponse{
		Success: true,
		Message: "Sản phẩm đã được tạo",
		Data:    map[string]string{"id": id},
	})
}

// ─────────────────────────────────────────────
// SEARCH — HTTP POST /api/products/search
// ─────────────────────────────────────────────
func (h *ProductHandler) Search(w http.ResponseWriter, r *http.Request) {
	var req model.SearchRequest

	// Giải mã JSON body thành struct SearchRequest
	if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
		responseJSON(w, http.StatusBadRequest, model.APIResponse{
			Success: false, Message: "Đầu vào không hợp lệ",
		})
		return
	}

	products, err := h.repo.Search(r.Context(), req.Field, req.Query)
	if err != nil {
		responseJSON(w, http.StatusInternalServerError, model.APIResponse{
			Success: false, Message: "Lỗi khi tìm kiếm sản phẩm",
		})
		return
	}

	responseJSON(w, http.StatusOK, model.APIResponse{
		Success: true,
		Message: "Tìm kiếm thành công",
		Data:    products,
	})
}

// ─────────────────────────────────────────────
// GET ALL — HTTP GET /api/products/get-all
// ─────────────────────────────────────────────
func (h *ProductHandler) GetAll(w http.ResponseWriter, r *http.Request) {
	products, err := h.repo.GetAll(r.Context())
	if err != nil {
		responseJSON(w, http.StatusInternalServerError, model.APIResponse{
			Success: false, Message: "Lỗi khi lấy danh sách sản phẩm",
		})
		return
	}

	responseJSON(w, http.StatusOK, model.APIResponse{
		Success: true,
		Message: "Lấy sản phẩm thành công",
		Data:    products,
	})
}

// ─────────────────────────────────────────────
// UPDATE — HTTP PUT /api/products/{id}
// ─────────────────────────────────────────────
func (h *ProductHandler) Update(w http.ResponseWriter, r *http.Request) {
	// Trích xuất ID từ URL path, ví dụ: /api/products/abc123 → "abc123"
	id := strings.TrimPrefix(r.URL.Path, "/api/products/")
	if id == "" {
		responseJSON(w, http.StatusBadRequest, model.APIResponse{
			Success: false, Message: "ID sản phẩm không được để trống",
		})
		return
	}

	// Cho phép partial update: client chỉ cần gửi các field cần cập nhật
	var update map[string]interface{}
	if err := json.NewDecoder(r.Body).Decode(&update); err != nil {
		responseJSON(w, http.StatusBadRequest, model.APIResponse{
			Success: false, Message: "Đầu vào không hợp lệ",
		})
		return
	}

	if err := h.repo.Update(r.Context(), id, update); err != nil {
		responseJSON(w, http.StatusInternalServerError, model.APIResponse{
			Success: false,
			Message: "Lỗi khi cập nhật sản phẩm",
			Data:    err.Error(),
		})
		return
	}

	responseJSON(w, http.StatusOK, model.APIResponse{
		Success: true,
		Message: "Sản phẩm đã được cập nhật",
	})
}

// ─────────────────────────────────────────────
// DELETE — HTTP DELETE /api/products/{id}
// ─────────────────────────────────────────────
func (h *ProductHandler) Delete(w http.ResponseWriter, r *http.Request) {
	// Trích xuất ID từ URL path
	id := strings.TrimPrefix(r.URL.Path, "/api/products/")
	if id == "" {
		responseJSON(w, http.StatusBadRequest, model.APIResponse{
			Success: false, Message: "ID sản phẩm không được để trống",
		})
		return
	}

	if err := h.repo.Delete(r.Context(), id); err != nil {
		responseJSON(w, http.StatusInternalServerError, model.APIResponse{
			Success: false,
			Message: "Lỗi khi xóa sản phẩm",
		})
		return
	}

	responseJSON(w, http.StatusOK, model.APIResponse{
		Success: true,
		Message: "Sản phẩm đã được xóa",
	})
}
```

### 6. Entry Point — `cmd/main.go`

`main.go` là điểm khởi đầu của toàn bộ ứng dụng: nạp config → khởi tạo ES client → khởi tạo các tầng → đăng ký route → bật server.

**Tệp:** `cmd/main.go`

```go
package main

import (
	"fmt"
	"log"
	"net/http"

	"github.com/your-username/golang-elasticsearch-demo/internal/config"
	"github.com/your-username/golang-elasticsearch-demo/internal/handler"
	"github.com/your-username/golang-elasticsearch-demo/internal/infrastructure/elasticsearch"
	"github.com/your-username/golang-elasticsearch-demo/internal/repository"
)

func main() {

	// Bước 1: Đọc cấu hình từ file .env
	cfg, err := config.Load()
	if err != nil {
		log.Fatalf("Lỗi khi đọc cấu hình: %v", err)
	}
	log.Printf("Cấu hình đã được tải: ES=%s, APP_PORT=%s", cfg.ES_Address, cfg.APP_Port)

	// Bước 2: Khởi tạo Elasticsearch client và kiểm tra kết nối
	esClient, err := elasticsearch.NewESClient(cfg.ES_Address)
	if err != nil {
		log.Fatalf("Không thể kết nối Elasticsearch: %v", err)
	}

	// Bước 3: Khởi tạo Repository — inject ES client vào
	repo := repository.NewProductRepository(esClient, cfg.ES_INDEX_PRODUCTS)

	// Bước 4: Khởi tạo Handler — inject Repository vào
	productHandler := handler.NewProductHandler(repo)

	// Bước 5: Đăng ký các route HTTP
	mux := http.NewServeMux()

	// POST /api/products — Tạo mới sản phẩm
	mux.HandleFunc("/api/products", func(w http.ResponseWriter, r *http.Request) {
		if r.Method == http.MethodPost {
			productHandler.Create(w, r)
		} else {
			http.Error(w, "Phương thức không được hỗ trợ", http.StatusMethodNotAllowed)
		}
	})

	// POST /api/products/search — Tìm kiếm sản phẩm
	mux.HandleFunc("/api/products/search", func(w http.ResponseWriter, r *http.Request) {
		if r.Method == http.MethodPost {
			productHandler.Search(w, r)
		} else {
			http.Error(w, "Phương thức không được hỗ trợ", http.StatusMethodNotAllowed)
		}
	})

	// GET /api/products/get-all — Lấy tất cả sản phẩm
	mux.HandleFunc("/api/products/get-all", func(w http.ResponseWriter, r *http.Request) {
		if r.Method == http.MethodGet {
			productHandler.GetAll(w, r)
		} else {
			http.Error(w, "Phương thức không được hỗ trợ", http.StatusMethodNotAllowed)
		}
	})

	// PUT /api/products/{id}   — Cập nhật sản phẩm theo ID
	// DELETE /api/products/{id} — Xóa sản phẩm theo ID
	// Dùng prefix /api/products/ (có dấu /) để bắt cả /api/products/{id}
	mux.HandleFunc("/api/products/", func(w http.ResponseWriter, r *http.Request) {
		switch r.Method {
		case http.MethodPut:
			productHandler.Update(w, r)
		case http.MethodDelete:
			productHandler.Delete(w, r)
		default:
			http.Error(w, "Phương thức không được hỗ trợ", http.StatusMethodNotAllowed)
		}
	})

	// Bước 6: Chạy HTTP server
	addr := fmt.Sprintf(":%s", cfg.APP_Port)
	log.Printf("🚀 Server đang chạy tại http://localhost%s", addr)
	if err := http.ListenAndServe(addr, mux); err != nil {
		log.Fatalf("Lỗi khi chạy server: %v", err)
	}
}
```
