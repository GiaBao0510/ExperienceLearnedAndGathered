
### **Cách bật CORS trong ASP.NET Core**

Đầu tiên chúng ta sẽ tải và dùng gói:
```bash
dotnet add package Microsoft.AspNetCore.Cors
```

Sau đó thêm các dịch vụ CORS vào phương thức ConfigureServices 
public void ConfigureServices(IServiceCollection services):

```csharp
{
	services.AddCors(options => {
		options.AddPolicy("AllowAll", builder => 
			.AllowAnyOrigins()
			.AllowAnyMethod()
			.AllowAnyHeader()
		)
	});
}
```

Áp dụng chính sách vào phương thức Configure
```csharp
public void Configure(IApplication app){
	app.UseCors("AllowAll");
}
```

##### **Hiểu về NET CORE Allow CORS Methods:**
Bây giờ chúng ta sẽ xem cách áp dụng các phương thức CORS này vào trong ứng dụng ASP.NET Core của mình:
```csharp
//NET Core cho pháp các phương thức CORS trong nháy mắt

//Cho phép yêu cầu từ bất kỳ nguồn nào
app.UseCors(builder => builder.AllowAnyOrigin());

//Cho phép yêu cầu từ một nguồn cụ thể
app.UseCors(builder => builder.WithOrigins("http://domain.com"));

//Cho phép bất kỳ tiêu đề nào trong yêu cầu
app.UseCors(builder => builder.AllowAnyHeader());

//Cho phép bất kỳ phương thức HTTP nào trong request
app.UseCors(builder => builder.AllowAnyMethod());
```


##### **Một ví dụ thực tế về CORS ASP.NET CORE**
CORS và ASP.NET CORE luôn đi sát cánh cùng nhau. Thông qua ví dụ để dễ hiểu
```csharp
//Cấu hình dịch vụ trong phương thức ConfigureSerrvice
public void ConfigureService(IServiceCollection service){
	services.AddCors(options => {
		options.AddPolicy("AllowSpecifiOrigin", builder => 
			.WithOrigins(
				"http://example.com", 
				"http://example2.com"
			)
			.AllowAnyMethod()
			.AllowAnyHeader()
		)
	});
}
```
- Bây giờ chúng ta đã thiết lập chính sách CORS "AllowSpecifiOrigin" là chỉ cho phép các tên miền cụ thể

##### **ASP.NET Core CORS AllowAll: Có nghĩa là gì?**

Đôi khi bạn muốn chấp nhận các yêu cầu từ tất cả các nguồn. Hãy xem cách biểu diễn

```csharp
public void ConfigureService(IServiceCollection service){
	services.AddCors(options => {
		options.AddPolicy("AllowEverything", builder => 
			.AllowAnyOrigins()
			.AllowAnyMethod()
			.AllowAnyHeader()
		)
	});
}
```
- Cách này không được khuyến nghị
