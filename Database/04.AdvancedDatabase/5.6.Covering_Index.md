# **Covering Index**

Covering index là cách nhanh nhất để chọn dữ liệu từ một bảng. Covering index là Index chứa tất cả các cột được yêu cầu trong một truy vấn, database engine sẽ lấy dữ liệu trực tiếp từ Index mà không cần truy cập bảng. Điều này giúp giảm I/O và tăng hiệu suất

Dưới đây là các điểm trọng tâm về Covering Index:
- Cơ chế hoạt động: Thay vì phải duyệt qua index để tìm vị trí rồi quay lại bảng gốc (table scan / key lookup) để lấy thêm dữ liệu, database engine chỉ cần đọc kết quả trực tiếp từ cây index (Index-only scan).
- Lợi ích: Tăng tốc độ truy vấn đáng kể, giảm chi phí đọc/ghi ổ cứng (I/O) và phù hợp lý tưởng cho các hệ thống báo cáo đọc nhiều.
- Hạn chế: Tốn dung lượng ổ cứng để lưu trữ và làm chậm các thao tác ghi (INSERT, UPDATE, DELETE) vì database phải cập nhật cả index.
  
Cách triển khai phổ biến:
- MySQL / PostgreSQL: Tạo Composite Index (index trên nhiều cột) bao gồm cả cột điều kiện và cột cần select.
- SQL Server: Sử dụng mệnh đề INCLUDE để thêm các cột cần trả về vào phần non-key của index, giúp index không bị quá cồng kềnh

Trong PostgreSQL, dùng mệnh đề INCLUDE để thêm cột vào index mà không dùng để sắp xếp/tìm kiếm, chỉ để "đính kèm" cho đủ dữ liệu trả về:
```sql
-- Query thường dùng: lọc theo category_id, chỉ cần lấy name và price
create index idx_products_covering
on products(category_id) include(name, price);

select name, price from products where category_id = 5;
- Kết quả: "Index Only Scan using idx_products_covering" — không cần đọc bảng chính (Heap)
```

#### **So sánh Index Scan thường vs Index-Only Scan:**

- **Index Scan:** DB tìm vị trí dòng trong index, rồi phải quay lại bảng chính (Heap) để lấy các cột không có trong index → 2 bước I/O.
- **Index-Only Scan:** mọi cột cần thiết đã có sẵn trong index → chỉ 1 bước I/O, nhanh hơn.

> Lưu ý: Postgres vẫn có thể phải kiểm tra "visibility" (dòng có còn hợp lệ không do MVCC) qua bảng visibility map — nếu bảng có nhiều dòng vừa update/delete gần đây, Index-Only Scan có thể vẫn phải chạm bảng chính. Chạy VACUUM định kỳ giúp tối ưu việc này.
