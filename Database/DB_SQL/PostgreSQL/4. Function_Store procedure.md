# Function và Stored Procedure Trong PostgreSQL

Tài liệu này giới thiệu **Function** và **Stored Procedure** trong PostgreSQL, hai công cụ mạnh mẽ giúp tự động hóa và xử lý logic phức tạp trong cơ sở dữ liệu.

## **1. Function**

### **Mô tả**

- **Function** (hàm) là một tập hợp các câu lệnh SQL hoặc PL/pgSQL, được sử dụng để thực hiện các tác vụ cụ thể như xử lý dữ liệu, tính toán, hoặc trả về kết quả.

- **Đặc điểm**:
    - Yêu cầu định nghĩa kiểu dữ liệu trả về (dùng từ khóa `RETURNS`).
    - Có thể nhận tham số đầu vào (`IN`), trả về kết quả (`OUT`), hoặc cả hai (`INOUT`).
    - Có thể trả về giá trị đơn (như `INTEGER`, `TEXT`) hoặc tập hợp (như `TABLE`, `SETOF`).

- **Ứng dụng**:
    - Tính toán (ví dụ: tính tổng lương).
    - Xử lý logic phức tạp (ví dụ: kiểm tra và cập nhật dữ liệu).
    - Trả về dữ liệu dạng bảng để sử dụng trong truy vấn.

### **Cú pháp**

```sql
CREATE FUNCTION function_name(parameter1 datatype, parameter2 datatype, ...)
RETURNS datatype AS $$
BEGIN
    -- Các câu lệnh SQL/PL/pgSQL
END;
$$ LANGUAGE plpgsql;
```

### **Ví dụ 1: Hàm xóa người dùng**

Xóa một người dùng dựa trên `uid`:
```sql
CREATE FUNCTION delete_user(user_id INT)
RETURNS VOID AS $$
BEGIN
    DELETE FROM users WHERE uid = user_id;
END;
$$ LANGUAGE plpgsql;
```

Gọi hàm:
```sql
CALL delete_user(5);
```

### **Ví dụ 2: Hàm trả về tổng số tiền đơn hàng**

Tính tổng số tiền đơn hàng của một người dùng:
```sql
CREATE FUNCTION get_total_order_amount(user_id INT)
RETURNS DECIMAL(10,2) AS $$
BEGIN
    RETURN (
        SELECT SUM(amount)
        FROM orders
        WHERE uid = user_id
    );
END;
$$ LANGUAGE plpgsql;
```

Gọi hàm:
```sql
SELECT get_total_order_amount(1); -- Trả về 350.80 cho người dùng có uid=1
```

### **Ví dụ 3: Hàm trả về bảng**

Trả về danh sách đơn hàng của một người dùng dưới dạng bảng:
```sql
CREATE FUNCTION get_user_orders(user_id INT)
RETURNS TABLE (username VARCHAR, order_date DATE, amount DECIMAL(10,2)) AS $$
BEGIN
    RETURN QUERY
    SELECT u.username, o.order_date, o.amount
    FROM users u
    INNER JOIN orders o ON u.uid = o.uid
    WHERE o.uid = user_id;
END;
$$ LANGUAGE plpgsql;
```

Gọi hàm:
```sql
SELECT * FROM get_user_orders(1);
```

- **Kết quả**:

|username|order_date|amount|
|---|---|---|
|Gia Bao|2025-07-07|100.30|
|Gia Bao|2025-07-07|250.50|

## **2. Stored Procedure**

### **Mô tả**

- **Stored Procedure** (thủ tục lưu trữ) là một tập hợp các câu lệnh SQL hoặc PL/pgSQL, được lưu trữ trong cơ sở dữ liệu để thực thi các tác vụ mà không cần trả về giá trị.

- **Đặc điểm**:
    - Không yêu cầu kiểu dữ liệu trả về (khác với **Function**).
    - Hỗ trợ xử lý giao dịch (transaction) như `COMMIT` hoặc `ROLLBACK`.
    - Thường dùng cho các tác vụ phức tạp như cập nhật nhiều bảng hoặc thực hiện logic điều khiển.

- **Ứng dụng**:
    - Thực hiện các tác vụ quản trị (như xóa dữ liệu cũ).
    - Tự động hóa các quy trình (như cập nhật trạng thái đơn hàng).

### **Cú pháp**

```sql
CREATE PROCEDURE procedure_name(parameter1 datatype, parameter2 datatype, ...)
LANGUAGE plpgsql AS $$
BEGIN
    -- Các câu lệnh SQL/PL/pgSQL
END;
$$;
```

### **Ví dụ 1: Procedure nối dữ liệu**

Lưu kết quả nối dữ liệu từ `users` và `orders` vào một bảng tạm:
```sql
CREATE PROCEDURE join_users_orders()
LANGUAGE plpgsql AS $$
BEGIN
    CREATE TEMP TABLE temp_user_orders AS
    SELECT u.username, o.order_date, o.amount 
    FROM users u
    INNER JOIN orders o ON u.uid = o.uid;
END;
$$;
```

Gọi procedure:
```sql
CALL join_users_orders();
SELECT * FROM temp_user_orders;
```

- **Kết quả**:

|username|order_date|amount|
|---|---|---|
|Gia Bao|2025-07-07|100.30|
|Gia Bao|2025-07-07|250.50|
|Nguyen Van A|2025-07-07|25.50|
|Nguyen Van B|2025-07-07|18.90|

### **Ví dụ 2: Procedure cập nhật trạng thái**

Cập nhật trạng thái đơn hàng và ghi log:
```sql
CREATE PROCEDURE update_order_status(order_id INT, new_status VARCHAR)
LANGUAGE plpgsql AS $$
BEGIN
    UPDATE orders 
    SET amount = amount * 1.1 -- Tăng giá 10%
    WHERE order_id = order_id;
    
    INSERT INTO order_log (order_id, status, updated_at)
    VALUES (order_id, new_status, CURRENT_TIMESTAMP);
    
    COMMIT;
EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK;
        RAISE NOTICE 'Error updating order: %', SQLERRM;
END;
$$;
```

Gọi procedure (giả sử có bảng `order_log`):
```sql
CALL update_order_status(1, 'Completed');
```

## **3. So Sánh Function và Stored Procedure**

| **Tiêu chí**        | **Function**                                | **Stored Procedure**                           |
| ------------------- | ------------------------------------------- | ---------------------------------------------- |
| **Trả về giá trị**  | Bắt buộc (`RETURNS` định nghĩa kiểu trả về) | Không bắt buộc, thường không trả về giá trị    |
| **Gọi**             | `SELECT` hoặc `CALL`                        | `CALL`                                         |
| **Xử lý giao dịch** | Không hỗ trợ `COMMIT`/`ROLLBACK`            | Hỗ trợ `COMMIT`/`ROLLBACK`                     |
| **Ứng dụng**        | Tính toán, trả về dữ liệu                   | Thực hiện tác vụ quản trị, cập nhật nhiều bảng |
| **Ví dụ**           | Tính tổng, trả về bảng                      | Cập nhật dữ liệu, ghi log                      |

## **4. Lưu Ý Khi Sử Dụng**

- **Function**:
    - Đặt tên hàm rõ ràng, phản ánh chức năng (ví dụ: `get_total_order_amount`).
    - Sử dụng `RETURN QUERY` cho hàm trả về bảng để tối ưu hiệu suất.
    - Tránh lạm dụng hàm cho các tác vụ phức tạp liên quan đến giao dịch.

- **Stored Procedure**:
    - Dùng procedure khi cần thực hiện nhiều lệnh SQL hoặc quản lý giao dịch.
    - Thêm xử lý lỗi (`EXCEPTION`) để tăng độ tin cậy.
    - Procedure phù hợp cho các tác vụ không cần trả về dữ liệu trực tiếp.

- **Hiệu suất**:
    - Tạo chỉ mục (index) trên các cột dùng trong hàm/procedure để tăng tốc độ.
    - Tránh lồng quá nhiều truy vấn phức tạp trong hàm.

- **Bảo trì**:
    - Ghi chú rõ ràng trong mã để dễ hiểu và bảo trì.
    - Kiểm tra quyền truy cập (`GRANT`) để đảm bảo chỉ người dùng được phép gọi hàm/procedure.
