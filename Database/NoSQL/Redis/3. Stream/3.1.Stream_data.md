**Redis Stream** là một cấu trúc dữ liệu vô cùng mạnh mẽ trong việc quản lý các luồng dữ liệu tốc độ cao. Với khả năng phân vùng độc lập, nhân bản và ổn định cao. Stream trong ==Redis có thể bắt xử lý hàng triệu điểm dữ liệu trong mỗi giây, với độ trễ chỉ tính bằng đơn vị mili giây.== Cấu trúc dữ liệu này được dựa trên triển khai redix-tree, do đó cho phép người dùng truy vấn tra cứu với tốc độ rất cao.

**Redis Stream** là một cấu trúc dữ liệu append-only (chỉ ghi thêm), lưu trữ các mục theo thứ tự thời gian.

Nó phù hợp cho:
- Ghi log, hành vi người dùng.
- Hệ thống chat real-time.
- Hàng đợi tin nhắn, giao tiếp giữa microservice.
- Tích hợp với SignalR + lưu trữ tạm thời (buffer).

**Một số đặc điểm nổi bậc của redis stream gồm:**

- *Truy cập ngẫu nhiên trong thời gian O(1):* Điều này giúp truy xuất dữ liệu một cách nhanh chóng.
- *Chiến lược tiêu thụ phức tạp:* Hỗ trợ các nhóm người tiêu dùng (consumer groups), cho phép nhiều người tiêu dùng đọc từ cùng một stream mà không bị trùng lặp dữ liệu.
- *Ghi nhận và phát sự kiện theo thời gian thực:* Streams có thể được sử dụng để ghi nhận các sự kiện như hành động của người dùng, dữ liệu từ cảm biến, thông báo,...

**Một số lệnh cơ bản của Redis Streams gồm:**

- **XADD:** 
	- Thêm một mục mới vào stream. Lệnh `XADD` sẽ tự động tạo một ID duy nhất cho bạn nếu đối số ID được chỉ định là ký tự `*` (Ký tự dấu hoa thị trong ASCII).
	- Cấu trúc lưu trữ:
```
XADD [Key name] * field1 value1 [field2 value2 field3 value3 ...]
```

*Ví dụ:*
```powershell
127.0.0.1:6379> xadd chatapp * senderID 125 receiver 145 message "Khoe khong"
"1750859313580-0"
127.0.0.1:6379> xadd chatapp * senderID 145 receiver 125 message "Khoe lam, dao nay lam gi"
"1750859337510-0"
127.0.0.1:6379> xadd chatapp * senderID 125 receiver 145 message "Dao nay chay grap may oi"
"1750859359855-0"
```

### ✅  **Tổng hợp các lệnh Redis Stream thông dụng**

| Lệnh         | Mô tả                                     |
| ------------ | ----------------------------------------- |
| `XADD`       | Thêm entry mới vào stream                 |
| `XRANGE`     | Đọc một phạm vi entry theo ID tăng dần    |
| `XREVRANGE`  | Đọc một phạm vi entry theo ID giảm dần    |
| `XREAD`      | Đọc entry theo dòng, hỗ trợ streaming     |
| `XLEN`       | Đếm số entry trong stream                 |
| `XDEL`       | Xóa một hoặc nhiều entry theo ID          |
| `XTRIM`      | Cắt bớt stream để giới hạn số lượng entry |
| `XGROUP`     | Tạo consumer group                        |
| `XREADGROUP` | Đọc từ stream theo group                  |
| `XACK`       | Đánh dấu entry là đã xử lý bởi consumer   |
