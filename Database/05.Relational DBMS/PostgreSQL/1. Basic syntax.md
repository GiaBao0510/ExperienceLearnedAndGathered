# Các Câu Lệnh Cơ Bản Trong PostgreSQL

Tài liệu này giới thiệu các câu lệnh SQL cơ bản trong PostgreSQL để tạo, quản lý và truy vấn dữ liệu. Các lệnh này là nền tảng cho việc làm việc với cơ sở dữ liệu quan hệ.

## **1. Tạo và Xóa Cơ Sở Dữ Liệu**

### **Tạo Database**

Tạo một cơ sở dữ liệu mới:
```sql
CREATE DATABASE ten_database;
```

### **Xóa Database**

Xóa một cơ sở dữ liệu (cần cẩn thận vì sẽ xóa toàn bộ dữ liệu):
```sql
DROP DATABASE ten_database;
```

---
## **2. Tạo và Quản Lý Bảng**

### **Tạo Bảng**

Ví dụ tạo bảng `users` (lưu thông tin người dùng) và bảng `orders` (lưu thông tin đơn hàng) với mối quan hệ khóa ngoại:
```sql
CREATE TABLE users (
    uid SERIAL PRIMARY KEY NOT NULL,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    create_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    age INT CHECK (age >= 16)
);

CREATE TABLE orders (
    order_id SERIAL PRIMARY KEY,
    uid INT NOT NULL,
    order_date DATE NOT NULL,
    amount DECIMAL(10,2) CHECK (amount > 0),
    CONSTRAINT fk_user_order FOREIGN KEY (uid) REFERENCES users(uid)
        ON DELETE CASCADE
        ON UPDATE CASCADE
);
```

- **Giải thích**:
    - `SERIAL`: Tự động tăng giá trị cho khóa chính.
    - `UNIQUE`: Đảm bảo email không trùng lặp.
    - `CHECK`: Ràng buộc tuổi ≥ 16 và số tiền > 0.
    - `FOREIGN KEY`: Liên kết `uid` trong `orders` với `uid` trong `users`.

### **Sửa Bảng**

Thêm hoặc sửa cấu trúc bảng bằng `ALTER TABLE`. Ví dụ thêm cột `phone` vào bảng `users`:
```sql
ALTER TABLE users ADD COLUMN phone VARCHAR(15);
```

### **Xóa Bảng**

Xóa bảng và toàn bộ dữ liệu:
```sql
DROP TABLE orders;
```

## **3. Thêm, Sửa, Xóa Dữ Liệu**

### **Thêm Dữ Liệu (INSERT)**

Thêm một dòng vào bảng `users`:
```sql
INSERT INTO users (username, email, age) 
VALUES ('Gia Bao', 'giabao2025@gmail.com', 23);
```

Thêm nhiều dòng:
```sql
INSERT INTO users (username, email, age) VALUES
    ('Nguyen Van A', 'nguyenvana@gmail.com', 24),
    ('Nguyen Van B', 'nguyenvanb@gmail.com', 25),
    ('Nguyen Van C', 'nguyenvanc@gmail.com', 26),
    ('Nguyen Van D', 'nguyenvand@gmail.com', 27);
```

Thêm dữ liệu vào bảng `orders`:
```sql
INSERT INTO orders (uid, order_date, amount) VALUES
    (1, '2025-07-07', 100.30),
    (1, '2025-07-07', 19.80),
    (2, '2025-07-07', 25.50),
    (3, '2025-07-07', 18.90);
```

### **Sửa Dữ Liệu (UPDATE)**

Cập nhật số tiền của đơn hàng có `order_id = 2`:
```sql
UPDATE orders 
SET amount = 250.50 
WHERE order_id = 2;
```

### **Xóa Dữ Liệu (DELETE)**

Xóa đơn hàng có `order_id = 5`:
```sql
DELETE FROM orders 
WHERE order_id = 5;
```

## **4. Truy Vấn Dữ Liệu (SELECT)**

### **Truy Vấn Cơ Bản**

Lấy toàn bộ dữ liệu từ bảng `users`:
```sql
SELECT * FROM users;
```

Lấy một số cột cụ thể:
```sql
SELECT uid, username FROM users;
```

### **Truy Vấn Với Điều Kiện**

Sử dụng `WHERE` để lọc dữ liệu:

- Lấy người dùng dưới 25 tuổi:
```sql
SELECT * FROM users WHERE age < 25;
```

- Lấy đơn hàng có số tiền từ 10 đến 180:
```sql
SELECT * FROM orders WHERE amount BETWEEN 10 AND 180;
```

- Lấy đơn hàng của người dùng có `uid` là 1, 3, hoặc 5:
```sql
SELECT * FROM orders WHERE uid IN (1, 3, 5);
```

- Tìm người dùng có tên chứa "Bao":
```sql
SELECT * FROM users WHERE username LIKE '%Bao%';
```

### **Sắp Xếp Dữ Liệu (ORDER BY)**

Sắp xếp theo tuổi tăng dần:
```sql
SELECT * FROM users ORDER BY age;
```

Sắp xếp theo tuổi giảm dần:
```sql
SELECT * FROM users ORDER BY age DESC;
```

### **Giới Hạn Dữ Liệu (LIMIT)**

Lấy 3 dòng đầu tiên từ bảng `users`:
```sql
SELECT * FROM users LIMIT 3;
```

Kết hợp `ORDER BY` và `LIMIT`:
```sql
SELECT * FROM users ORDER BY age DESC LIMIT 2;
```
