## **Redis là gì?**

> **Redis (Remote Dictionary Server)** là một hệ quản trị cơ sở dữ liệu **NoSQL (Not Only SQL)**. Cụ thể thì dữ liệu sẽ được lưu dưới dạng key-value.

- Redis có thể đảm nhận nhiều vai trò khác nhau trong hệ thống:
	- Có thể được sử dụng như Database.
	- Bộ nhớ đệm (cache) để tăng tốc độ truy xuất
	- Trung gian truyền tin (Message broker)
	- Hàng đợi (queue) để xử lý tác vụ
