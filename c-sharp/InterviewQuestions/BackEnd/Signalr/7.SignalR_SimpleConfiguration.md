SignalR là thư viện giúp xây dựng ứng dụng thời gian thực. File này hướng dẫn cách cấu hình SignalR trên server và client, bao gồm quản lý Connection, Connection ID, và Groups.
## **1. Cài đặt SignalR**

Cài đặt gói NuGet cần thiết:
```bash
dotnet add package Microsoft.AspNetCore.SignalR
```

---
## **2. Cấu hình SignalR trên Server**

##### **Bước 1: Thêm dịch vụ SignalR vào Dependency Injection**

Trong Program.cs, thêm SignalR vào dịch vụ:
```csharp
var builder = WebApplication.CreateBuilder(args);

// Thêm dịch vụ SignalR
builder.Services.AddSignalR();

var app = builder.Build();

// Cấu hình middleware
app.UseRouting();
app.MapHub<ChatHub>("/chat-hub", options =>
    {
        options.Transports = 
	        HttpTransportType.WebSockets | 
	        HttpTransportType.LongPolling;
    }
); 

app.Run();
```

**Giải thích**:
- AddSignalR: Đăng ký SignalR vào DI container.
- MapHub<`ChatHub`>: Ánh xạ Hub đến endpoint /chat-hub.
- Transports: Cho phép sử dụng WebSocket hoặc Long Polling (fallback nếu WebSocket không hỗ trợ).

### **Bước 2: Tạo SignalR Hub**

Tạo lớp ChatHub để xử lý giao tiếp thời gian thực:
```csharp
using Microsoft.AspNetCore.SignalR;
using System.Threading.Tasks;

public class ChatHub : Hub
{
    // Gửi đến tất cả client
    public async Task SendBroadcastMessage(string message)
    {
        await Clients.All.SendAsync("ReceiveBroadcastMessage", message);
    }

    // Gửi đến client cụ thể (dùng Connection ID)
    public async Task SendPrivateMessage(string connectionId, string message)
    {
        await Clients.Client(connectionId).SendAsync("ReceivePrivateMessage", message);
    }

    // Gửi đến nhóm (Groups)
    public async Task SendMessageToGroup(string groupName, string message)
    {
        await Clients.Group(groupName).SendAsync("ReceiveGroupMessage", message);
    }

    // Thêm client vào nhóm
    public async Task JoinGroup(string groupName)
    {
        await Groups.AddToGroupAsync(Context.ConnectionId, groupName);
        await Clients.Group(groupName).SendAsync("ReceiveGroupMessage", $"User {Context.ConnectionId} joined {groupName}");
    }

    // Xóa client khỏi nhóm
    public async Task LeaveGroup(string groupName)
    {
        await Groups.RemoveFromGroupAsync(Context.ConnectionId, groupName);
        await Clients.Group(groupName).SendAsync("ReceiveGroupMessage", $"User {Context.ConnectionId} left {groupName}");
    }

    // Xử lý khi client kết nối
    public override async Task OnConnectedAsync()
    {
        await Clients.Caller.SendAsync("ReceiveMessage", $"Connected with ID: {Context.ConnectionId}");
        await base.OnConnectedAsync();
    }

    // Xử lý khi client ngắt kết nối
    public override async Task OnDisconnectedAsync(Exception exception)
    {
        await Clients.All.SendAsync("ReceiveMessage", $"User {Context.ConnectionId} disconnected");
        await base.OnDisconnectedAsync(exception);
    }
}
```

**Giải thích**:
- Context.ConnectionId: Lấy **Connection ID** của client để gửi tin nhắn riêng.
- Groups.AddToGroupAsync và RemoveFromGroupAsync: Quản lý **Groups**, thêm/xóa client vào nhóm.
- OnConnectedAsync và OnDisconnectedAsync: Xử lý sự kiện kết nối/ngắt kết nối, hữu ích để quản lý trạng thái client.

## **3. Bảo mật SignalR**

- **Xác thực (Authentication)**:
    - Sử dụng JWT hoặc cookie để xác thực client.
    - Ví dụ: Thêm middleware xác thực trong Program.cs:
```csharp
builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            // Cấu hình JWT
        };
    });
app.UseAuthentication();
app.UseAuthorization();
```

- Trong Hub, kiểm tra user:
```csharp
public async Task SendPrivateMessage(string userId, string message)
{
    if (Context.User.Identity.IsAuthenticated)
    {
        await Clients.User(userId).SendAsync("ReceivePrivateMessage", message);
    }
}
```

**CORS (Cross-Origin Resource Sharing)**:
- Nếu client và server ở khác domain, cấu hình CORS:

```csharp
builder.Services.AddCors(options =>
{
    options.AddPolicy("AllowAll", builder =>
    {
        builder.AllowAnyOrigin().AllowAnyMethod().AllowAnyHeader();
    });
});
app.UseCors("AllowAll");
```

## **4. Mở rộng quy mô (Scaling)**

- **Redis Backplane**:
    - Khi có nhiều server, sử dụng Redis để đồng bộ tin nhắn giữa các server:

```csharp
dotnet add package Microsoft.AspNetCore.SignalR.StackExchangeRedis
```

```csharp
builder.Services.AddSignalR().AddStackExchangeRedis("redis_connection_string");
```

- **Azure SignalR Service**:
	- Sử dụng dịch vụ Azure để quản lý kết nối lớn:

```csharp
builder.Services.AddSignalR().AddAzureSignalR("azure_connection_string");
```

## **5. Lưu ý triển khai**

- **Kiểm tra Transport**: Đảm bảo server và client hỗ trợ WebSocket. Nếu không, SignalR sẽ tự động fallback sang Long Polling hoặc SSE.
- **Xử lý reconnection**: Kích hoạt withAutomaticReconnect trên client để tự động kết nối lại khi mất kết nối.
- **Hiệu suất**: Giới hạn số lượng tin nhắn gửi đến Groups để tránh quá tải.
- **Debug**: Sử dụng logging hoặc Chrome DevTools để kiểm tra kết nối SignalR.

---
## **Liên kết với Connection, Connection ID, Groups**

- **Connection**: Được thiết lập khi client kết nối đến Hub (/chat-hub). SignalR quản lý kết nối qua WebSocket hoặc các Transport khác.
- **Connection ID**: Được gán tự động (Context.ConnectionId) để gửi tin nhắn riêng (SendPrivateMessage).
- **Groups**: Được quản lý qua JoinGroup và LeaveGroup, cho phép gửi tin nhắn đến nhiều client cùng lúc (SendMessageToGroup).
