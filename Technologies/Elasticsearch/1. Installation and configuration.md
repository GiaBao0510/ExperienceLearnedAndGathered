# Hướng Dẫn Cài Đặt và Thiết Lập Elasticsearch và Kibana trên Windows

Bài viết này hướng dẫn chi tiết cách cài đặt và thiết lập Elasticsearch và Kibana trên hệ điều hành Windows, phù hợp cho người mới bắt đầu. Elasticsearch là một công cụ tìm kiếm và phân tích dữ liệu mạnh mẽ, còn Kibana là giao diện trực quan để tương tác với dữ liệu trong Elasticsearch.

## Yêu Cầu Hệ Thống

Trước khi bắt đầu, hãy đảm bảo hệ thống của bạn đáp ứng các yêu cầu sau:

- **Hệ điều hành**: Windows 10 hoặc mới hơn (64-bit).
- **Java**: Elasticsearch yêu cầu Java (JDK) phiên bản 17 trở lên. Đề xuất sử dụng OpenJDK hoặc Oracle JDK.
- **RAM**: Tối thiểu 4GB (khuyến nghị 8GB trở lên).
- **Dung lượng đĩa**: Tối thiểu 2GB trống để cài đặt và lưu trữ dữ liệu.
- **Trình duyệt**: Chrome, Firefox hoặc Edge để truy cập giao diện Kibana.

## Bước 1: Tải và Giải Nén Elasticsearch

1. **Tải Elasticsearch**:
    - Truy cập [trang tải Elasticsearch](https://www.elastic.co/downloads/elasticsearch).
    - Chọn phiên bản mới nhất (ví dụ: 9.0.3) dành cho Windows (file `.zip`).
    - Tải xuống và giải nén vào một thư mục, ví dụ: `C:\elasticsearch-9.0.3`.
2. **Cài đặt Java (nếu chưa có)**:
    - Kiểm tra xem Java đã được cài đặt chưa bằng lệnh:
        
        ```cmd
        java -version
        ```
        
    - Nếu chưa cài, tải và cài đặt [OpenJDK 17](https://adoptium.net/) hoặc [Oracle JDK](https://www.oracle.com/java/technologies/javase-downloads.html).
    - Thiết lập biến môi trường `JAVA_HOME` trỏ đến thư mục cài đặt Java (hướng dẫn chi tiết có trên trang web của nhà cung cấp Java).

3. **Khởi động Elasticsearch**:
    - Mở Command Prompt (cmd) với quyền Administrator.
    - Điều hướng đến thư mục `bin` của Elasticsearch:
        
        ```cmd
        cd C:\elasticsearch-9.0.3\bin
        ```
        
    - Chạy lệnh:
        ```cmd
        elasticsearch.bat
        ```
        
    - **==Lần đầu chạy==**, Elasticsearch sẽ hiển thị thông tin quan trọng trên cmd, bao gồm:
        - **User**: Tên người dùng mặc định (thường là `elastic`).
        - **Password**: Mật khẩu tự động tạo.
        - **Enrollment token**: Token để kết nối Kibana với Elasticsearch.
    - **Lưu ý**: ==Ghi lại các thông tin này và lưu trữ ở nơi an toàn==.

4. **Kiểm tra Elasticsearch**:
    - Mở trình duyệt và truy cập: `http://localhost:9200/`.
    - Nhập `user` và `password` vừa lưu. Nếu thành công, bạn sẽ thấy thông tin JSON về phiên bản và trạng thái của Elasticsearch, ví dụ:
        
        ```json
        {
          "name": "node-1",
          "cluster_name": "elasticsearch",
          "version": {
            "number": "9.0.3"
          },
          ...
        }
        ```
        
    - **Lưu ý**: ==Đừng đóng cửa sổ cmd đang chạy Elasticsearch, vì nó cần hoạt động để Kibana kết nối.==

## Bước 2: Tải và Thiết Lập Kibana

1. **Tải Kibana**:
    - Truy cập [trang tải Kibana](https://www.elastic.co/downloads/kibana).
    - Tải phiên bản tương ứng với Elasticsearch (ví dụ: 9.0.3) dành cho Windows (file `.zip`).
    - Giải nén vào một thư mục, ví dụ: `C:\kibana-9.0.3`.

2. **Khởi động Kibana**:    
    - Mở Command Prompt (cmd) với quyền Administrator.
    - Điều hướng đến thư mục `bin` của Kibana:
        
        ```cmd
        cd C:\kibana-9.0.3\bin
        ```
        
    - Chạy lệnh:
        ```cmd
        kibana.bat
        ```
        
    - Kibana sẽ khởi động và hiển thị các thông tin trạng thái, ví dụ:
        ```cmd
        [2025-07-10T20:23:25.791+07:00][INFO][root] Kibana is starting
        [2025-07-10T20:24:11.239+07:00][INFO][http.server.Preboot] http server running at http://localhost:5601
        ```
        
3. **Truy cập giao diện Kibana**:
    - Mở trình duyệt và truy cập: `http://localhost:5601/`.
    - Kibana sẽ yêu cầu nhập **enrollment token** (lấy từ bước chạy Elasticsearch).
    - Sau khi nhập token, Kibana sẽ yêu cầu mã xác thực (verification code).

4. **Lấy mã xác thực (Verification Code)**:    
    - Mở một Command Prompt mới.
    - Điều hướng đến thư mục `bin` của Kibana:
        
        ```cmd
        cd C:\kibana-9.0.3\bin
        ```
        
    - Chạy lệnh:
        ```cmd
        kibana-verification-code.bat
        ```
        
    - Lệnh này sẽ hiển thị mã xác thực, ví dụ:
        ```cmd
        Your verification code is: 735 076
        ```
        
    - Nhập mã này (Mã này là ví dụ thôi) vào giao diện Kibana và nhấn xác nhận.

5. **Đăng nhập vào Kibana**:    
    
Sau khi xác thực mã, Kibana sẽ yêu cầu nhập `user` và `password` (tương tự thông tin từ Elasticsearch).
    ![](img_login.png)
 
 Sau khi đăng nhập thành công, bạn sẽ được chuyển đến giao diện chính của Kibana.

## Lưu Ý và Xử Lý Lỗi
- **Phiên bản tương thích**: Đảm bảo phiên bản Elasticsearch và Kibana giống nhau (ví dụ: đều là 9.0.3).
- **Cổng bị chiếm dụng**: Nếu cổng 9200 (Elasticsearch) hoặc 5601 (Kibana) bị chiếm dụng, kiểm tra và đóng ứng dụng sử dụng cổng bằng lệnh:
    
    ```cmd
    netstat -aon | findstr :9200
    ```
    
    Sau đó, dùng `taskkill /PID <số_PID> /F` để đóng tiến trình.
- **Không kết nối được Elasticsearch**:
    - Kiểm tra xem Elasticsearch đang chạy.
    - Đảm bảo thông tin `user`, `password`, và `enrollment token` được nhập chính đúng.

- **Hiệu suất**: Nếu máy tính yếu, tăng bộ nhớ cho Elasticsearch bằng cách chỉnh sửa file `config\jvm.options` trong thư mục Elasticsearch, ví dụ:
    
    ```text
    -Xms2g
    -Xmx2g
    ```

- **Cập nhật mật khẩu**: Nếu cần đặt lại mật khẩu, chạy lệnh sau trong thư mục `bin` của Elasticsearch:
    ```cmd
    elasticsearch-reset-password -u elastic
    ```

## Kết Luận
