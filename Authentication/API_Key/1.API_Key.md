### **API Key là gì**

**API Key (Application Programming Interface Key)** là ==một chuỗi ký tự đặc biệt được nhà phát hành API cung cấp== cho người dùng để ==xác thực và quản lý quyền truy cập== của vào API của họ. Nó giúp nhà cung cấp xác định và kiểm soát việc truy cập API và xác minh quyền hợp lệ của người dùng khi sử dụng dịch vụ API.

**API key** thường được ==gửi kèm trong các yêu cầu API== để xác minh danh tính và quyền hạn của người dùng khi sử dụng API. Khi mà bạn gửi một yêu cầu API với **API Key,** nhà cung cấp API sẽ kiểm tra danh tính  hợp lệ của key và xác định quyền truy cập tương ứng. Điều này đảm bảo rằng chỉ những người dùng được ủy quyền mới có thể sử dụng và truy cập các dịch vụ API.

API Key cũng có thể được sử dụng để ==giới hạn số lượng yêu cầu== API mà bạn cho phép trong khoảng thời gian nhất định. Điều này hữu ích cho việc ngăn chặn việc lạm dụng và đảm bảo công bằng trong việc cấp phát tài nguyên.

### **Tại sao dùng API key?**

- **Xác thực và ủy quyền:** API Keys được sử dụng để xác thự người dùng và cung cấp quyền truy cập vào dịch vụ API. Khi người dùng gửi yêu cầu API, cần API Key để xác thực và kiểm tra quyền hạn. Điều này giúp đảm bảo ngắn chặn việc truy cấp trái phép từ người dùng.

- **Giới hạn sử dụng:** API keys được sử dụng để giới hạn số lượng yêu cầu API mà một người dùng có thể gửi trong khoảng thời gian nhất định. Điều này giúp ngăn chặn người dùng lạm dụng tài nguyên.

- **Thống kê và giám sát:** API Keys cung cấp thông tin và dữ liệu về việc sử dụng API của người dùng. Bằng cách theo dõi và phân tích API Keys, có thể đánh giá lưu lượng sử dụng, thống kê các yêu cầu thành công và thất bại từ người dùng.

- **Phân quyền:** API Keys cung cấp khả năng phân quyền cho người dùng API. Có thể thiết lập các quyền truy cập khác nhau cho từng API Key hoặc nhóm API Key, cho phép chúng chỉ được truy cập vào phần cụ thể vào API của bạn.

### **Ưu & nhược điểm**

##### **Ưu điểm:**
- Có thể kết nối mọi lúc, mọi nơi miễn là có internet.
- Có cấu hình đơn giản hơn WCF
- Có mã nguồn mở
- API cho phép giap tiếp 2 chiều giữa các thông tin xác định
- Hỗ trợ RESTFul
- Hoạt động ổn định
- API dễ dàng truy cập, dễ hiểu và thân thiện

##### **Nhược điểm:**
- Tốn chi phí để nâng cấp, vận hàng và phát triển
- Triển khai phức tạp
- Dễ xảy ra vấn đề bảo mật khi hệ thống bị tấn công.
