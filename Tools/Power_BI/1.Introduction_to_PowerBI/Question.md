## **1. In the Query Settings pane, how can you modify the name of a query?**

> Double-click on the query name in the Query Settings pane
 
**Description:**
To rename a query, you can double-click on the query name directly in the Query Settings pane, which allows you to edit it. This makes it easier to manage and organise multiple queries.

## 3. **What is the purpose of the "Enable Load" option found in the Query Settings pane in Power BI?**

> To determine whether the query results are loaded into the data model

*Description:*
The "Enable Load" option in the Query Settings pane allows you to control whether the results of a query are loaded into the data model. Disabling this option can be useful if you only want to use the query for intermediate transformations and not load the final result into the model.

## 5. **Which of the following is the primary view used for creating relationships between tables in Power BI?**

> Model View

*Description:*
The Model View in Power BI is specifically designed for managing relationships between tables in your data model. It allows you to visually create, edit, and view the relationships between tables.

## 6. **What information does the "Query Settings" pane in Power BI's Query Editor typically display?**

>The name of the query and the applied steps

*Description:*
The "Query Settings" pane displays the name of the current query and a list of all the transformations or steps that have been applied to that query. This helps users track and manage the changes made to the data.
