# 5.4 Shell Variables

Trong Linux, các biến shell được sử dụng để lưu trữ dữ liệu. Dữ liệu này được chính shell cũng như các chương trình và người dùng sử dụng.
Trọng tâm của phần này là tìm hiểu cách hiển thị giá trị của các biến shell.

### 5.4.1 Step 1
Lệnh `echo` có thể được sử dụng để in văn bản và giá trị của một biến, đồng thời cho thấy cách môi trường shell mở rộng các ký tự đặc biệt (metacharacter) — chúng ta sẽ tìm hiểu kỹ hơn về các ký tự này ở phần sau của bài thực hành. Hãy nhập lệnh dưới đây để hiển thị văn bản nguyên bản:

```
echo Hello Student
```

Kết quả đầu ra của bạn sẽ tương tự như sau:
```shell
sysadmin@localhost:~$ echo Hello Student                                        
Hello Student                                                                   
```

### 5.4.2 Step 2:
Các biến môi trường khả dụng trên toàn hệ thống. Hệ thống sẽ tự động tạo lại các biến môi trường này mỗi khi một shell mới được mở. Các ví dụ bao gồm các biến `PATH`, `HOME` và `HISTSIZE`. Biến `HISTSIZE` xác định số lượng lệnh trước đó được lưu trữ trong danh sách lịch sử. Trong ví dụ dưới đây, lệnh này sẽ hiển thị giá trị của biến `HISTSIZE`:

```shell
sysadmin@localhost:~$ echo $HISTSIZE                                            
1000  
```

### 5.4.3 Step 3
Hãy nhập lệnh sau để hiển thị giá trị của biến PATH:

```
echo $PATH
```

Kết quả đầu ra của bạn sẽ tương tự như sau:
```shell
sysadmin@localhost:~$ echo $PATH                                                
/home/sysadmin/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:
/usr/games:/usr/local/games:/snap/bin  
```

Biến PATH được hiển thị bằng cách đặt ký tự $ phía trước tên biến.

Biến này được sử dụng để xác định vị trí của các lệnh. Mỗi thư mục được liệt kê ở trên đều sẽ được tìm kiếm khi bạn chạy một lệnh. Chẳng hạn, nếu bạn cố chạy lệnh `date`, shell trước tiên sẽ tìm kiếm lệnh này trong thư mục `/home/sysadmin/bin`, sau đó là thư mục `/usr/local/sbin`, và cứ tiếp tục như vậy. Ngay khi tìm thấy lệnh `date`, shell sẽ "thực thi" lệnh đó.

### 5.4.4 Step 4

Sử dụng lệnh `which` để xác định xem có tệp thực thi nào (trong trường hợp này là tệp có tên `date`) nằm trong một thư mục được liệt kê trong giá trị `PATH` hay không:

```
which date
```

Kết quả đầu ra của bạn sẽ tương tự như sau:
```shell
sysadmin@localhost:~$ which date                                                
/bin/date   
```

Kết quả từ lệnh `which` cho biết rằng khi bạn thực thi lệnh `date`, hệ thống sẽ chạy lệnh `/bin/date`. Lệnh `which` sử dụng biến `PATH` để xác định vị trí của lệnh `date`.

# 5.5 Command Types

Trong phần này, chúng ta sẽ tìm hiểu về bốn loại lệnh được sử dụng trong Linux. Việc hiểu rõ nguồn gốc cũng như sự khác biệt giữa các loại lệnh này sẽ giúp người quản trị hệ thống quản lý hệ thống hiệu quả hơn.

### 5.5.1 Step 1

Một cách để tìm hiểu thêm về lệnh là xem nó đến từ đâu. Lệnh `type` có thể được sử dụng để xác định thông tin về loại lệnh.

```
type command
```

Có một số nguồn lệnh khác nhau trong shell CLI của bạn:

Các lệnh nội bộ được tích hợp sẵn trong shell. Một ví dụ điển hình là lệnh `cd` (thay đổi thư mục) vì nó là một phần của shell Bash. Khi người dùng gõ lệnh `cd`, shell Bash đã thực thi và biết cách diễn giải nó, không yêu cầu khởi động thêm chương trình nào.

Lệnh type xác định lệnh `cd` là lệnh nội bộ:

```shell
sysadmin@localhost:~$ type cd                                                   
cd is a shell builtin 
```

### 5.5.2 Step 2

Các lệnh bên ngoài (external commands) là các tệp thực thi nhị phân được lưu trữ trong các thư mục mà shell sẽ tìm kiếm. Nếu người dùng nhập lệnh `ls`, shell sẽ tìm kiếm trong các thư mục được liệt kê trong biến `PATH` để cố gắng tìm một tệp có tên là `ls` mà nó có thể thực thi. Hãy sử dụng lệnh `which` để hiển thị đường dẫn đầy đủ đến lệnh `ls`.

```
which ls
```

```shell                                                                         
sysadmin@localhost:~$ which ls                                                  
/bin/ls       
```

Đối với các lệnh bên ngoài, lệnh type hiển thị vị trí của lệnh đó:
```shell
sysadmin@localhost:~$ type cp
cp is /bin/cp
```

Trong một số trường hợp, kết quả đầu ra của lệnh `type` có thể khác biệt đáng kể so với kết quả đầu ra của lệnh `which`:
```shell
sysadmin@localhost:~$ which cp                                                  
/bin/cp    
```

Việc sử dụng tùy chọn -a của lệnh type sẽ hiển thị tất cả các vị trí có chứa lệnh đó:
```shell
sysadmin@localhost:~$ type -a ls
ls được đặt bí danh là `ls --color=auto'
ls là /bin/ls
```

### 5.5.3 Step 3
Các bí danh (alias) có thể được sử dụng để ánh xạ các lệnh dài thành những chuỗi phím ngắn hơn. Khi shell phát hiện một bí danh đang được thực thi, nó sẽ thay thế bí danh đó bằng chuỗi lệnh đầy đủ trước khi tiến hành thông dịch các lệnh.

Để xác định những bí danh nào đã được thiết lập trong shell hiện tại, hãy sử dụng lệnh `alias`:
```shell
sysadmin@localhost:~$ alias                                                     
alias alert='notify-send --urgency=low -i "$([ $? = 0 ] && echo terminal || echo
 error)" "$(history|tail -n1|sed -e '\''s/^\s*[0-9]\+\s*//;s/[;&|]\s*alert$//'\'
')"'                                                                            
alias egrep='egrep --color=auto'                                                
alias fgrep='fgrep --color=auto'                                                
alias grep='grep --color=auto'                                                  
alias l='ls -CF'                                                                
alias la='ls -A'                                                                
alias ll='ls -alF'                                                              
alias ls='ls --color=auto'   
```

### 5.5.4 Step 4
Loại lệnh cuối cùng là chương trình thực thi. Các lệnh này gọi đến những chương trình đã được cài đặt trên hệ thống để thực hiện các tác vụ cụ thể. Khi người dùng nhập lệnh `vi`, shell sẽ sử dụng biến môi trường PATH để xác định vị trí và thực thi chương trình đó. Những chương trình như `vi` thường có sẵn trên hầu hết các bản phân phối Linux; trong khi đó, các chương trình khác—ví dụ như `vlc` (một trình phát đa phương tiện mã nguồn mở thường được dùng trên các hệ thống Linux)—thường do người dùng hoặc quản trị viên cài đặt cho một mục đích cụ thể, và chúng sẽ không nằm trong PATH trừ khi được cài đặt riêng biệt.

```
type vi
cd /bin
type vlc
cd
```

```shell
sysadmin@localhost:~$ type vi                                                   
vi is /usr/bin/vi                                                               
sysadmin@localhost:~$ cd /bin                                                   
sysadmin@localhost:/bin$ type vlc                                               
-bash: type: vlc: not found   
```
