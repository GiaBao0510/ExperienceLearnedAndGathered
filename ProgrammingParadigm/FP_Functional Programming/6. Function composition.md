# Kết Hợp Hàm (Function Composition)

**Kết hợp hàm (Function Composition)** là kỹ thuật tạo ra một hàm mới bằng cách **nối tiếp nhiều hàm nhỏ lại với nhau**, trong đó đầu ra của hàm này trở thành đầu vào của hàm tiếp theo. Thay vì viết một hàm lớn làm nhiều việc cùng lúc, bạn chia nhỏ logic thành các hàm đơn giản rồi kết hợp chúng lại theo nhu cầu.

Hình dung đơn giản: giống như **dây chuyền sản xuất trong nhà máy** — nguyên liệu đi qua từng trạm, mỗi trạm làm đúng một việc, và sản phẩm cuối cùng là kết quả của toàn bộ dây chuyền. Bạn có thể thêm, bớt, hoặc hoán đổi các trạm mà không cần xây lại toàn bộ nhà máy.

---

## 1. Nền Tảng Toán Học

Function Composition bắt nguồn từ toán học. Trong toán học, nếu có hai hàm `f` và `g`, thì hàm hợp của chúng được ký hiệu là:

```
(f ∘ g)(x) = f(g(x))
```

Nghĩa là: áp dụng `g` trước, lấy kết quả rồi truyền vào `f`. Thứ tự thực hiện là **từ trong ra ngoài** (hoặc từ phải sang trái).

Ví dụ với `f(x) = x + 3` và `g(x) = x * 2`:

```
(f ∘ g)(5) = f(g(5)) = f(10) = 13
```

## 2. Ví Dụ Cơ Bản Trong Go

### Cách thủ công — gọi lồng nhau trực tiếp

Đây là cách đơn giản nhất: gọi hàm bên trong hàm.

```go
package main

import "fmt"

func multiplyBy2(x int) int {
    return x * 2
}

func add3(x int) int {
    return x + 3
}

// Hàm hợp thủ công: g(x) = add3(multiplyBy2(x))
func multiplyAndAdd(x int) int {
    return add3(multiplyBy2(x))
}

func main() {
    fmt.Println(multiplyAndAdd(5)) // (5 * 2) + 3 = 13
    fmt.Println(multiplyAndAdd(0)) // (0 * 2) + 3 = 3
    fmt.Println(multiplyAndAdd(10)) // (10 * 2) + 3 = 23
}
```

Cách này hoạt động tốt nhưng có hạn chế: mỗi khi muốn kết hợp theo thứ tự khác, bạn phải viết thêm một hàm mới.

## 3. Hàm Compose Tổng Quát

Thay vì viết tay từng hàm hợp, ta có thể tạo một **hàm `compose` tổng quát** nhận hai hàm và trả về hàm hợp của chúng. Đây chính là sự kết hợp giữa Function Composition và Higher-order Functions.

```go
package main

import "fmt"

// compose nhận hai hàm f và g, trả về hàm mới thực hiện f(g(x))
func compose(f, g func(int) int) func(int) int {
    return func(x int) int {
        return f(g(x))
    }
}

func multiplyBy2(x int) int { return x * 2 }
func add3(x int) int        { return x + 3 }
func square(x int) int      { return x * x }

func main() {
    // Tạo hàm hợp: add3(multiplyBy2(x))
    multiplyThenAdd := compose(add3, multiplyBy2)
    fmt.Println(multiplyThenAdd(5))  // (5 * 2) + 3 = 13
    fmt.Println(multiplyThenAdd(10)) // (10 * 2) + 3 = 23

    // Đổi thứ tự: multiplyBy2(add3(x))
    addThenMultiply := compose(multiplyBy2, add3)
    fmt.Println(addThenMultiply(5))  // (5 + 3) * 2 = 16
    fmt.Println(addThenMultiply(10)) // (10 + 3) * 2 = 26

    // Kết hợp ba hàm bằng cách lồng compose
    squareThenMultiplyThenAdd := compose(add3, compose(multiplyBy2, square))
    fmt.Println(squareThenMultiplyThenAdd(3)) // ((3^2) * 2) + 3 = 21
}
```

Lưu ý quan trọng: thứ tự các hàm trong `compose(f, g)` ảnh hưởng trực tiếp đến kết quả. `compose(add3, multiplyBy2)` khác với `compose(multiplyBy2, add3)` — giống hệt toán học.

## 4. Compose Nhiều Hàm Cùng Lúc

Khi cần kết hợp nhiều hơn hai hàm, ta có thể mở rộng `compose` để nhận một danh sách hàm tùy ý và thực hiện chúng theo thứ tự **từ phải sang trái** (đúng theo quy ước toán học).

```go
package main

import "fmt"

// composeMany nhận danh sách các hàm và trả về hàm hợp của tất cả,
// thực hiện theo thứ tự từ phải sang trái
func composeMany(fns ...func(int) int) func(int) int {
    return func(x int) int {
        result := x
        for i := len(fns) - 1; i >= 0; i-- {
            result = fns[i](result)
        }
        return result
    }
}

func multiplyBy2(x int) int { return x * 2 }
func add3(x int) int        { return x + 3 }
func subtract1(x int) int   { return x - 1 }
func square(x int) int      { return x * x }

func main() {
    // Thứ tự thực hiện (phải → trái): square → multiplyBy2 → add3 → subtract1
    // Với x = 3:
    //   square(3)      = 9
    //   multiplyBy2(9) = 18
    //   add3(18)       = 21
    //   subtract1(21)  = 20
    transform := composeMany(subtract1, add3, multiplyBy2, square)
    fmt.Println(transform(3)) // 20
    fmt.Println(transform(4)) // subtract1(add3(multiplyBy2(square(4)))) = subtract1(add3(32)) = subtract1(35) = 34
}
```

## 5. Biến Thể: Pipe (Thực Hiện Từ Trái Sang Phải)

Trong thực tế lập trình, nhiều người thấy thứ tự **trái sang phải** dễ đọc hơn vì nó khớp với cách ta đọc văn bản. Biến thể này thường được gọi là **pipe** (đường ống).

```go
package main

import "fmt"

// pipe thực hiện các hàm theo thứ tự từ trái sang phải
func pipe(fns ...func(int) int) func(int) int {
    return func(x int) int {
        result := x
        for _, f := range fns {
            result = f(result)
        }
        return result
    }
}

func multiplyBy2(x int) int { return x * 2 }
func add3(x int) int        { return x + 3 }
func subtract1(x int) int   { return x - 1 }
func square(x int) int      { return x * x }

func main() {
    // Thứ tự thực hiện (trái → phải): square → multiplyBy2 → add3 → subtract1
    // Với x = 3: 3 → 9 → 18 → 21 → 20
    transform := pipe(square, multiplyBy2, add3, subtract1)
    fmt.Println(transform(3)) // 20

    // Dễ đọc hơn: ta thấy ngay dữ liệu chạy qua từng bước theo thứ tự
    processData := pipe(
        multiplyBy2, // bước 1: nhân đôi
        add3,        // bước 2: cộng 3
        subtract1,   // bước 3: trừ 1
    )
    fmt.Println(processData(5)) // 5 → 10 → 13 → 12
}
```

|Kỹ thuật|Thứ tự|Ký hiệu toán học|Dễ đọc khi|
|---|---|---|---|
|`compose(f, g)`|Phải sang trái: g trước, f sau|`(f ∘ g)(x)`|Quen với ký hiệu toán học|
|`pipe(f, g)`|Trái sang phải: f trước, g sau|Không có ký hiệu chuẩn|Đọc như mô tả các bước|

## 6. Ứng Dụng Thực Tế: Xử Lý Chuỗi Văn Bản

Dưới đây là ví dụ gần với thực tế hơn — xử lý và chuẩn hóa dữ liệu đầu vào từ người dùng bằng cách kết hợp nhiều bước nhỏ.

```go
package main

import (
    "fmt"
    "strings"
)

// Các hàm xử lý chuỗi nhỏ, mỗi hàm làm đúng một việc
func trimSpaces(s string) string    { return strings.TrimSpace(s) }
func toLowerCase(s string) string   { return strings.ToLower(s) }
func removeDoubleSpaces(s string) string {
    for strings.Contains(s, "  ") {
        s = strings.ReplaceAll(s, "  ", " ")
    }
    return s
}

// pipe cho kiểu string
func pipeString(fns ...func(string) string) func(string) string {
    return func(s string) string {
        result := s
        for _, f := range fns {
            result = f(result)
        }
        return result
    }
}

func main() {
    // Kết hợp các bước xử lý thành một pipeline chuẩn hóa văn bản
    normalizeInput := pipeString(
        trimSpaces,        // bước 1: xóa khoảng trắng đầu/cuối
        toLowerCase,       // bước 2: chuyển về chữ thường
        removeDoubleSpaces, // bước 3: xóa khoảng trắng thừa bên trong
    )

    inputs := []string{
        "  Hello   World  ",
        "   GO   PROGRAMMING   ",
        "  Functional   PROGRAMMING  ",
    }

    for _, input := range inputs {
        fmt.Printf("Trước: %q\n", input)
        fmt.Printf("Sau:   %q\n\n", normalizeInput(input))
    }
    // Trước: "  Hello   World  "
    // Sau:   "hello world"
    //
    // Trước: "   GO   PROGRAMMING   "
    // Sau:   "go programming"
    //
    // Trước: "  Functional   PROGRAMMING  "
    // Sau:   "functional programming"
}
```

## 7. So Sánh: Có và Không Có Function Composition

Xét bài toán: chuẩn hóa điểm số — đảm bảo điểm nằm trong khoảng [0, 100] rồi làm tròn.

**Không dùng Function Composition — logic trộn lẫn nhau:**

```go
func processScore(score float64) float64 {
    // Ba bước trộn lẫn trong một hàm, khó thay đổi từng bước độc lập
    if score < 0 {
        score = 0
    }
    if score > 100 {
        score = 100
    }
    return math.Round(score)
}
```

**Dùng Function Composition — mỗi bước tách biệt, dễ thay đổi:**

```go
func clampMin(score float64) float64 {
    if score < 0 { return 0 }
    return score
}
func clampMax(score float64) float64 {
    if score > 100 { return 100 }
    return score
}
func roundScore(score float64) float64 {
    return math.Round(score)
}

processScore := pipe(clampMin, clampMax, roundScore)

// Muốn bỏ bước làm tròn? Chỉ cần:
processScoreNoRound := pipe(clampMin, clampMax)
```

## 8. Tổng Kết

|Khái niệm|Nội dung|
|---|---|
|Định nghĩa|Tạo hàm mới bằng cách nối tiếp các hàm nhỏ|
|Nguyên tắc|Đầu ra của hàm trước là đầu vào của hàm sau|
|Thứ tự compose|Phải sang trái: `compose(f, g)(x) = f(g(x))`|
|Thứ tự pipe|Trái sang phải: dễ đọc hơn trong lập trình|
|Lợi ích|Tái sử dụng cao, dễ thêm/bớt bước xử lý, mỗi hàm làm đúng một việc|
|Liên hệ|Kết hợp với Higher-order Functions để tạo pipeline linh hoạt|

> **Phần tiếp theo:** Chúng ta sẽ tìm hiểu về **Recursion (Đệ quy)** — kỹ thuật thay thế vòng lặp trong lập trình hàm, và cách Go xử lý đệ quy hiệu quả.
