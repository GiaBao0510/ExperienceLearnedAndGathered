
### **Functional Programming là gì?**

**Functional Programming** là một dạng mô hình lập trình (FR - Gọi là lập trình hàm), nó giống như lập trình tuần tự hay [lập trình hướng đối tượng (OOP)](obsidian://open?vault=CuuAmChanKinh&file=ProgrammingParadigm%2FOOP_Object%20Oriented%20Programming%2F1_Getting%20Started%20with%20OOP).

**Functional Programming** là một phương pháp lập trình trên các hàm toán học, tránh việc thay đối giá trị dữ liệu. Nó có nhiều lợi ích như: các khối xử lý độc lập dễ tái sử dụng, thuận lợi cho việc thay đối logic hoặc tìm lỗi chương trình.

**Functional Programming (FP)** là lựa chọn tối ưu cho việc xử lý song song, đặc biệt khi xử lý dữ liệu từ nhiều nguồn khác nhau. FP giúp đảm bảo tính toàn vẹn của dữ liệu và không gây ra xung đột khi thực hiện các phép tính song song và phân tích dữ liệu theo thời gian thực

### **Những đặc điểm của Functional Programming**

#### **Hàm phải thuần túy (Pure function)**
Hàm thuần túy là hàm có 2 đặc tính chính:
- ***Không có tác dụng phụ (No Side Effects):*** Hàm không thay đổi bất kỳ trạng thái bên ngoài nào, không tương tác với dữ liệu bên ngoài như biến toàn cục, không đọc/ghi tệp, không hiển thị ra màn hình, không thay đổi giá trị đối số truyền vào. Nó chỉ sử dụng dữ liệu mà nhận nhận được và thực hiện tính toán và trả về kết quả
- ***Nhất quán (Deterministic)***: Với cùng một đầu vào, hàm thuần túy luôn trả về kết quả giống nhau, không phụ thuộc vào trạng thái bên ngoài hay bất kỳ yếu tố nào khác. Điều này giúp dễ dàng dữ đoán kết quả và kiểm thử hàm.
```csharp
//Hàm thuần túy
public int sum(int a, int b){
	return a + b;
}

//Hàm không thuần túy
public int temp = 0;
public int SUM(int a){
	return temp + a;
}
```

#### **Dữ liệu có tính bất biến (Immutability)**

Dữ liệu có tính bất biến (Data Immutability) là khi một giá trị hoặc một đối tượng được tạo ra, nó **không thể thay đổi**, lập trình hàm sẽ tạo ra **bản sao** mới và bổ sung những thay đổi cần thiết trên bảo sao đó thay vì chỉnh sửa bản gốc

```csharp
static void Main(){

	//Khởi tạo danh sách ban đầu
	List l1 = new List<int> {1,3,5,7};

	//Thay vì thêm phần tử mới cho l1, thì sẽ tạo ra danh sách mới
	//Từ danh sách hiện có
	List l2 = l1.Append(9).ToList();
	
	// In ra danh sách mới
	Console.WriteLine($"List mới: {string.Join(", ", l2)}");

	// Kiểm tra danh sách cũ không thay đổi
	Console.WriteLine($"List gốc: {string.Join(", ", l1)}");
}
```

#### **Phù hợp với Đệ quy**

Trong Functional Programming có một nguyên tắc quan trong là tính **bất biến của dữ liệu (Immutability)**, có nghĩa là không thể thay đối biến trực tiếp khi lặp ra các phần tử, như trong vòng lặp thông thường. Thay vì đó ==đệ quy được sử dụng để xử lý các tác vụ lặp đi lặp lại mà không cần thay đổi trạng thái hoặc biến==.

- Vi phạm nguyên tắc bất biến
```csharp
using System;
using System.Collections.Generic;

class Program
{
    public static int SumList(List<int> lst)
    {
        int total = 0;  //Biến trạng thái có thể thay đổi 
        
        foreach (int i in lst)
        {
            total += i; //Thay đổi giá trị mỗi lần lặp
        }
        
        return total;
    }

    static void Main()
    {
        Console.WriteLine(SumList(new List<int>{1,2,3,4,5} ));
    }
}
```

- Không vi phạm nguyên tắc bất biến
```csharp
using System;
using System.Collections.Generic;

class Program
{
    public static int SumList(List<int> lst, int idx = 0)
    {
        if (idx >= lst.Count)
            return 0;

        return lst[idx] + SumList(lst, idx + 1);  // Không thay đổi trạng thái biến
    }

    static void Main()
    {
        Console.WriteLine(SumList(new List<int>{1,2,3,4,5 }));
    }
}
```


#### **Hỗ trợ Cài đặt hàm**

**Cài đặt hàm** (function configuration) trong lập trình hàm là một kỹ thuật cho phép tạo ra một hàm mới từ một hàm có sẳn bằng cách "cấu hình" một phần các tham số đầu vào của nó, giúp tạo ra các hàm chuyên biệt hơn từ những hàm tổng quát, đồng thời tái sử dụng code một cách hiệu quả. 

- ***Partial Application:*** tạo ra một hàm mới bằng cách "đóng băng" một số đối số của hàm gốc, hàm mới sẽ chờ nhận các đối số còn lại.
```csharp
using System;

class Program
{
    // Hàm tổng quát có 2 tham số
    public static int Multiply(int a, int b)
    {
        return a * b;
    }

    // Partial application: Đóng băng tham số a
    public static Func<int, int> PartiallyApplyMultiply(int a)
    {
        return b => Multiply(a, b);  // trả về hàm mới chỉ còn 1 tham số b
    }

    static void Main()
    {
        var Double = PartiallyApplyMultiply(2); // tạo hàm "Double"

        Console.WriteLine(Double(5));  // kết quả: 10 (2 * 5)
    }
}

```

- ***Currying:*** biến đổi một hàm có nhiều tham số thành một chuỗi các hàm đơn tham số. Thay vì truyền tất cả tham số cùng lúc, bạn có thể truyền từng tham số một, với một lần truyền sẽ trả về một hàm mới chờ tham số tiếp theo.
```csharp
using System;

class Program
{
    // Currying: hàm trả về một hàm
    public static Func<int, Func<int, int>> CurriedMultiply()
    {
        return a => b => a * b;
    }

    static void Main()
    {
        var multiply = CurriedMultiply();

        var Double = multiply(2);  // trả về hàm b => 2 * b

        Console.WriteLine(Double(5));  // kết quả: 10 (2 * 5)
    }
}
```

#### **Có tính trì hoãn (Lazy Evaluation)**

**Tính toán trì hoãn (Lazy Evaluation)** trong lập trình hàm giúp ==trì hõan việc tính toán một biểu thức cho đến khi giá trị của biểu thức đó thực sự cần thiết== (được gọi ở đâu đó), giúp tối ưu hóa hiệu suất và tiết kiệm tài nguyên.

```csharp
class Program
{
	// Hàm có tính trì hoãn sử dụng yield return
	public static IEnumerable<int> LazyRange(int n)
	{
		for(int i = 0; i < n; i++){
			yield return i;  // Trả về từng giá trị khi được yêu cầu
		}
	}

	static void Main()
	{
		var gen = LazyRange(5); //Không thực thi ngay
		foreach(var vle in gen) //Mỗi lần lặp nó sẽ lấy giá trị mới
		{
			Console.WriteLine(vle);
		}
	}
}
```

#### **Cho phép kết hợp hàm**

**Kết hợp hàm (Function Composition)** cho phép tạo ra các hàm mới bằng cách kết hợp hai hoặc nhiều hàm với nhau. Thay vì thực thi các hàm riêng biệt, trong đó đầu ra của hàm này là đầu vào của hàm kia.

```csharp
public int multiply_by_2(int x){
	return x * 2;
}

public int add_3(int x){
	return x + 3;
}

public multiply_and_add(int x){
	return add_3(multiply_by_2(x));
}
```
