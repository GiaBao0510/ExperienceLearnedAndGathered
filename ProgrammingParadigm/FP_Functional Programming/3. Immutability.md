## **Immutability (Sự bất biến)**

Trong Functional Programming không có khái niệm về biến (variable) 

FP xử lý việc thay đổi giá trị của một bản ghi mới bằng cách tạo ra bản sau của bản ghi đó với dữ liệu được cập nhật
FP xử lý trường hợp thay đổi giá trị này bằng cách: không copy lại tất cả các thành phần của bản ghi, mà sử dụng cấu trúc dữ liệu để thực hiện việc này một cách hiệu quả

>FP sử dụng đệ quy cho việc sử lý vòng lặp

Ví dụ:
```go
//Simple loop construct
var acc = 0
for i:= 0; i <= 10; i++{
	acc += i
}

fmt.Println(acc)
    
// without loop construct or variable (recurrsion)
func sumRange(start, end, acc int) int {
	if(start > end){
		return acc
	}
	
	return sumRange(start +1, end, start + acc)
}
```
