## 📍 GIAI ĐOẠN 1: Kiến thức nền tảng

### 🔹 1. Elasticsearch là gì?

- Tìm hiểu khái niệm: Elasticsearch, Logstash, Kibana (gọi chung là ELK stack).
- Mục đích và các bài toán ứng dụng: full-text search, log analytics, hệ thống đề xuất, v.v.

### 🔹 2. Kiến trúc tổng quan

- Cluster, Node, Index, Document
- Shard & Replica: Cơ chế phân tán và sao lưu
- Mapping và Schema
- REST API hoạt động ra sao

## 📍 GIAI ĐOẠN 2: Làm việc với dữ liệu

### 🔹 1. CRUD cơ bản

- Tạo index, thêm document, cập nhật và xóa
- Index vs Type vs Document ID

### 🔹 2. Mapping & Data Types

- Mapping thủ công vs dynamic mapping
- Kiểu dữ liệu: text, keyword, date, nested, object...

### 🔹 3. Search cơ bản

- Match vs Term
- Bool queries (must, should, filter)
- Range queries, wildcard, prefix, regexp...

## 📍 GIAI ĐOẠN 3: Kỹ thuật truy vấn nâng cao

### 🔹 1. Full-Text Search

- Analyzer (Standard, Whitespace, Custom analyzer)
- Tokenizer, Filters
- Highlighting, fuzziness (tìm kiếm gần đúng)

### 🔹 2. Aggregations

- Metric Aggregations (sum, avg, min, max, count)
- Bucket Aggregations (terms, date_histogram, range)
- Nested Aggregations

### 🔹 3. Pagination & Sorting

- `from`, `size`, `search_after`, `scroll`

## 📍 GIAI ĐOẠN 4: Tối ưu hóa và quản trị

### 🔹 1. Performance

- Tối ưu mapping, tránh dynamic mapping
- Chọn đúng số shard & replica
- Sử dụng `filter` thay vì `must` khi có thể

### 🔹 2. Monitoring & quản trị

- Xem trạng thái cluster (`_cluster/health`, `_cat` API)
- Snapshot & Restore
- ILM (Index Lifecycle Management)

## 📍 GIAI ĐOẠN 5: Tích hợp và thực chiến

### 🔹 1. Tích hợp với các ngôn ngữ lập trình

- Sử dụng Elasticsearch client cho:
    
    - C# (.NET): [NEST](https://www.elastic.co/guide/en/elasticsearch/client/net-api/current/index.html)

### 🔹 2. Kết hợp ELK Stack (Logstash + Kibana)

- Cấu hình pipeline với Logstash để đẩy log
- Phân tích dữ liệu bằng Kibana
- Viết dashboard trực quan

### 🔹 3. Use case thực tế

- Xây dựng tính năng tìm kiếm cho E-commerce
