# Routing trong ASP.NET

## **Routing là gì?**

Routing là cơ chế trong ASP.NET cho phép ánh xạ (mapping) các URL requests từ client đến các Action Method tương ứng trong Controller. Đây là thành phần cốt lõi quyết định cách ứng dụng web phản hồi với các URL khác nhau.

**Nhiệm vụ chính của Routing:**

- Tìm Action Method phù hợp với URL request từ client
- Trích xuất các tham số từ URL và truyền vào Action Method
- Tạo ra các URL cho các link trong ứng dụng (URL Generation)
- Trả về lỗi 404 khi không tìm thấy route phù hợp

---

## **Cách thức hoạt động của Routing**

### **Quy trình xử lý request:**

1. **Client gửi request** với URL cụ thể
2. **Routing Middleware** nhận và phân tích URL
3. **Route Matching** tìm route pattern phù hợp
4. **Parameter Extraction** trích xuất các tham số từ URL
5. **Action Selection** xác định Controller và Action Method
6. **Execution** thực thi Action Method với các tham số

### **Ví dụ minh họa:**

```
URL Request: /Products/Details/5
↓
Route Pattern: {controller}/{action}/{id?}
↓
Controller: ProductsController
Action: Details
Parameter: id = 5
```

---

## **Hai phương pháp Routing chính**

ASP.NET hỗ trợ hai cách định nghĩa routing:

### **1. Convention-based Routing (Conventional Routing)**

- Định nghĩa quy tắc tập trung tại một nơi (Program.cs)
- Áp dụng cho toàn bộ ứng dụng
- Phù hợp với các ứng dụng có cấu trúc URL đồng nhất

### **2. Attribute-based Routing (Attribute Routing)**

- Định nghĩa route trực tiếp trên Controller/Action
- Linh hoạt và tùy chỉnh cao
- Phù hợp với API và các route phức tạp

---

## **Convention-based Routing (Conventional Routing)**

### **Cấu hình cơ bản trong Program.cs:**

```csharp
var app = builder.Build();

// Đăng ký Routing Middleware
app.UseRouting();

// Định nghĩa route mặc định
app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Home}/{action=Index}/{id?}");

app.Run();
```

### **Giải thích các thành phần:**

#### **`app.UseRouting()`**

**Chức năng:**

- Đăng ký Routing Middleware vào pipeline
- Cho phép ứng dụng xử lý và phân tích URL
- Thiết lập cơ chế tìm kiếm Action Method

#### **`app.MapControllerRoute()`**

**Chức năng:**

- Định nghĩa quy tắc ánh xạ URL sang Action Method
- Cấu hình các tham số routing

**Các tham số quan trọng:**

##### **`name` (Tên Route)**

```csharp
app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Home}/{action=Index}/{id?}");
```

- Đặt tên cho route để dễ quản lý và tham chiếu
- Sử dụng khi tạo URL trong View hoặc Controller

##### **`pattern` (Mẫu URL)**

```csharp
// Mẫu cơ bản
pattern: "{controller=Home}/{action=Index}/{id?}"

// Mẫu có constraints
pattern: "{controller}/{action}/{id:int?}"

// Mẫu tùy chỉnh
pattern: "products/{category}/{id:int}"
```

**Ý nghĩa các ký hiệu:**

- `{controller}`: Placeholder cho tên Controller
- `{action}`: Placeholder cho tên Action Method
- `{id?}`: Tham số tùy chọn (optional)
- `{id:int}`: Tham số với constraint (phải là số nguyên)
- `=Home`: Giá trị mặc định

### **Ví dụ về Conventional Routing:**

```csharp
// Cấu hình multiple routes
app.MapControllerRoute(
    name: "product-details",
    pattern: "products/{id:int}",
    defaults: new { controller = "Products", action = "Details" });

app.MapControllerRoute(
    name: "category",
    pattern: "category/{categoryName}",
    defaults: new { controller = "Products", action = "Category" });

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Home}/{action=Index}/{id?}");
```

**URL Matching Examples:**

- `/products/5` → ProductsController.Details(5)
- `/category/electronics` → ProductsController.Category("electronics")
- `/Home/About` → HomeController.About()
- `/` → HomeController.Index() (default)

## **Attribute-based Routing (Attribute Routing)**

### **Cấu hình cơ bản:**

```csharp
// Trong Program.cs, vẫn cần đăng ký routing
app.UseRouting();
app.MapControllers(); // Thay vì MapControllerRoute
```

### **Sử dụng Attribute Route:**

#### **Route trên Controller:**

```csharp
[Route("api/[controller]")]
public class ProductsController : ControllerBase
{
    // Tất cả action sẽ có prefix "api/Products"
    
    [HttpGet] // GET: api/Products
    public IActionResult GetAll() { ... }
    
    [HttpGet("{id:int}")] // GET: api/Products/5
    public IActionResult GetById(int id) { ... }
}
```

#### **Route trên Action Method:**

```csharp
public class HomeController : Controller
{
    [Route("")]
    [Route("home")]
    [Route("home/index")]
    public IActionResult Index()
    {
        // Có thể truy cập qua: /, /home, /home/index
        return View();
    }
    
    [Route("about-us")]
    public IActionResult About()
    {
        // URL: /about-us
        return View();
    }
    
    [Route("contact/{department?}")]
    public IActionResult Contact(string department = "general")
    {
        // URL: /contact hoặc /contact/sales
        return View();
    }
}
```

### **Route Parameters và Constraints:**

```csharp
public class ProductsController : Controller
{
    // Tham số bắt buộc
    [Route("products/{id}")]
    public IActionResult Details(string id) { ... }
    
    // Tham số với constraint
    [Route("products/{id:int}")]
    public IActionResult Details(int id) { ... }
    
    // Multiple constraints
    [Route("products/{id:int:min(1)}")]
    public IActionResult Details(int id) { ... }
    
    // Optional parameter
    [Route("products/search/{term?}")]
    public IActionResult Search(string term = "") { ... }
    
    // Multiple parameters
    [Route("products/{category}/{id:int}")]
    public IActionResult CategoryProduct(string category, int id) { ... }
    
    // Catch-all parameter
    [Route("files/{*filepath}")]
    public IActionResult DownloadFile(string filepath) { ... }
}
```

## **Route Constraints (Ràng buộc Route)**

Route constraints giúp kiểm soát việc matching URL với các điều kiện cụ thể.

### **Các loại Constraints phổ biến:**

```csharp
// Numeric constraints
[Route("products/{id:int}")]        // Số nguyên
[Route("products/{price:decimal}")]  // Số thập phân
[Route("products/{rating:double}")]  // Số thực
[Route("products/{id:long}")]       // Long integer

// String constraints
[Route("users/{name:alpha}")]       // Chỉ chữ cái
[Route("users/{code:alphanumeric}")]// Chữ cái và số
[Route("products/{id:guid}")]       // GUID format

// Length constraints
[Route("products/{name:length(5)}")]     // Độ dài chính xác
[Route("products/{name:minlength(2)}")]  // Độ dài tối thiểu
[Route("products/{name:maxlength(50)}")]  // Độ dài tối đa

// Range constraints
[Route("products/{page:int:min(1)}")]           // Giá trị tối thiểu
[Route("products/{count:int:range(1,100)}")]    // Trong khoảng

// Pattern constraints
[Route("products/{sku:regex(^[A-Z]{{3}}-\\d{{4}}$)}")]  // Regex pattern

// Custom constraints
[Route("users/{email:email}")]      // Email format
[Route("files/{filename:file}")]    // File name format
```

### **Kết hợp nhiều Constraints:**

```csharp
[Route("api/products/{id:int:min(1):max(9999)}")]
public IActionResult GetProduct(int id) { ... }
```

## **Route Parameters và Model Binding**

### **Binding từ Route:**

```csharp
[Route("products/{id:int}/reviews/{reviewId:int}")]
public IActionResult GetReview(int id, int reviewId)
{
    // ASP.NET tự động bind id và reviewId từ URL
    var review = _service.GetReview(id, reviewId);
    return Json(review);
}
```

### **Complex Parameter Binding:**

```csharp
[Route("search")]
public IActionResult Search([FromQuery] SearchRequest request)
{
    // URL: /search?term=laptop&category=electronics&page=1
    return View(request);
}

public class SearchRequest
{
    public string Term { get; set; }
    public string Category { get; set; }
    public int Page { get; set; } = 1;
}
```

## **Area Routing**

Areas giúp tổ chức ứng dụng lớn thành các module nhỏ hơn.

### **Cấu hình Area:**

```csharp
// Program.cs
app.MapControllerRoute(
    name: "areas",
    pattern: "{area:exists}/{controller=Home}/{action=Index}/{id?}");
```

### **Area Controller:**

```csharp
[Area("Admin")]
public class ProductsController : Controller
{
    // URL: /Admin/Products/Index
    public IActionResult Index() { ... }
}

// Hoặc sử dụng attribute routing
[Area("Admin")]
[Route("admin/products")]
public class ProductsController : Controller
{
    [Route("")]
    public IActionResult Index() { ... }
    
    [Route("{id:int}")]
    public IActionResult Details(int id) { ... }
}
```

## **API Routing**

### **RESTful API Routing:**

```csharp
[ApiController]
[Route("api/[controller]")]
public class ProductsController : ControllerBase
{
    [HttpGet]                    // GET api/products
    public IActionResult GetAll() { ... }
    
    [HttpGet("{id}")]           // GET api/products/5
    public IActionResult GetById(int id) { ... }
    
    [HttpPost]                  // POST api/products
    public IActionResult Create([FromBody] Product product) { ... }
    
    [HttpPut("{id}")]          // PUT api/products/5
    public IActionResult Update(int id, [FromBody] Product product) { ... }
    
    [HttpDelete("{id}")]       // DELETE api/products/5
    public IActionResult Delete(int id) { ... }
    
    // Nested resources
    [HttpGet("{id}/reviews")]  // GET api/products/5/reviews
    public IActionResult GetReviews(int id) { ... }
}
```

### **API Versioning:**

```csharp
[ApiController]
[Route("api/v{version:apiVersion}/[controller]")]
public class ProductsV1Controller : ControllerBase
{
    [HttpGet]
    public IActionResult GetAll() { ... }
}

[ApiController]
[Route("api/v{version:apiVersion}/[controller]")]
public class ProductsV2Controller : ControllerBase
{
    [HttpGet]
    public IActionResult GetAll() { ... }
}
```

### **Common Routing Issues:**

#### **1. Route Order Matters:**

```csharp
// ❌ Wrong order
app.MapControllerRoute("default", "{controller=Home}/{action=Index}/{id?}");
app.MapControllerRoute("specific", "products/featured");

// ✅ Correct order - specific routes first
app.MapControllerRoute("specific", "products/featured");
app.MapControllerRoute("default", "{controller=Home}/{action=Index}/{id?}");
```

#### **2. Conflicting Routes:**

```csharp
// ❌ Ambiguous routes
[Route("products/{id}")]
public IActionResult Details(string id) { ... }

[Route("products/{name}")]
public IActionResult ByName(string name) { ... }

// ✅ Use constraints to differentiate
[Route("products/{id:int}")]
public IActionResult Details(int id) { ... }

[Route("products/{name:alpha}")]
public IActionResult ByName(string name) { ... }
```

## **Performance Considerations**

### **Route Optimization:**

```csharp
// ✅ Use constraints to improve performance
[Route("api/products/{id:int:min(1)}")]
public IActionResult GetProduct(int id) { ... }

// ✅ Order routes by specificity
app.MapControllerRoute("most-specific", "very/specific/path");
app.MapControllerRoute("less-specific", "{controller}/{action}");
app.MapControllerRoute("catch-all", "{**path}");
```

### **Caching Routes:**

```csharp
// Routes are cached by default, but you can optimize
builder.Services.Configure<RouteOptions>(options =>
{
    options.LowercaseUrls = true;
    options.LowercaseQueryStrings = true;
    options.AppendTrailingSlash = false;
});
```

## **Best Practices**

### **1. Route Design:**

- **Sử dụng conventional routing** cho ứng dụng web truyền thống
- **Sử dụng attribute routing** cho API và routes phức tạp
- **Đặt routes cụ thể trước routes chung**
- **Sử dụng constraints** để tránh ambiguity

### **2. URL Design:**

- **Giữ URL ngắn gọn và có ý nghĩa**
- **Sử dụng lowercase URLs**
- **Tránh deep nesting** (quá nhiều cấp)
- **Consistent naming convention**

### **3. API Routing:**

- **Tuân thủ RESTful conventions**
- **Sử dụng HTTP verbs đúng cách**
- **Version APIs appropriately**
- **Group related endpoints**

### **4. Performance:**

- **Sử dụng constraints** để cải thiện matching speed
- **Avoid catch-all routes** khi không cần thiết
- **Order routes by frequency of use**

## **Tóm tắt**

**Các điểm quan trọng về Routing:**

1. **Routing** ánh xạ URL requests đến Action Methods
2. **Conventional Routing** định nghĩa rules tập trung
3. **Attribute Routing** linh hoạt và tùy chỉnh cao
4. **Route Constraints** kiểm soát URL matching
5. **Route Order** rất quan trọng - specific trước, general sau
6. **URL Generation** tạo links động trong ứng dụng
7. **Performance** có thể tối ưu thông qua constraints và ordering

Routing là nền tảng của web application, hiểu rõ về nó sẽ giúp bạn xây dựng ứng dụng có cấu trúc URL tốt, dễ sử dụng và maintainable.
