## 🔶 1. **Realtime là gì?**

![](https://static.vietnix.vn/wp-content/uploads/2022/08/real-time.webp)

**Realtime (thời gian thực)** trong lập trình là khả năng cập nhật thông tin giữa server và client **ngay lập tức**, mà **không cần người dùng thao tác thủ công** (như F5 để reload trang).

Ví dụ:

- Khi bạn chat trong Messenger, tin nhắn của người khác hiện ra ngay mà bạn không cần reload trang → đó là realtime.
- Một trang dashboard hiển thị số đơn hàng, khi có đơn mới thì tự động cập nhật → đó cũng là realtime.

---
## 🔶 2. **Tại sao cần áp dụng realtime?**

### ✅ Lý do:

- Trải nghiệm người dùng tốt hơn: Không cần reload để thấy thông tin mới.
- Dữ liệu luôn cập nhật, tránh lỗi sai hoặc trễ thông tin.
- Bắt buộc trong nhiều hệ thống có tính thời gian cao như: chat, đấu thầu, theo dõi vị trí...

---
## 🔶 3. **Áp dụng realtime khi nào?**

Dưới đây là một số tình huống thường dùng realtime:

| Tình huống                       | Mô tả                                                        |
| -------------------------------- | ------------------------------------------------------------ |
| Ứng dụng chat                    | Nhắn tin, hiển thị trạng thái "đang gõ", "đã xem"            |
| Notification                     | Khi có sự kiện mới (đơn hàng, người dùng đăng nhập...)       |
| Dashboard                        | Hiển thị dữ liệu thời gian thực như đơn hàng, người truy cập |
| Game                             | Cập nhật vị trí, trạng thái giữa các người chơi              |
| Livestream / bình chọn trực tiếp | Biểu quyết hoặc like realtime                                |
| Theo dõi vị trí GPS              | Như trong Uber hoặc Grab                                     |

## 🔶 4. **Cách thức hoạt động của realtime**

![](https://www.inexture.com/wp-content/uploads/2024/03/WebSocket-connection-1-768x419.png)

Truyền thống: Client → gửi request → Server → trả về dữ liệu.

Realtime:

- **Server giữ kết nối mở với Client** (thường là WebSocket, Long Polling…).
- Khi có dữ liệu mới, **Server tự động push xuống client**, không cần client hỏi.

SignalR chính là thư viện giúp bạn làm việc này dễ dàng trên nền tảng .NET.

## 🔶 6. Những chức năng nào thường áp dụng realtime trong ứng dụng lớn?

| Chức năng                         | Tính chất realtime                           |
| --------------------------------- | -------------------------------------------- |
| Chat nội bộ (support, live chat)  | Gửi nhận tin nhắn tức thì                    |
| Hệ thống thông báo                | Có sự kiện mới thì push thông báo ngay       |
| Quản lý đơn hàng                  | Cập nhật trạng thái đơn hàng trong dashboard |
| Cập nhật tồn kho                  | Khi sản phẩm được mua thì kho tự giảm        |
| Trạng thái người dùng             | Online/offline, đang gõ, đã xem...           |
| Theo dõi hệ thống (logs, metrics) | Ghi log thời gian thực                       |
