### **Hướng dẫn thao tác với Fly.io trên terminal của web [Fly.io](https://fly.io/) (Phần này bạn có thể đọc hiểu thêm)**

```
curl -L https://fly.io/install.sh | sh
```

#### ***Bây giờ ta sẽ thực hiện việc triển khai một [repo](https://github.com/GiaBao0510/fullstack-hy2026) từ github lên fly.io như sau:***

**Bước 1: Kiểm tra thư mục hiện tại**

Chạy:
```
pwd
```

*Output:*
```

```

Sau đó chạy:
```
ls -la
```

**Bước 2: Clone repo vào web terminal**

Nếu bạn chưa clone repo:
```
git clone https://github.com/GiaBao0510/fullstack-hy2026.git
```

```
cd fullstack-hy2026
```

```
pwd
```

```

/home/sprite/fullstack-hy2026
```

**Kiểm tra chính xác cấu trúc repo**

Đây là bước mình rất khuyến nghị trước khi chạy `fly launch`.

```
find . -maxdepth 2 -type f | sort
```

### Tạo deploy token

Chỉ chạy bước này sau khi application đã tồn tại:
```
fly tokens create deploy -a fullstack-hy2026-gia-bao
```

*Output:*
```
sprite@web-terminal:~/fullstack-hy2026$ fly tokens create deploy -a fullstack-hy2026-gia-bao
FlyV1 fm99_XXXYYYZZZ
```

Điều kiện hợp lý để tạo token cho App là
```
fly launch
     ↓
tạo được App
     ↓
fly tokens create deploy
     ↓
có App để tạo deploy token
```


*(Hết phần hướng dẫn thao tác với Terminal trong [Fly.io](https://fly.io/))*
