## Amazon EC2 Là Gì?

**EC2** là một trong những dịch vụ được sử dụng nhiều nhất của AWS.

![](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQxzlS5Db0NW7ZMYMpmbPSofmBgFMFUADQDTWsIQxG1jvCj-iAtdO3fXY8o&s=10)

**EC2 = Elastic Compute Cloud**, thuộc nhóm dịch vụ **Cơ sở hạ tầng dưới dạng dịch vụ (Infrastructure as a Service - IaaS)** — nghĩa là AWS cho bạn "thuê" hạ tầng máy tính (máy chủ, ổ đĩa, mạng...) theo nhu cầu, thay vì phải tự mua và vận hành phần cứng vật lý.

Dưới cái tên "EC2", AWS thực chất cung cấp cả một nhóm dịch vụ liên quan chặt chẽ với nhau:

- **EC2 Instance** — máy chủ ảo mà bạn thuê để chạy ứng dụng.
- **EBS (Elastic Block Store)** — ổ đĩa lưu trữ ảo gắn vào EC2 Instance.
- **ELB (Elastic Load Balancing)** — phân phối tải (traffic) giữa nhiều máy chủ.
- **ASG (Auto Scaling Group)** — tự động tăng/giảm số lượng máy chủ theo nhu cầu thực tế.

Nắm vững EC2 là nền tảng để hiểu cách điện toán đám mây hoạt động: đám mây cho phép bạn "thuê" tài nguyên tính toán bất cứ khi nào cần, theo đúng nhu cầu (on-demand) — và EC2 chính là hiện thân rõ nhất của ý tưởng đó.

## Các Tùy Chọn Cấu Hình EC2

Khi tạo một EC2 Instance, bạn có thể tùy chỉnh các nhóm cấu hình sau:

![](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQLqQ4V0NAyFtC9JLXBUs2FiiELSHqv0tmyTl70EzwkPJDgyPYeF3UEquDl&s=10)

| Nhóm cấu hình            | Chi tiết                                                                                                                                            |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hệ điều hành (OS)**    | Linux, Windows, hoặc macOS                                                                                                                          |
| **Công suất tính toán**  | Số nhân CPU, loại CPU                                                                                                                               |
| **Bộ nhớ (RAM)**         | Dung lượng RAM                                                                                                                                      |
| **Lưu trữ (Storage)**    | Lưu trữ qua mạng (**EBS**, **EFS**) hoặc lưu trữ phần cứng gắn trực tiếp (**EC2 Instance Store**) — nội dung này sẽ có một phần riêng, chi tiết hơn |
| **Mạng (Network)**       | Tốc độ card mạng, loại địa chỉ IP công khai (Public IP)                                                                                             |
| **Tường lửa (Firewall)** | Cấu hình qua **Security Group** của EC2 Instance                                                                                                    |
| **Tập lệnh khởi động**   | **EC2 User Data** — script chạy để tự động cấu hình instance ngay khi khởi chạy lần đầu (xem chi tiết ở mục tiếp theo)                              |

Đây là những khái niệm cốt lõi cho kỳ thi và thực hành; ở các cấp chứng chỉ nâng cao hơn, danh sách tùy chọn còn chi tiết hơn nhiều.

Điểm mấu chốt: bạn hoàn toàn tự do lựa chọn cấu hình máy chủ ảo theo đúng nhu cầu, và có thể "thuê" nó từ AWS gần như ngay lập tức — đây chính là sức mạnh cốt lõi của điện toán đám mây.

## EC2 User Data

**EC2 User Data** là cách để thực hiện **bootstrapping** cho một EC2 Instance — tức là **thực thi các lệnh tự động ngay khi máy chủ khởi động**, mà không cần bạn phải SSH vào và gõ tay từng lệnh.

![](https://storage.ghost.io/c/5f/2f/5f2f4d20-2abf-4534-8d40-7aa233aedd43/content/images/2025/03/image-21-29.png)

### Bootstrapping là gì?

![](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQIX2bjZNKevW5B6aeEKqdob2UTnaxWLcflBYBLObaagQ&s=10)

**Bootstrap** nghĩa là tự động thực thi các lệnh ngay khi máy chủ khởi động lần đầu tiên. Theo mặc định, **User Data script chỉ chạy đúng một lần**, ngay tại thời điểm EC2 Instance khởi động lần đầu — sau đó sẽ không tự chạy lại nữa dù bạn có restart instance [^1].

> 📌 Đây là hành vi **mặc định**, không phải giới hạn cứng: bạn hoàn toàn có thể cấu hình để User Data chạy lại ở **mỗi lần khởi động** (mỗi lần reboot/start), ví dụ trên Windows bằng cách thêm thẻ `<persist>true</persist>` vào script [^1]. Với phần lớn use case cơ bản, hành vi mặc định "chạy một lần" là đủ dùng.

### Dùng User Data để làm gì?

EC2 User Data thường dùng để tự động hóa các tác vụ thiết lập ban đầu, ví dụ:

- Cài đặt các bản cập nhật hệ thống.
- Cài đặt phần mềm cần thiết (web server, runtime...).
- Tải các file cấu hình phổ biến từ Internet.
- Bất kỳ tác vụ thiết lập nào khác mà bạn muốn tự động hóa.

**Ví dụ thực tế:** một script User Data đơn giản cho instance Linux — tự động cài và khởi động web server Apache ngay khi EC2 Instance khởi động lần đầu:

```bash
#!/bin/bash
yum update -y
yum install -y httpd
systemctl start httpd
systemctl enable httpd
echo "<html><h1>Xin chào từ EC2!</h1></html>" > /var/www/html/index.html
```

Với script này, ngay khi EC2 Instance khởi động xong, bạn đã có sẵn một web server đang chạy — không cần thao tác thủ công gì thêm.

> ⚠️ **Lưu ý:** User Data script càng dài, càng nhiều tác vụ, thì thời gian khởi động (boot) của instance càng lâu — vì tất cả các lệnh trong script đều chạy tuần tự trước khi instance sẵn sàng phục vụ.

### Quyền hạn khi chạy User Data

Trên **Linux**, User Data script chạy với quyền của **user `root`** — nghĩa là mọi lệnh trong script đều có toàn quyền trên hệ thống (tương đương chạy với `sudo`), không cần khai báo thêm [^1].

> 📌 Trên **Windows**, khái niệm tương đương là tài khoản **Local System** (không gọi là "root" — đây là thuật ngữ đặc trưng của hệ thống Unix/Linux), cũng có quyền cao nhất trên hệ thống [^1].

## Mở Rộng

- **EC2 Instance Types** — các họ instance (General Purpose, Compute Optimized, Memory Optimized, Storage Optimized...) tối ưu cho từng loại tải công việc khác nhau.
- **EBS vs EFS vs Instance Store** — so sánh chi tiết ba loại lưu trữ đã nhắc đến ở trên, sẽ học sâu ở phần Storage.
- **Security Group** — tìm hiểu sâu hơn cách cấu hình tường lửa cho EC2 Instance (inbound/outbound rules).
- **IAM Role cho EC2** — cách cấp quyền gọi API AWS cho EC2 Instance một cách an toàn (đã học ở phần IAM Roles), thường được cấu hình cùng lúc với User Data.
- **cloud-init** — công cụ chuẩn hóa xử lý bootstrapping trên hầu hết bản phân phối Linux, là nền tảng kỹ thuật đứng sau cơ chế EC2 User Data.
- **EC2 Instance Metadata & IMDSv2** — cách một ứng dụng chạy trên EC2 tự lấy thông tin về chính instance đó (bao gồm cả credentials từ IAM Role) trong runtime.
