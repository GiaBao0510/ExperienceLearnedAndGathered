## **Package net/http trong Golang**

### **Giới thiệu**
`net/http` là package tích hợp sẵn trong thư viện chuẩn của Golang. Nó cung cấp các công cụ mạnh mẽ để xây dựng và xử lý các ứng dụng web, đặc biệt là HTTP server và client.

### **Ưu điểm:**
- ✅ Tích hợp sẵn (không cần cài thêm)
- ✅ Nhẹ và hiệu năng cao
- ✅ Linh hoạt, kiểm soát chi tiết
- ✅ Phù hợp học cơ bản về HTTP

### **Nhược điểm:**
- ❌ Cú pháp dài dòng hơn
- ❌ Thiếu các tính năng sẵn có (routing phức tạp, middleware,...)
- ❌ Phải tự xử lý nhiều thứ (validation, error handling,...)

## **Xây dựng GET API với net/http**

### **Cấu trúc cơ bản của HTTP Server**

```go
package main

import (
    "log"
    "net/http"
)

func main() {
    // Bước 1: Đăng ký endpoint với handler function
    http.HandleFunc("/endpoint", handlerFunction)
    
    // Bước 2: Khởi động server và lắng nghe port
    log.Println("Server is running on http://localhost:8080")
    err := http.ListenAndServe(":8080", nil)
    
    // Bước 3: Xử lý lỗi nếu server không khởi động được
    if err != nil {
        log.Fatal("Error starting server:", err)
    }
}

func handlerFunction(w http.ResponseWriter, r *http.Request) {
    // Xử lý request và trả về response
}
```

### **Giải thích các thành phần:**

#### **1. http.HandleFunc()**

```go
http.HandleFunc("/demo", demoHandler)
```

- Đăng ký một endpoint (route) với handler function tương ứng
- Tham số 1: đường dẫn endpoint (`/demo`)
- Tham số 2: function xử lý request (`demoHandler`)

#### **2. http.ListenAndServe()**

```go
err := http.ListenAndServe(":8080", nil)
```

- Khởi động HTTP server
- Tham số 1: địa chỉ port (`:8080` = localhost:8080)
- Tham số 2: handler (nil = dùng DefaultServeMux)
- Trả về error nếu server không khởi động được

#### **3. Handler Function**

```go
func handlerFunction(w http.ResponseWriter, r *http.Request) {
    // w: dùng để ghi response trả về client
    // r: chứa thông tin request từ client
}
```

### **Ví dụ 1: GET API đơn giản**

```go
package main

import (
	"encoding/json"
	"log"
	"net/http"
)

func main() {
	// Đăng ký endpoint
	http.HandleFunc("/demo", demoHandler)

	log.Println("Server is running on http://localhost:8080")
	
	// Khởi động server
	err := http.ListenAndServe(":8080", nil)
	if err != nil {
		log.Fatal("Error starting server:", err)
	}
}

// Handler xử lý request
func demoHandler(w http.ResponseWriter, r *http.Request) {
	// Bước 1: Kiểm tra HTTP method
	if r.Method != http.MethodGet {
		http.Error(w, "Method not allowed", http.StatusMethodNotAllowed)
		return
	}

	// Bước 2: Tạo dữ liệu response
	response := map[string]string{
		"message": "Hello World",
		"status":  "success",
	}

	// Bước 3: Set header cho response
	w.Header().Set("Content-Type", "application/json")

	// Bước 4: Mã hóa response thành JSON
	data, err := json.Marshal(response)
	if err != nil {
		http.Error(w, "Error encoding JSON", http.StatusInternalServerError)
		return
	}

	// Bước 5: Ghi response vào body
	w.Write(data)
}
```

**Test API:**

```bash
curl http://localhost:8080/demo
```

**Response:**

```json
{
  "message": "Hello World",
  "status": "success"
}
```

### **Ví dụ 2: Cách viết ngắn gọn hơn với json.NewEncoder()**

```go
func demoHandler2(w http.ResponseWriter, r *http.Request) {
	// Kiểm tra HTTP method
	if r.Method != http.MethodGet {
		http.Error(w, "Method not allowed", http.StatusMethodNotAllowed)
		return
	}

	// Tạo response
	response := map[string]string{
		"message": "Hello World",
		"status":  "success",
	}

	// Set header
	w.Header().Set("Content-Type", "application/json")

	// Encode và ghi trực tiếp vào response (ngắn gọn hơn)
	json.NewEncoder(w).Encode(response)
}
```

### **So sánh 2 cách:**

| Cách                  | Code                                                     | Ưu điểm                 | Nhược điểm      |
| --------------------- | -------------------------------------------------------- | ----------------------- | --------------- |
| **json.Marshal()**    | `data, err := json.Marshal(response)`<br>`w.Write(data)` | Kiểm soát error tốt hơn | Dài dòng hơn    |
| **json.NewEncoder()** | `json.NewEncoder(w).Encode(response)`                    | Ngắn gọn, tự động ghi   | Khó xử lý error |

### **Ví dụ 3: GET API với Query Parameters**

```go
func getUserHandler(w http.ResponseWriter, r *http.Request) {
	// Kiểm tra method
	if r.Method != http.MethodGet {
		http.Error(w, "Method not allowed", http.StatusMethodNotAllowed)
		return
	}

	// Lấy query parameters từ URL
	// Ví dụ: /user?id=123&name=John
	userID := r.URL.Query().Get("id")
	userName := r.URL.Query().Get("name")

	// Kiểm tra tham số bắt buộc
	if userID == "" {
		http.Error(w, "Missing user ID", http.StatusBadRequest)
		return
	}

	// Tạo response
	response := map[string]interface{}{
		"user_id":   userID,
		"user_name": userName,
		"message":   "User found",
	}

	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(response)
}
```

**Test:**

```bash
curl "http://localhost:8080/user?id=123&name=John"
```

### **Ví dụ 5: Server hoàn chỉnh với nhiều endpoints**

```go
package main

import (
	"encoding/json"
	"log"
	"net/http"
)

type Product struct {
	ID    int     `json:"id"`
	Name  string  `json:"name"`
	Price float64 `json:"price"`
}

func main() {
	// Đăng ký nhiều endpoints
	http.HandleFunc("/", homeHandler)
	http.HandleFunc("/api/products", getProductsHandler)
	http.HandleFunc("/api/product", getProductByIDHandler)
	http.HandleFunc("/health", healthCheckHandler)

	log.Println("🚀 Server is running on http://localhost:8080")
	log.Fatal(http.ListenAndServe(":8080", nil))
}

// Handler cho trang chủ
func homeHandler(w http.ResponseWriter, r *http.Request) {
	w.Write([]byte("Welcome to API Server!"))
}

// Handler lấy danh sách sản phẩm
func getProductsHandler(w http.ResponseWriter, r *http.Request) {
	if r.Method != http.MethodGet {
		http.Error(w, "Method not allowed", http.StatusMethodNotAllowed)
		return
	}

	products := []Product{
		{ID: 1, Name: "Laptop", Price: 15000000},
		{ID: 2, Name: "Mouse", Price: 200000},
	}

	response := map[string]interface{}{
		"status": "success",
		"data":   products,
	}

	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(response)
}

// Handler lấy sản phẩm theo ID
func getProductByIDHandler(w http.ResponseWriter, r *http.Request) {
	if r.Method != http.MethodGet {
		http.Error(w, "Method not allowed", http.StatusMethodNotAllowed)
		return
	}

	productID := r.URL.Query().Get("id")
	if productID == "" {
		http.Error(w, "Missing product ID", http.StatusBadRequest)
		return
	}

	// Giả lập tìm sản phẩm (thực tế sẽ query database)
	product := Product{ID: 1, Name: "Laptop", Price: 15000000}

	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(product)
}

// Health check endpoint
func healthCheckHandler(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(map[string]string{
		"status": "healthy",
	})
}
```

## **Gin Framework**

### **Giới thiệu**

Gin Framework là một web framework nhẹ và nhanh trong Go (Golang), được xây dựng dựa trên `net/http` nhưng cung cấp nhiều tính năng tiện lợi hơn.

### **Tại sao nên dùng Gin?**

#### **Ưu điểm:**

- ✅ **Hiệu năng cao**: Nhanh hơn nhiều framework khác (40x nhanh hơn Martini)
- ✅ **Cú pháp đơn giản**: Code ngắn gọn, dễ đọc
- ✅ **Routing mạnh mẽ**: Hỗ trợ path parameters, query params, grouping
- ✅ **Middleware sẵn có**: Logger, Recovery, CORS, Authentication,...
- ✅ **JSON handling tự động**: Tự động parse và encode JSON
- ✅ **Validation**: Validate input dễ dàng với struct tags
- ✅ **Error handling tốt**: Quản lý lỗi tập trung

#### **Nhược điểm:**
- ❌ Cần cài đặt thêm package (không built-in)
- ❌ Phụ thuộc vào thư viện bên ngoài

### **Cài đặt Gin**

```bash
go get -u github.com/gin-gonic/gin
```

---

### **Ví dụ 1: Hello World với Gin**

```go
package main

import "github.com/gin-gonic/gin"

func main() {
	// Tạo router (với Logger và Recovery middleware mặc định)
	r := gin.Default()

	// Định nghĩa endpoint GET
	r.GET("/demo", func(c *gin.Context) {
		c.JSON(200, gin.H{
			"message": "Hello World",
			"status":  "success",
		})
	})

	// Khởi động server
	r.Run(":8080") // Mặc định chạy trên 0.0.0.0:8080
}
```

**Giải thích:**

- `gin.Default()`: Tạo router với middleware Logger và Recovery (Đây là chức năng/ Framework của gin, nó được sử dụng tạo version của instance mặc định)
- `r.GET()`: Định nghĩa endpoint GET
- `c.JSON()`: Tự động encode và trả về JSON với status code
- `gin.H`: Shorthand cho `map[string]interface{}`
- `gin.Context` là **struct của framework Gin**. Nó chứa rất nhiều thông tin như:
	- Request
	- Response
	- Params
	- Query
	- Headers
	- Cookies
	- Middleware data

### **Ví dụ 2: Nhiều endpoints với Gin**

```go
package main

import (
	"net/http"
	"github.com/gin-gonic/gin"
)

type Product struct {
	ID    int     `json:"id"`
	Name  string  `json:"name"`
	Price float64 `json:"price"`
}

func main() {
	r := gin.Default()

	// Endpoint 1: Trang chủ
	r.GET("/", func(c *gin.Context) {
		c.String(http.StatusOK, "Welcome to Gin API!")
	})

	// Endpoint 2: Danh sách sản phẩm
	r.GET("/api/products", getProducts)

	// Endpoint 3: Chi tiết sản phẩm
	r.GET("/api/products/:id", getProductByID)

	// Endpoint 4: Health check
	r.GET("/health", func(c *gin.Context) {
		c.JSON(http.StatusOK, gin.H{
			"status": "healthy",
		})
	})

	r.Run(":8080")
}

// Handler lấy danh sách sản phẩm
func getProducts(c *gin.Context) {
	products := []Product{
		{ID: 1, Name: "Laptop", Price: 15000000},
		{ID: 2, Name: "Mouse", Price: 200000},
		{ID: 3, Name: "Keyboard", Price: 500000},
	}

	c.JSON(http.StatusOK, gin.H{
		"status": "success",
		"total":  len(products),
		"data":   products,
	})
}

// Handler lấy sản phẩm theo ID (path parameter)
func getProductByID(c *gin.Context) {
	// Lấy ID từ URL path
	id := c.Param("id")

	// Giả lập tìm sản phẩm
	product := Product{ID: 1, Name: "Laptop", Price: 15000000}

	c.JSON(http.StatusOK, gin.H{
		"status": "success",
		"data":   product,
	})
}
```

## **So sánh net/http vs Gin**

### **Code cho cùng 1 chức năng:**

#### **Với net/http:**

```go
func handler(w http.ResponseWriter, r *http.Request) {
    if r.Method != http.MethodGet {
        http.Error(w, "Method not allowed", http.StatusMethodNotAllowed)
        return
    }
    
    id := r.URL.Query().Get("id")
    if id == "" {
        http.Error(w, "Missing ID", http.StatusBadRequest)
        return
    }
    
    response := map[string]string{"id": id, "name": "John"}
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(response)
}
```

#### **Với Gin:**

```go
func handler(c *gin.Context) {
    id := c.Query("id")
    if id == "" {
        c.JSON(400, gin.H{"error": "Missing ID"})
        return
    }
    
    c.JSON(200, gin.H{"id": id, "name": "John"})
}
```

### **Bảng so sánh:**

| Tiêu chí           | net/http          | Gin Framework            |
| ------------------ | ----------------- | ------------------------ |
| **Cài đặt**        | Built-in          | Cần `go get`             |
| **Độ dài code**    | Dài hơn           | Ngắn gọn hơn             |
| **Hiệu năng**      | Rất cao           | Cao (nhưng vẫn overhead) |
| **Routing**        | Đơn giản          | Mạnh mẽ (params, groups) |
| **Middleware**     | Tự implement      | Có sẵn nhiều             |
| **JSON handling**  | Manual            | Tự động                  |
| **Validation**     | Tự implement      | Built-in                 |
| **Error handling** | Phải tự xử lý     | Có Recovery middleware   |
| **Học tập**        | Hiểu sâu HTTP     | Nhanh, dễ dùng           |
| **Production**     | Phù hợp dự án nhỏ | Phù hợp mọi quy mô       |

## **Best Practices**

### **1. Tổ chức code rõ ràng**

```
project/
├── main.go           # Entry point
├── handlers/         # Request handlers
│   ├── product.go
│   └── user.go
├── models/           # Data structures
│   └── product.go
├── routes/           # Route definitions
│   └── routes.go
└── utils/            # Helper functions
    └── response.go
```

### **2. Sử dụng struct thay vì map**

❌ **Không nên:**

```go
response := map[string]interface{}{
    "id": 1,
    "name": "John",
}
```

✅ **Nên:**

```go
type User struct {
    ID   int    `json:"id"`
    Name string `json:"name"`
}

response := User{ID: 1, Name: "John"}
```

### **3. Xử lý lỗi đầy đủ**

```go
func getUser(c *gin.Context) {
    id := c.Param("id")
    
    // Validate input
    if id == "" {
        c.JSON(http.StatusBadRequest, gin.H{
            "error": "Invalid user ID",
        })
        return
    }
    
    // Simulate database query
    user, err := db.GetUser(id)
    if err != nil {
        c.JSON(http.StatusInternalServerError, gin.H{
            "error": "Failed to fetch user",
        })
        return
    }
    
    if user == nil {
        c.JSON(http.StatusNotFound, gin.H{
            "error": "User not found",
        })
        return
    }
    
    c.JSON(http.StatusOK, user)
}
```

### **4. Sử dụng HTTP Status Code đúng**

```go
c.JSON(http.StatusOK, data)           // 200 - Success
c.JSON(http.StatusCreated, data)      // 201 - Created
c.JSON(http.StatusBadRequest, err)    // 400 - Bad Request
c.JSON(http.StatusUnauthorized, err)  // 401 - Unauthorized
c.JSON(http.StatusNotFound, err)      // 404 - Not Found
c.JSON(http.StatusInternalServerError, err) // 500 - Server Error
```

### **5. Logging requests**

```go
func main() {
    r := gin.Default() // Đã có Logger middleware
    
    // Hoặc custom logger
    r.Use(gin.Logger())
    
    r.GET("/api/products", getProducts)
    r.Run(":8080")
}
```
