## 1. Tại sao Redis và Golang?

**Redis** là một cơ sở dữ liệu dạng key-value lưu trữ trực tiếp trên RAM, nên tốc độ đọc/ghi cực nhanh (thường dưới 1ms). Redis thường được dùng để:

- **Cache** dữ liệu thường xuyên truy cập (giảm tải database chính)
- **Session** lưu trạng thái đăng nhập người dùng
- **Queue** hàng đợi tác vụ (message broker)
- **Rate Limiting** giới hạn số lượng request

**Golang** nổi bật với hiệu năng cao, xử lý đồng thời (concurrency) tốt, và thời gian biên dịch nhanh. Kết hợp Golang + Redis là lựa chọn phổ biến trong các hệ thống backend hiệu năng cao.

> 💡 **Lưu ý cho sinh viên:** Hầu hết các công ty tuyển dụng backend hiện nay đều yêu cầu kinh nghiệm làm việc với Redis. Đây là kỹ năng rất được đánh giá cao trong thực tế.

## 2. Cài đặt Redis bằng Docker

Thay vì cài Redis trực tiếp lên máy, chúng ta dùng **Docker** để tiện quản lý và tránh xung đột môi trường.

### Yêu cầu

- Đã cài [Docker Desktop](https://www.docker.com/products/docker-desktop/)

### Lệnh khởi động Redis

```bash
docker run -d \
  --name redis-stack-server \
  -p 6379:6379 \
  -e REDIS_ARGS="--save 60 1000 --appendonly yes --requirepass redispass" \
  -v /local-data/:/data \
  redis/redis-stack-server:latest
```

### Giải thích từng tham số

|Tham số|Ý nghĩa|
|---|---|
|`-d`|Chạy container ở chế độ nền (detached)|
|`--name redis-stack-server`|Đặt tên cho container|
|`-p 6379:6379`|Map cổng 6379 của máy host vào container|
|`--save 60 1000`|Tự động lưu snapshot RDB mỗi 60 giây nếu có ít nhất 1000 key thay đổi|
|`--appendonly yes`|Bật chế độ AOF (Append-Only File) — ghi lại từng lệnh vào file để phục hồi dữ liệu khi khởi động lại|
|`--requirepass redispass`|Đặt mật khẩu xác thực. Thay `redispass` bằng mật khẩu của bạn|
|`-v /local-data/:/data`|Gắn thư mục `/local-data/` trên máy thật vào `/data` trong container để dữ liệu không mất khi container bị xóa|

> ⚠️ **Lưu ý:** Trên Windows, đường dẫn volume cần dùng định dạng như `-v C:/local-data:/data`.

### Kiểm tra Redis đang chạy

```bash
docker ps
```

Bạn sẽ thấy container `redis-stack-server` trong danh sách. Để kiểm tra kết nối:

```bash
docker exec -it redis-stack-server redis-cli -a redispass ping
# Kết quả mong đợi: PONG
```

## 5. Tệp cấu hình `config.yaml`

File này chứa toàn bộ thông tin kết nối Redis. Tách cấu hình ra file riêng giúp dễ thay đổi mà không cần sửa code.

```yaml
# config.yaml
redis:
  default:
    address: "127.0.0.1:6379"  # Địa chỉ IP và cổng của Redis server
    password: "redispass"       # Mật khẩu (phải khớp với --requirepass ở trên)
    db: 0                       # Redis có 16 database (0-15), mặc định dùng db 0
    idleTimeout: "60s"          # Thời gian giữ kết nối rảnh trước khi đóng
    maxConnLifetime: "90s"      # Thời gian sống tối đa của một kết nối
    waitTimeout: "60s"          # Thời gian tối đa chờ kết nối từ pool
    dialTimeout: "30s"          # Timeout khi thiết lập kết nối TCP
    readTimeout: "30s"          # Timeout khi đọc dữ liệu từ Redis
    writeTimeout: "30s"         # Timeout khi ghi dữ liệu vào Redis
    maxActive: 10000            # Số kết nối tối đa trong connection pool
```

> 💡 **Connection Pool là gì?** Thay vì tạo kết nối mới mỗi lần gửi lệnh đến Redis (tốn thời gian), connection pool duy trì sẵn một nhóm kết nối để tái sử dụng. `maxActive: 10000` nghĩa là có thể duy trì tối đa 10.000 kết nối đồng thời.

## 6. Khởi tạo kết nối Redis (`init.go`)

File này đọc cấu hình từ `config.yaml` và tạo Redis client dùng chung cho toàn bộ ứng dụng.

```go
// init.go
package main

import (
	"context"
	"fmt"
	"log"
	"os"
	"time"

	"github.com/go-redis/redis/v8"
	"gopkg.in/yaml.v3"
)

// Config ánh xạ cấu trúc của file config.yaml
type Config struct {
	Redis struct {
		Default struct {
			Address      string `yaml:"address"`
			Password     string `yaml:"password"`
			DB           int    `yaml:"db"`
			DialTimeout  string `yaml:"dialTimeout"`
			ReadTimeout  string `yaml:"readTimeout"`
			WriteTimeout string `yaml:"writeTimeout"`
			MaxActive    int    `yaml:"maxActive"`
		} `yaml:"default"`
	} `yaml:"redis"`
}

// Rdb là Redis client dùng chung (global variable)
// Ctx là context dùng chung — cần thiết cho mọi lệnh Redis
var Rdb *redis.Client
var Ctx = context.Background()

// InitRedis đọc file config và khởi tạo kết nối Redis
func InitRedis() {
	// Bước 1: Đọc nội dung file config.yaml
	yamlFile, err := os.ReadFile("config.yaml")
	if err != nil {
		log.Fatalf("❌ Lỗi đọc file config: %v", err)
	}

	// Bước 2: Parse nội dung YAML vào struct Config
	var cfg Config
	if err = yaml.Unmarshal(yamlFile, &cfg); err != nil {
		log.Fatalf("❌ Lỗi parse YAML: %v", err)
	}

	// Bước 3: Chuyển chuỗi timeout ("30s") sang kiểu time.Duration
	dialTimeout, _  := time.ParseDuration(cfg.Redis.Default.DialTimeout)
	readTimeout, _  := time.ParseDuration(cfg.Redis.Default.ReadTimeout)
	writeTimeout, _ := time.ParseDuration(cfg.Redis.Default.WriteTimeout)

	// Bước 4: Khởi tạo Redis client với các tùy chọn từ config
	Rdb = redis.NewClient(&redis.Options{
		Addr:         cfg.Redis.Default.Address,
		Password:     cfg.Redis.Default.Password,
		DB:           cfg.Redis.Default.DB,
		DialTimeout:  dialTimeout,
		ReadTimeout:  readTimeout,
		WriteTimeout: writeTimeout,
		PoolSize:     cfg.Redis.Default.MaxActive, // Số kết nối tối đa trong pool
	})

	// Bước 5: Kiểm tra kết nối bằng lệnh PING
	if _, err = Rdb.Ping(Ctx).Result(); err != nil {
		log.Fatalf("❌ Không thể kết nối Redis: %v", err)
	}

	fmt.Println("✅ Kết nối Redis thành công!")
}
```

> ⚠️ **Lưu ý:** `ioutil.ReadFile` đã bị deprecated từ Go 1.16. Hãy dùng `os.ReadFile` thay thế như trong ví dụ trên.

> 💡 **context.Background() là gì?** Trong Go, `context` được dùng để truyền thông tin về deadline, cancellation giữa các goroutine. `context.Background()` là context gốc, không có timeout, thường dùng ở tầng khởi tạo.

## 7. Thao tác với kiểu String (`string.go`)

Redis String là kiểu dữ liệu cơ bản nhất — lưu một giá trị văn bản (hoặc số) theo một key.

```go
// string.go
package main

import (
	"bufio"
	"fmt"
	"os"
	"strings"
	"time"
)

// reader dùng chung để đọc input từ bàn phím
var reader = bufio.NewReader(os.Stdin)

// readLine đọc một dòng và bỏ ký tự xuống dòng
func readLine(prompt string) string {
	fmt.Print(prompt)
	text, _ := reader.ReadString('\n')
	return strings.TrimSpace(text)
}

// Menu_STRING hiển thị menu thao tác với kiểu String
func Menu_STRING() {
	for {
		fmt.Println("\n--- MENU: String ---")
		fmt.Println("1. Thêm key - value")
		fmt.Println("2. Đọc giá trị theo key")
		fmt.Println("3. Xóa key")
		fmt.Println("0. Quay lại")
		fmt.Print("Lựa chọn: ")

		choiceByte, _ := reader.ReadByte()
		reader.ReadString('\n') // Xóa ký tự newline còn lại trong buffer

		switch choiceByte {
		case '1':
			insertKeyValue()
		case '2':
			key := readLine("Nhập key cần đọc: ")
			GetKey(key)
		case '3':
			key := readLine("Nhập key cần xóa: ")
			DeleteKey(key)
		case '0':
			return
		default:
			fmt.Println("⚠️ Lựa chọn không hợp lệ!")
		}
	}
}

// insertKeyValue nhận input từ người dùng rồi gọi SetKeyValue
func insertKeyValue() {
	key   := readLine("Nhập key: ")
	value := readLine("Nhập value: ")
	expStr := readLine("Nhập thời hạn (vd: 10s, 5m, 1h — nhập 0 để không hết hạn): ")

	exp, err := time.ParseDuration(expStr)
	if err != nil {
		fmt.Println("❌ Định dạng thời gian không hợp lệ. Ví dụ đúng: 10s, 5m, 1h")
		return
	}

	SetKeyValue(key, value, exp)
}

// SetKeyValue lưu một cặp key-value vào Redis với thời gian hết hạn
// exp = 0 nghĩa là key không bao giờ hết hạn
func SetKeyValue(key, value string, exp time.Duration) error {
	err := Rdb.Set(Ctx, key, value, exp).Err()
	if err != nil {
		fmt.Printf("❌ Lỗi khi set key '%s': %v\n", key, err)
		return err
	}
	fmt.Printf("✅ Đã lưu key='%s', value='%s', hết hạn sau: %v\n", key, value, exp)
	return nil
}

// GetKey đọc và in giá trị của một key từ Redis
func GetKey(key string) (string, error) {
	val, err := Rdb.Get(Ctx, key).Result()
	if err == redis.Nil {
		fmt.Printf("⚠️ Key '%s' không tồn tại hoặc đã hết hạn\n", key)
		return "", err
	} else if err != nil {
		fmt.Printf("❌ Lỗi khi đọc key '%s': %v\n", key, err)
		return "", err
	}
	fmt.Printf("✅ key='%s' → value='%s'\n", key, val)
	return val, nil
}

// DeleteKey xóa một key khỏi Redis
func DeleteKey(key string) error {
	result, err := Rdb.Del(Ctx, key).Result()
	if err != nil {
		fmt.Printf("❌ Lỗi khi xóa key '%s': %v\n", key, err)
		return err
	}
	if result == 0 {
		fmt.Printf("⚠️ Key '%s' không tồn tại\n", key)
	} else {
		fmt.Printf("✅ Đã xóa key '%s' thành công\n", key)
	}
	return nil
}
```

> 💡 **Xử lý `redis.Nil`:** Khi key không tồn tại, Redis trả về lỗi đặc biệt `redis.Nil`. Cần phân biệt trường hợp này với lỗi thực sự (mất kết nối, timeout,...) để thông báo đúng cho người dùng.

## 8. Chương trình chính (`main.go`)

```go
// main.go
package main

import (
	"fmt"
)

func main() {
	// Khởi tạo kết nối Redis ngay khi chương trình bắt đầu
	InitRedis()

	for {
		fmt.Println("\n====== REDIS DATA TYPE MENU ======")
		fmt.Println("1. String  — lưu giá trị đơn giản")
		fmt.Println("2. Hash    — lưu nhiều field (như object)")
		fmt.Println("3. List    — danh sách có thứ tự")
		fmt.Println("4. Set     — tập hợp không trùng lặp")
		fmt.Println("5. Sorted Set — tập hợp có điểm sắp xếp")
		fmt.Println("0. Thoát")
		fmt.Print("Lựa chọn của bạn: ")

		choiceByte, _ := reader.ReadByte()
		reader.ReadString('\n')

		switch choiceByte {
		case '1':
			Menu_STRING()
		case '0':
			fmt.Println("👋 Tạm biệt!")
			return
		default:
			fmt.Println("⚠️ Chức năng đang được phát triển. Vui lòng chọn lại.")
		}
	}
}
```

> 💡 **Lưu ý:** Biến `reader` được khai báo trong `string.go` ở cấp package `main`, nên `main.go` có thể dùng chung mà không cần khai báo lại.

## 10. Lỗi thường gặp

|Lỗi|Nguyên nhân|Cách xử lý|
|---|---|---|
|`NOAUTH Authentication required`|Chưa cung cấp mật khẩu|Kiểm tra `password` trong `config.yaml`|
|`connection refused`|Redis chưa chạy|Kiểm tra `docker ps`, khởi động lại container|
|`i/o timeout`|Timeout quá ngắn hoặc mạng chậm|Tăng giá trị `readTimeout`/`writeTimeout`|
|`key không tồn tại`|Key đã hết hạn hoặc chưa được set|Kiểm tra lại logic hoặc tăng thời gian hết hạn|
|`yaml: unmarshal errors`|Sai cú pháp trong `config.yaml`|Dùng YAML validator để kiểm tra file|

## Tóm tắt luồng hoạt động

```
main.go
  └─ InitRedis()         ← Đọc config.yaml → Tạo Redis Client → Ping kiểm tra
       └─ Rdb (global)   ← Dùng chung cho tất cả các hàm

  └─ Menu_STRING()
       ├─ SetKeyValue()  ← Rdb.Set(key, value, exp)
       ├─ GetKey()       ← Rdb.Get(key)
       └─ DeleteKey()    ← Rdb.Del(key)
```

---

> 📌 **Bước tiếp theo:** Thử tự cài thêm các chức năng cho **Hash**, **List**, **Set**, **Sorted Set** theo mô hình tương tự `string.go`. Mỗi kiểu dữ liệu Redis có lệnh riêng như `HSet`, `LPush`, `SAdd`, `ZAdd`.
