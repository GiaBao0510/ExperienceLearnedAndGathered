## Tổng quan kiến trúc

Dự án này áp dụng kiến trúc **Layered Architecture** (kiến trúc phân tầng), chia code thành các tầng độc lập, mỗi tầng chỉ làm một nhiệm vụ duy nhất:

```
HTTP Request
     ↓
┌──────────┐
│  Router  │  → Điều hướng request đến đúng handler
└──────────┘
     ↓
┌──────────┐
│  Handler │  → Đọc input, validate, trả về response
└──────────┘
     ↓
┌────────────┐
│ Repository │  → Thao tác CRUD với MongoDB
└────────────┘
     ↓
┌──────────┐
│  MongoDB │  → Lưu trữ dữ liệu
└──────────┘
```

**Tại sao phân tầng?**
- **Handler** không biết MongoDB tồn tại — chỉ gọi repository
- **Repository** không biết HTTP tồn tại — chỉ làm việc với DB
- Muốn đổi từ MongoDB sang PostgreSQL → chỉ cần sửa repository, handler không thay đổi

## Tầng Config — Kết nối MongoDB

Tạo file `config/mongodb.go`:

```go
package config

import (
    "context"
    "log"
    "os"
    "time"

    "go.mongodb.org/mongo-driver/mongo"
    "go.mongodb.org/mongo-driver/mongo/options"
)

// DB là biến toàn cục (package-level variable) lưu kết nối đến database.
// Được khởi tạo một lần trong ConnectDB(), dùng lại ở mọi nơi trong ứng dụng.
// Dùng *mongo.Database (con trỏ) để chia sẻ cùng một kết nối, tránh tạo nhiều kết nối.
var DB *mongo.Database

// ConnectDB thực hiện kết nối đến MongoDB.
// Được gọi một lần duy nhất khi server khởi động (trong main.go).
func ConnectDB() {

    // Đọc cấu hình từ biến môi trường (đã load từ .env)
    mongoURI := os.Getenv("MONGO_URI")
    dbName   := os.Getenv("MONGO_DB_NAME")

    if mongoURI == "" || dbName == "" {
        // log.Fatal in lỗi ra terminal và dừng chương trình ngay lập tức
        // Dùng khi gặp lỗi không thể tiếp tục chạy (thiếu cấu hình bắt buộc)
        log.Fatal("MONGO_URI and MONGO_DB_NAME environment variables are not set")
    }

    // context.WithTimeout tạo một "deadline" — nếu sau 10 giây vẫn chưa kết nối được
    // thì tự động hủy, không để chương trình bị treo vô thời hạn.
    // defer cancel() đảm bảo tài nguyên của context được giải phóng dù xảy ra lỗi hay không.
    ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
    defer cancel()

    // Tạo cấu hình kết nối từ URI
    clientOptions := options.Client().ApplyURI(mongoURI)

    // mongo.Connect() khởi tạo client nhưng CHƯA thực sự kết nối
    // Kết nối thực sự xảy ra lần đầu khi có thao tác với DB
    client, err := mongo.Connect(ctx, clientOptions)
    if err != nil {
        log.Fatal("Error connecting to MongoDB: ", err)
    }

    // client.Ping() gửi một lệnh thử đến MongoDB để kiểm tra kết nối thực sự hoạt động.
    // Cần thiết vì mongo.Connect() không báo lỗi ngay dù server không chạy.
    err = client.Ping(ctx, nil)
    if err != nil {
        log.Fatal("Error pinging MongoDB: ", err)
    }

    // Lấy database theo tên và gán vào biến toàn cục
    DB = client.Database(dbName)

    log.Println("Successfully connected to MongoDB!")
}

// GetCollection trả về một collection (tương đương "bảng" trong SQL) từ database.
// Được gọi trong Repository để lấy collection cần thao tác.
func GetCollection(collectionName string) *mongo.Collection {
    return DB.Collection(collectionName)
}
```

> 💡 **`context.Background()` là gì?** Đây là context gốc, không có deadline hay cancel. Ta wrap nó bằng `context.WithTimeout` để thêm giới hạn thời gian. Context được truyền qua tất cả các thao tác DB để Go có thể hủy chúng khi cần.

> 💡 **Tại sao `mongo.Connect()` không báo lỗi ngay khi server không chạy?** MongoDB driver dùng cơ chế lazy connection — kết nối thực sự chỉ thiết lập khi cần. Đó là lý do cần gọi thêm `client.Ping()` để xác nhận kết nối thực sự hoạt động ngay lúc khởi động server.

## Tầng Model — Định nghĩa dữ liệu

Tạo file `Model/student.go`:

```go
package model

import (
    "time"
    "go.mongodb.org/mongo-driver/bson/primitive"
)

// Student là struct đại diện cho một document trong collection "students" của MongoDB.
//
// Mỗi trường có hai loại tag:
//   json:"key"  → tên field khi serialize sang JSON (trả về cho client)
//   bson:"key"  → tên field khi lưu vào MongoDB
//
// Hai tên này có thể khác nhau: ví dụ ID trong Go là "id" (json) nhưng MongoDB lưu là "_id" (bson).
type Student struct {
    // primitive.ObjectID là kiểu ID chuẩn của MongoDB (12 bytes, dạng hex 24 ký tự)
    // omitempty trong bson: nếu ID là zero value → MongoDB tự tạo ID mới
    ID       primitive.ObjectID `json:"id"        bson:"_id,omitempty"`
    Name     string             `json:"name"      bson:"name"`
    Email    string             `json:"email"     bson:"email"`
    PhoneNum string             `json:"phoneNum"  bson:"phoneNum"`
    GPA      float64            `json:"gpa"       bson:"gpa"`
    CreatedAt time.Time         `json:"createdAt" bson:"createdAt"`
    UpdatedAt time.Time         `json:"updatedAt" bson:"updatedAt"`
}

// CreateStudentInput là struct nhận dữ liệu từ request body khi TẠO MỚI sinh viên.
// Tách riêng khỏi Student vì:
//   - Không cần ID (server tự tạo)
//   - Không cần CreatedAt/UpdatedAt (server tự set)
//   - Có thêm tag binding để validate dữ liệu đầu vào
type CreateStudentInput struct {
    Name     string  `json:"name"     binding:"required"`
    Email    string  `json:"email"    binding:"required,email"`
    PhoneNum string  `json:"phoneNum" binding:"required"`
    // min=0,max=4: GPA phải trong khoảng [0.0, 4.0]
    // Lưu ý: không có "required" → GPA là tùy chọn, mặc định là 0.0
    GPA      float64 `json:"gpa"      binding:"min=0,max=4"`
}

// UpdateStudentInput là struct nhận dữ liệu từ request body khi CẬP NHẬT sinh viên.
// Tất cả các trường đều tùy chọn (omitempty trong bson):
//   - Client chỉ cần gửi các trường muốn cập nhật
//   - Trường nào không gửi → giữ nguyên giá trị cũ trong DB
type UpdateStudentInput struct {
    Name     string `json:"name"     bson:"name,omitempty"`
    Email    string `json:"email"    bson:"email,omitempty"`
    PhoneNum string `json:"phoneNum" bson:"phoneNum,omitempty"`
}
```

> 💡 **Tại sao cần tách `CreateStudentInput` và `UpdateStudentInput` khỏi `Student`?**
> 
> - `Student` dùng để **ánh xạ dữ liệu từ MongoDB ra** — có đủ mọi trường kể cả ID, timestamps.
> - `CreateStudentInput` dùng để **nhận dữ liệu từ client** — client không được phép tự đặt ID hay thời gian tạo.
> - `UpdateStudentInput` dùng cho **partial update** — client chỉ gửi những gì muốn thay đổi, không cần gửi toàn bộ. Đây là pattern **DTO (Data Transfer Object)** phổ biến trong thiết kế API.

> 💡 **`bson:"name,omitempty"` trong UpdateStudentInput nghĩa là gì?** Khi dùng `$set` để update, nếu trường có giá trị rỗng (`""`) mà không có `omitempty`, MongoDB sẽ cập nhật trường đó thành `""`. Với `omitempty`, trường rỗng bị bỏ qua — MongoDB giữ nguyên giá trị cũ.

## Tầng Repository — Thao tác với Database

Tạo file `repositories/student_repo.go`:

```go
package repositories

import (
    "context"
    "errors"
    "time"

    model "golang-mongodb-crud/Model"
    "golang-mongodb-crud/config"

    "go.mongodb.org/mongo-driver/bson"
    "go.mongodb.org/mongo-driver/bson/primitive"
    "go.mongodb.org/mongo-driver/mongo"
    "go.mongodb.org/mongo-driver/mongo/options"
)

const CollectionName = "students"

// StudentRepository đóng gói tất cả thao tác với collection "students".
// Trường collection lưu tham chiếu đến collection MongoDB — không cần gọi GetCollection() mỗi lần.
type StudentRepository struct {
    collection *mongo.Collection
}

// NewStudentRepository là Constructor — khởi tạo repository với collection đã kết nối.
func NewStudentRepository() *StudentRepository {
    return &StudentRepository{
        collection: config.GetCollection(CollectionName),
    }
}

// ─────────────────────────────────────────────
// CREATE
// ─────────────────────────────────────────────

func (r *StudentRepository) Create(input model.Student) (*model.Student, error) {
    ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
    defer cancel()

    now := time.Now()
    student := model.Student{
        // primitive.NewObjectID() tạo một ObjectID mới hoàn toàn ngẫu nhiên.
        // MongoDB dùng ObjectID thay vì số nguyên auto-increment để đảm bảo
        // tính duy nhất ngay cả trong hệ thống phân tán nhiều server.
        ID:        primitive.NewObjectID(),
        Name:      input.Name,
        Email:     input.Email,
        PhoneNum:  input.PhoneNum,
        GPA:       input.GPA,
        CreatedAt: now,
        UpdatedAt: now,
    }

    // InsertOne() thêm một document vào collection.
    // Trả về InsertOneResult (chứa ID vừa insert) và error.
    // Ta bỏ qua InsertOneResult bằng _ vì đã có ID trong struct student.
    _, err := r.collection.InsertOne(ctx, student)
    if err != nil {
        return nil, err
    }

    return &student, nil
}

// ─────────────────────────────────────────────
// READ ALL
// ─────────────────────────────────────────────

func (r *StudentRepository) GetAll() ([]model.Student, error) {
    ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
    defer cancel()

    var students []model.Student

    // bson.M{} là filter rỗng — lấy tất cả document trong collection.
    // bson.M là map[string]interface{} — dùng để xây dựng filter, update, sort...
    cursor, err := r.collection.Find(ctx, bson.M{})
    if err != nil {
        return nil, err
    }
    // cursor giống như con trỏ duyệt qua kết quả — phải đóng sau khi dùng để giải phóng tài nguyên
    defer cursor.Close(ctx)

    // cursor.All() duyệt tất cả document và decode vào slice students
    if err = cursor.All(ctx, &students); err != nil {
        return nil, err
    }

    // Trả về slice rỗng thay vì nil.
    // Lý do: JSON marshal nil slice → null, nhưng empty slice → []
    // Client thường mong đợi [] thay vì null khi không có dữ liệu.
    if students == nil {
        students = []model.Student{}
    }

    return students, nil
}

// ─────────────────────────────────────────────
// READ BY ID
// ─────────────────────────────────────────────

func (r *StudentRepository) FindByID(id string) (*model.Student, error) {
    ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
    defer cancel()

    // ID từ URL là string (ví dụ: "69cbd9a10d38f6d365d47687")
    // MongoDB lưu ID dạng ObjectID (12 bytes) — phải chuyển đổi trước khi query
    objectID, err := primitive.ObjectIDFromHex(id)
    if err != nil {
        return nil, errors.New("ID không hợp lệ")
    }

    var student model.Student

    // Lưu ý: MongoDB lưu ID với tên "_id", không phải "id"
    // Phải dùng "_id" trong filter, không phải "id"
    filter := bson.M{"_id": objectID}

    // FindOne() tìm một document khớp filter và decode kết quả vào &student
    err = r.collection.FindOne(ctx, filter).Decode(&student)
    if err != nil {
        if err == mongo.ErrNoDocuments {
            // ErrNoDocuments: không tìm thấy document nào — trả lỗi có ý nghĩa
            return nil, errors.New("Không tìm thấy sinh viên với ID đã cho")
        }
        return nil, err
    }

    return &student, nil
}

// ─────────────────────────────────────────────
// UPDATE
// ─────────────────────────────────────────────

func (r *StudentRepository) Update(id string, input model.Student) (*model.Student, error) {
    ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
    defer cancel()

    objectID, err := primitive.ObjectIDFromHex(id)
    if err != nil {
        return nil, errors.New("ID không hợp lệ")
    }

    filter := bson.M{"_id": objectID}

    // $set là MongoDB update operator — chỉ cập nhật các trường được chỉ định,
    // các trường khác giữ nguyên. Nếu dùng replace thay vì $set, toàn bộ document
    // sẽ bị thay thế và mất các trường không được gửi.
    update := bson.M{
        "$set": bson.M{
            "name":      input.Name,
            "email":     input.Email,
            "phoneNum":  input.PhoneNum,
            "gpa":       input.GPA,
            "updatedAt": time.Now(), // Cập nhật thời gian sửa đổi
        },
    }

    // options.After: trả về document SAU KHI cập nhật (không phải trước).
    // Nếu dùng options.Before (mặc định): trả về giá trị cũ trước khi update.
    opts := options.FindOneAndUpdate().SetReturnDocument(options.After)

    var updatedStudent model.Student
    err = r.collection.FindOneAndUpdate(ctx, filter, update, opts).Decode(&updatedStudent)
    if err != nil {
        if err == mongo.ErrNoDocuments {
            return nil, errors.New("Không tìm thấy sinh viên với ID đã cho")
        }
        return nil, err
    }

    return &updatedStudent, nil
}

// ─────────────────────────────────────────────
// DELETE
// ─────────────────────────────────────────────

func (r *StudentRepository) Delete(id string) error {
    ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
    defer cancel()

    objectID, err := primitive.ObjectIDFromHex(id)
    if err != nil {
        return errors.New("ID không hợp lệ")
    }

    filter := bson.M{"_id": objectID}

    // DeleteOne() xóa document đầu tiên khớp filter.
    // Trả về DeleteResult.DeletedCount = số document đã xóa (0 hoặc 1).
    result, err := r.collection.DeleteOne(ctx, filter)
    if err != nil {
        return err
    }

    // DeletedCount == 0 nghĩa là không tìm thấy document để xóa
    // (ID đúng định dạng nhưng không tồn tại trong DB)
    if result.DeletedCount == 0 {
        return errors.New("Không tìm thấy sinh viên với ID đã cho")
    }

    return nil
}
```

### Bảng tóm tắt các lệnh MongoDB Driver

|Lệnh|Mô tả|Trả về|
|---|---|---|
|`InsertOne(ctx, doc)`|Thêm 1 document|`*InsertOneResult`, `error`|
|`Find(ctx, filter)`|Tìm nhiều document|`*Cursor`, `error`|
|`FindOne(ctx, filter)`|Tìm 1 document|`*SingleResult`|
|`FindOneAndUpdate(ctx, filter, update, opts)`|Tìm và cập nhật, trả về document|`*SingleResult`|
|`DeleteOne(ctx, filter)`|Xóa 1 document|`*DeleteResult`, `error`|
|`bson.M{}`|Filter rỗng — lấy tất cả|—|
|`bson.M{"_id": id}`|Filter theo ID|—|
|`bson.M{"$set": bson.M{...}}`|Chỉ cập nhật trường chỉ định|—|

## Tầng Handler — Xử lý HTTP Request

Tạo file `handlers/student_handler.go`:

```go
package handlers

import (
    "net/http"

    model "golang-mongodb-crud/Model"
    "golang-mongodb-crud/repositories"

    "github.com/gin-gonic/gin"
)

// StudentHandler kết nối tầng HTTP với tầng Repository.
// Không trực tiếp thao tác với DB — chỉ gọi các hàm của Repository.
type StudentHandler struct {
    repo *repositories.StudentRepository
}

// NewStudentHandler là Constructor — inject repository vào handler.
func NewStudentHandler() *StudentHandler {
    return &StudentHandler{
        repo: repositories.NewStudentRepository(),
    }
}

// POST /api/v1/students — Tạo mới sinh viên
func (h *StudentHandler) CreateStudent(c *gin.Context) {

    var input model.CreateStudentInput

    if err := c.ShouldBindJSON(&input); err != nil {
        c.JSON(http.StatusBadRequest, gin.H{
            "status":  "false",
            "message": "Dữ liệu không hợp lệ: " + err.Error(),
        })
        return
    }

    // Chuyển CreateStudentInput → model.Student để truyền vào Repository
    studentData := model.Student{
        Name:     input.Name,
        Email:    input.Email,
        PhoneNum: input.PhoneNum,
        GPA:      input.GPA,
    }

    student, err := h.repo.Create(studentData)
    if err != nil {
        c.JSON(http.StatusInternalServerError, gin.H{
            "status":  "false",
            "message": "Lỗi khi tạo student: " + err.Error(),
        })
        return
    }

    // 201 Created — HTTP status code chuẩn khi tạo mới tài nguyên thành công
    c.JSON(http.StatusCreated, gin.H{
        "status":  "true",
        "message": "Student created successfully",
        "data":    student,
    })
}

// GET /api/v1/students — Lấy tất cả sinh viên
func (h *StudentHandler) GetAll(c *gin.Context) {

    students, err := h.repo.GetAll()
    if err != nil {
        c.JSON(http.StatusInternalServerError, gin.H{
            "status":  "false",
            "message": "Lỗi khi lấy danh sách student: " + err.Error(),
        })
        return // Quan trọng: phải có return để dừng xử lý sau khi trả lỗi
    }

    c.JSON(http.StatusOK, gin.H{
        "status":  "true",
        "message": "Danh sách student retrieved successfully",
        "data":    students,
    })
}

// GET /api/v1/students/:id — Lấy sinh viên theo ID
func (h *StudentHandler) GetByID(c *gin.Context) {

    id := c.Param("id")
    student, err := h.repo.FindByID(id)

    if err != nil {
        // Phân biệt lỗi "không tìm thấy" (404) với lỗi hệ thống (500)
        status := http.StatusInternalServerError
        if err.Error() == "Không tìm thấy sinh viên với ID đã cho" ||
            err.Error() == "ID không hợp lệ" {
            status = http.StatusNotFound
        }
        c.JSON(status, gin.H{
            "status":  "false",
            "message": err.Error(),
        })
        return
    }

    c.JSON(http.StatusOK, gin.H{
        "status":  "true",
        "message": "Student retrieved successfully",
        "data":    student,
    })
}

// PUT /api/v1/students/:id — Cập nhật sinh viên theo ID
func (h *StudentHandler) UpdateStudent(c *gin.Context) {

    id := c.Param("id")

    var input model.UpdateStudentInput
    if err := c.ShouldBindJSON(&input); err != nil {
        c.JSON(http.StatusBadRequest, gin.H{
            "status":  "false",
            "message": "Dữ liệu không hợp lệ: " + err.Error(),
        })
        return
    }

    // Chuyển UpdateStudentInput → model.Student
    studentData := model.Student{
        Name:     input.Name,
        Email:    input.Email,
        PhoneNum: input.PhoneNum,
    }

    student, err := h.repo.Update(id, studentData)
    if err != nil {
        status := http.StatusInternalServerError
        if err.Error() == "Không tìm thấy sinh viên với ID đã cho" ||
            err.Error() == "ID không hợp lệ" {
            status = http.StatusNotFound
        }
        c.JSON(status, gin.H{
            "status":  "false",
            "message": err.Error(),
        })
        return
    }

    c.JSON(http.StatusOK, gin.H{
        "status":  "true",
        "message": "Student updated successfully",
        "data":    student,
    })
}

// DELETE /api/v1/students/:id — Xóa sinh viên theo ID
func (h *StudentHandler) DeleteStudent(c *gin.Context) {

    id := c.Param("id")
    err := h.repo.Delete(id)

    if err != nil {
        status := http.StatusInternalServerError
        if err.Error() == "Không tìm thấy sinh viên với ID đã cho" ||
            err.Error() == "ID không hợp lệ" {
            status = http.StatusNotFound
        }
        c.JSON(status, gin.H{
            "status":  "false",
            "message": err.Error(),
        })
        return // Phải có return để dừng xử lý
    }

    c.JSON(http.StatusOK, gin.H{
        "status":  "true",
        "message": "Student deleted successfully",
    })
}
```

|`201 Created`|Tạo mới thành công|POST thành công|

## Tầng Router — Đăng ký Routes

Tạo file `routers/routers.go`:

```go
package routers

import (
    "golang-mongodb-crud/handlers"

    "github.com/gin-gonic/gin"
)

// SetupRouter đăng ký tất cả API routes vào Gin engine.
// Tập trung tất cả route vào một nơi — dễ xem tổng quan API có gì.
func SetupRouter(router *gin.Engine) {

    studentHandler := handlers.NewStudentHandler()

    api := router.Group("/api/v1")
    {
        students := api.Group("/students")
        {
            students.POST("",      studentHandler.CreateStudent)  // Tạo mới
            students.GET("",       studentHandler.GetAll)          // Lấy tất cả
            students.GET("/:id",   studentHandler.GetByID)         // Lấy theo ID
            students.PUT("/:id",   studentHandler.UpdateStudent)   // Cập nhật theo ID
            students.DELETE("/:id", studentHandler.DeleteStudent)  // Xóa theo ID
        }
    }
}
```

## Entry Point — `main.go`

Tạo file `main.go` ở thư mục gốc:

```go
package main

import (
    "log"
    "os"

    "golang-mongodb-crud/config"
    "golang-mongodb-crud/routers"

    "github.com/gin-gonic/gin"
    "github.com/joho/godotenv"
)

func main() {

    // Bước 1: Load biến môi trường từ file .env
    // Phải làm TRƯỚC mọi thứ khác vì các bước sau cần đọc biến môi trường
    if err := godotenv.Load(); err != nil {
        log.Fatal("Error loading .env file")
    }

    // Bước 2: Kết nối MongoDB
    // Phải làm trước khi khởi tạo handler/repository (chúng cần DB đã kết nối)
    config.ConnectDB()

    // Bước 3: Tạo Gin router
    // gin.Default() tự thêm 2 middleware quan trọng:
    //   - Logger: in log mỗi request ra terminal (method, path, status, thời gian xử lý)
    //   - Recovery: bắt panic và trả về 500 thay vì crash toàn bộ server
    router := gin.Default()

    // Bước 4: Đăng ký tất cả routes
    routers.SetupRouter(router)

    // Bước 5: Lấy port từ biến môi trường, mặc định 8080
    port := os.Getenv("PORT")
    if port == "" {
        port = "8080"
    }

    // Bước 6: Khởi động server
    log.Println("Server is running on port " + port)
    if err := router.Run(":" + port); err != nil {
        log.Fatal("Failed to run server: ", err)
    }
    // Lưu ý: log.Println phía trên in trước router.Run() vì router.Run() là blocking —
    // nó chạy mãi cho đến khi server dừng, không bao giờ return bình thường.
}
```

> ⚠️ **Thứ tự khởi động quan trọng:** Load `.env` → Kết nối DB → Tạo router → Đăng ký routes → Chạy server. Nếu đảo thứ tự (ví dụ tạo handler trước khi connect DB), sẽ bị lỗi vì `config.DB` chưa được khởi tạo.

## Tổng kết

### Luồng dữ liệu hoàn chỉnh (ví dụ CREATE)

```
Client gửi POST /api/v1/students
        ↓
Router → studentHandler.CreateStudent()
        ↓
Handler: ShouldBindJSON() → validate input
        ↓
Handler: repo.Create(studentData)
        ↓
Repository: primitive.NewObjectID() → tạo ID
Repository: collection.InsertOne() → lưu vào MongoDB
        ↓
Handler: c.JSON(201, gin.H{...})
        ↓
Client nhận response
```

### Các khái niệm quan trọng trong bài

|Khái niệm|Ý nghĩa|
|---|---|
|`primitive.ObjectID`|Kiểu ID chuẩn của MongoDB, 12 bytes, dạng hex 24 ký tự|
|`bson.M{}`|Map để xây dựng filter/update cho MongoDB|
|`$set` operator|Chỉ cập nhật trường chỉ định, giữ nguyên trường còn lại|
|`context.WithTimeout`|Đặt deadline cho thao tác DB, tránh treo vô thời hạn|
|`cursor`|Con trỏ duyệt kết quả từ `Find()`, cần `defer cursor.Close()`|
|`mongo.ErrNoDocuments`|Lỗi khi `FindOne()` không tìm thấy document nào|
|`omitempty` (bson)|Bỏ qua trường khi giá trị là zero value — dùng cho partial update|
|`options.After`|Trả về document sau khi update (không phải trước)|
|Layered Architecture|Tách code thành các tầng độc lập: Handler → Repository → DB|
|DTO Pattern|Dùng struct riêng cho input (CreateInput, UpdateInput) khác với struct DB (Student)|

### Những lỗi thường gặp cần lưu ý

1. **Thiếu `return` sau `c.JSON` trả lỗi** — chương trình tiếp tục chạy và gọi `c.JSON` lần thứ hai.
2. **Dùng `"id"` thay vì `"_id"` trong bson filter** — MongoDB lưu ID với tên `_id`, filter `{"id": ...}` sẽ không tìm thấy gì.
3. **Không gọi `defer cursor.Close(ctx)`** — cursor không được đóng, rò rỉ tài nguyên.
4. **Thứ tự khởi động sai trong `main.go`** — Load `.env` và `ConnectDB()` phải đứng trước khi tạo handler.
5. **`mongo.Connect()` không báo lỗi ngay** — luôn gọi `client.Ping()` sau để xác nhận kết nối thực sự thành công.
