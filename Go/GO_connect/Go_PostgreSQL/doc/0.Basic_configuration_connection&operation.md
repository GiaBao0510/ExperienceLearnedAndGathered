## 1. Khởi tạo dự án

Mở terminal, tạo thư mục và khởi tạo Go module:

```bash
mkdir Go_PostgreSQL
cd Go_PostgreSQL
go mod init go-postgresql
go mod tidy
```

Tải thư viện driver PostgreSQL cho Go (`lib/pq`):

```bash
go get github.com/lib/pq
```

> **`lib/pq` là gì?**  
> Đây là thư viện driver cho phép Go giao tiếp với PostgreSQL thông qua interface chuẩn `database/sql` của Go. Dấu `_` khi import (`_ "github.com/lib/pq"`) có nghĩa là chỉ cần load driver, không dùng trực tiếp.

## 2. Kết nối PostgreSQL đơn giản

Tạo file `main.go` để kiểm tra kết nối:

```go
package main

import (
    "database/sql"
    "log"
    _ "github.com/lib/pq"
)

func main() {
    // Chuỗi kết nối (Connection String)
    connStr := "host=localhost port=5432 user=admin password=admin123 dbname=test sslmode=disable"

    // Mở kết nối - lưu ý: sql.Open() chưa thực sự kết nối ngay
    pgDB, err := sql.Open("postgres", connStr)
    if err != nil {
        log.Fatal("Lỗi cấu hình kết nối: ", err)
    }
    defer pgDB.Close()

    // Ping() mới thực sự kiểm tra kết nối đến CSDL
    err = pgDB.Ping()
    if err != nil {
        log.Fatal("Không thể kết nối đến CSDL: ", err)
    }

    log.Println("Kết nối PostgreSQL thành công!")
}
```

**Kết quả chạy thử:**


### Giải thích các tham số trong Connection String

|Tham số|Ý nghĩa|Ví dụ|
|---|---|---|
|`host`|Địa chỉ máy chủ PostgreSQL|`localhost` hoặc IP|
|`port`|Cổng kết nối (mặc định PostgreSQL)|`5432`|
|`user`|Tên người dùng CSDL|`admin`|
|`password`|Mật khẩu|`admin123`|
|`dbname`|Tên database cần kết nối|`test`|
|`sslmode`|Chế độ mã hoá SSL|`disable` (tắt SSL ở môi trường dev)|

> ⚠️ **Lưu ý:** `sql.Open()` chỉ **chuẩn bị** cấu hình kết nối, chưa thực sự mở kết nối.  
> Phải gọi `pgDB.Ping()` hoặc thực hiện truy vấn để kết nối thật sự được thiết lập.

## 3. Chuẩn bị CSDL - Tạo bảng users

Trước khi code, cần tạo bảng `users` trong PostgreSQL. Chạy câu lệnh SQL sau trong pgAdmin hoặc `psql`:

```sql
-- Tạo user và cấp quyền (nếu chưa có)
CREATE USER admin WITH PASSWORD 'admin123';
GRANT ALL PRIVILEGES ON DATABASE test TO admin;

-- Tạo bảng users
CREATE TABLE IF NOT EXISTS users (
    id         SERIAL PRIMARY KEY,           -- Tự động tăng
    username   VARCHAR(50)  NOT NULL UNIQUE, -- Tên đăng nhập, không trùng
    email      VARCHAR(100) NOT NULL UNIQUE, -- Email, không trùng
    password   VARCHAR(255) NOT NULL,        -- Mật khẩu
    full_name  VARCHAR(100),                 -- Họ tên đầy đủ
    created_at TIMESTAMP DEFAULT NOW()       -- Thời gian tạo, tự điền
);
```

> **`SERIAL`** là kiểu dữ liệu tự tăng (auto increment) trong PostgreSQL, tương đương `AUTO_INCREMENT` trong MySQL.

## 5. Tách module kết nối

Tạo file `database/connection.go`:

```go
package database

import (
    "database/sql"
    "log"
    _ "github.com/lib/pq"
)

// InitDB khởi tạo và trả về kết nối đến PostgreSQL
// Chương trình sẽ dừng ngay (log.Fatal) nếu không kết nối được
func InitDB() *sql.DB {

    connStr := "host=localhost port=5432 user=admin password=admin123 dbname=test sslmode=disable"

    pgDB, err := sql.Open("postgres", connStr)
    if err != nil {
        log.Fatal("Lỗi cấu hình kết nối: ", err)
    }

    err = pgDB.Ping()
    if err != nil {
        log.Fatal("Lỗi kết nối đến cơ sở dữ liệu: ", err)
    }

    log.Println("Kết nối PostgreSQL thành công!")
    return pgDB
}
```

> **Tại sao dùng `log.Fatal` thay vì `return nil`?**  
> Nếu không có kết nối DB, chương trình không thể hoạt động được. `log.Fatal` in ra lỗi và dừng chương trình ngay lập tức — hành vi phù hợp hơn là để chương trình chạy tiếp với DB bị `nil`.

## 6. Các hàm tương tác CSDL quan trọng

Gói `database/sql` cung cấp 3 hàm chính để thao tác với CSDL. Đây là điểm quan trọng bạn cần nắm rõ:

---

### `db.Exec()` — Thực thi câu lệnh không cần đọc dữ liệu về

Dùng cho: `INSERT`, `UPDATE`, `DELETE`

```go
result, err := db.Exec(
    "INSERT INTO users (username, email) VALUES ($1, $2)",
    "giabao", "giabao@email.com",
)

// Có thể lấy thêm thông tin từ result (không bắt buộc)
rowsAffected, _ := result.RowsAffected() // Số dòng bị ảnh hưởng
lastInsertId, _ := result.LastInsertId()  // ID vừa được insert (không dùng được trong PostgreSQL, dùng RETURNING thay thế)
```

---

### `db.Query()` — Truy vấn trả về nhiều dòng

Dùng cho: `SELECT` nhiều dòng dữ liệu

```go
rows, err := db.Query("SELECT id, username, email FROM users")
if err != nil {
    log.Println("Lỗi truy vấn: ", err)
    return
}
defer rows.Close() // ⚠️ Luôn phải đóng rows sau khi dùng xong!

for rows.Next() {
    var id int
    var username, email string

    err := rows.Scan(&id, &username, &email) // Đọc từng cột vào biến
    if err != nil {
        log.Println(err)
        continue
    }
    fmt.Printf("ID: %d, User: %s, Email: %s\n", id, username, email)
}
```

> ⚠️ **Quan trọng:** Phải gọi `rows.Close()` để giải phóng tài nguyên. Dùng `defer rows.Close()` ngay sau khi kiểm tra lỗi là thói quen tốt.

---

### `db.QueryRow()` — Truy vấn trả về đúng 1 dòng

Dùng cho: `SELECT` theo `id` hoặc các trường hợp chỉ cần 1 kết quả

```go
var user User
err := db.QueryRow(
    "SELECT id, username, email FROM users WHERE id = $1", 5,
).Scan(&user.ID, &user.Username, &user.Email)

if err == sql.ErrNoRows {
    fmt.Println("Không tìm thấy người dùng")
} else if err != nil {
    log.Println("Lỗi truy vấn: ", err)
}
```

> `db.QueryRow()` không trả về `error` ngay — lỗi chỉ xuất hiện khi bạn gọi `.Scan()`. Nếu không có dòng nào khớp, `.Scan()` trả về lỗi `sql.ErrNoRows`.

---

### Tổng kết: khi nào dùng hàm nào?

|Hàm|Dùng khi|Trả về|
|---|---|---|
|`db.Exec()`|INSERT, UPDATE, DELETE|`sql.Result`, `error`|
|`db.Query()`|SELECT nhiều dòng|`*sql.Rows`, `error`|
|`db.QueryRow()`|SELECT đúng 1 dòng|`*sql.Row` (lỗi lấy qua `.Scan()`)|

---

### Tham số `$1`, `$2`, `$3`... là gì?

Đây là **parameterized query** (truy vấn tham số hóa) — cách an toàn để truyền dữ liệu vào câu SQL:

```go
// ❌ KHÔNG làm thế này (dễ bị SQL Injection)
query := "SELECT * FROM users WHERE username = '" + username + "'"

// ✅ Luôn dùng tham số $1, $2...
query := "SELECT * FROM users WHERE username = $1"
db.QueryRow(query, username)
```

> PostgreSQL dùng `$1, $2, $3...` (MySQL dùng `?`). Thứ tự tham số tương ứng với thứ tự biến truyền vào sau chuỗi query.

## 7. Repository - Thao tác với bảng users

Tạo file `repository/user.go`:

```go
package repository

import (
    "database/sql"
    "log"
    "time"
    _ "github.com/lib/pq"
)

// User ánh xạ với cấu trúc bảng "users" trong PostgreSQL
type User struct {
    ID        int       `db:"id"`
    Username  string    `db:"username"`
    Email     string    `db:"email"`
    Password  string    `db:"password"`
    FullName  string    `db:"full_name"`
    CreatedAt time.Time `db:"created_at"`
}

// InsertUser thêm một người dùng mới vào CSDL
func InsertUser(user User, db *sql.DB) error {
    query := `INSERT INTO users (username, email, password, full_name) 
              VALUES ($1, $2, $3, $4)`

    _, err := db.Exec(query, user.Username, user.Email, user.Password, user.FullName)
    if err != nil {
        log.Println("Lỗi khi thêm người dùng: ", err)
        return err
    }

    log.Println("Thêm người dùng thành công!")
    return nil
}

// ListUsers lấy danh sách tất cả người dùng từ CSDL
func ListUsers(db *sql.DB) ([]User, error) {
    query := `SELECT id, username, email, password, full_name, created_at FROM users`

    rows, err := db.Query(query)
    if err != nil {
        log.Println("Lỗi khi truy vấn danh sách người dùng: ", err)
        return nil, err
    }
    defer rows.Close()

    var users []User
    for rows.Next() {
        var user User
        err := rows.Scan(
            &user.ID, &user.Username, &user.Email,
            &user.Password, &user.FullName, &user.CreatedAt,
        )
        if err != nil {
            log.Println("Lỗi khi đọc dữ liệu: ", err)
            continue
        }
        users = append(users, user)
    }

    return users, nil
}

// GetUserByID lấy thông tin người dùng theo ID
func GetUserByID(id string, db *sql.DB) (User, error) {
    query := `SELECT id, username, email, password, full_name, created_at 
              FROM users WHERE id = $1`

    var user User
    err := db.QueryRow(query, id).Scan(
        &user.ID, &user.Username, &user.Email,
        &user.Password, &user.FullName, &user.CreatedAt,
    )

    if err == sql.ErrNoRows {
        log.Println("Không tìm thấy người dùng với ID: ", id)
        return User{}, err
    } else if err != nil {
        log.Println("Lỗi khi lấy người dùng theo ID: ", err)
        return User{}, err
    }

    return user, nil
}

// UpdateUserByID cập nhật thông tin người dùng theo ID
func UpdateUserByID(id string, user User, db *sql.DB) error {
    query := `UPDATE users 
              SET username = $1, email = $2, password = $3, full_name = $4 
              WHERE id = $5`

    _, err := db.Exec(query, user.Username, user.Email, user.Password, user.FullName, id)
    if err != nil {
        log.Println("Lỗi khi cập nhật người dùng: ", err)
        return err
    }

    log.Println("Cập nhật người dùng thành công!")
    return nil
}

// DeleteUserByID xoá người dùng theo ID
func DeleteUserByID(id string, db *sql.DB) error {
    query := `DELETE FROM users WHERE id = $1`

    _, err := db.Exec(query, id)
    if err != nil {
        log.Println("Lỗi khi xóa người dùng: ", err)
        return err
    }

    log.Println("Xóa người dùng thành công!")
    return nil
}
```

> **Tag `db:"..."` trong struct có tác dụng gì?**  
> Đây là **struct tag** — chú thích ánh xạ tên field Go với tên cột trong DB. Gói `lib/pq` không tự dùng tag này (cần thư viện như `sqlx` để tự động ánh xạ), nhưng giữ lại để tài liệu hóa cấu trúc và dễ dùng sau này nếu nâng cấp.

## 8. Chương trình chính main.go

Tạo file `main.go`:

```go
package main

import (
    "bufio"
    "fmt"
    "go-postgresql/database"
    "go-postgresql/repository"
    "log"
    "os"

    _ "github.com/lib/pq"
)

func main() {

    // Khởi tạo kết nối DB
    db := database.InitDB()
    defer db.Close()

    scanner := bufio.NewScanner(os.Stdin)

    // Vòng lặp menu chính
    for {
        fmt.Println("\n\t\t===== MENU =====")
        fmt.Println("1. Hiển thị danh sách người dùng")
        fmt.Println("2. Thêm người dùng")
        fmt.Println("3. Sửa thông tin người dùng")
        fmt.Println("4. Xóa người dùng")
        fmt.Println("0. Thoát")
        fmt.Print("Chọn chức năng: ")

        scanner.Scan()
        choice := scanner.Text()

        switch choice {
        case "1":
            fmt.Println("\n--- Danh sách người dùng ---")
            users, err := repository.ListUsers(db)
            if err != nil {
                log.Println("Lỗi:", err)
                continue
            }
            if len(users) == 0 {
                fmt.Println("Chưa có người dùng nào.")
                continue
            }
            for _, user := range users {
                fmt.Printf("ID: %d | Username: %s | Email: %s | Full Name: %s | Ngày tạo: %s\n",
                    user.ID, user.Username, user.Email, user.FullName,
                    user.CreatedAt.Format("2006-01-02 15:04:05"))
            }

        case "2":
            fmt.Println("\n--- Thêm người dùng ---")
            var user repository.User
            fmt.Print("Username: ")
            fmt.Scanln(&user.Username)
            fmt.Print("Email: ")
            fmt.Scanln(&user.Email)
            fmt.Print("Password: ")
            fmt.Scanln(&user.Password)
            fmt.Print("Full name: ")
            fmt.Scanln(&user.FullName)

            if err := repository.InsertUser(user, db); err != nil {
                log.Println("Lỗi:", err)
            } else {
                fmt.Println("✓ Thêm thành công!")
            }

        case "3":
            fmt.Println("\n--- Sửa thông tin người dùng ---")
            fmt.Print("Nhập ID người dùng cần sửa: ")
            var id string
            fmt.Scanln(&id)

            user, err := repository.GetUserByID(id, db)
            if err != nil {
                log.Println("Lỗi:", err)
                continue
            }

            fmt.Printf("Thông tin hiện tại: Username=%s | Email=%s | Full Name=%s\n",
                user.Username, user.Email, user.FullName)
            fmt.Println("(Nhập thông tin mới, Enter để giữ nguyên không được hỗ trợ trong ví dụ này)")

            fmt.Print("Username mới: ")
            fmt.Scanln(&user.Username)
            fmt.Print("Email mới: ")
            fmt.Scanln(&user.Email)
            fmt.Print("Password mới: ")
            fmt.Scanln(&user.Password)
            fmt.Print("Full name mới: ")
            fmt.Scanln(&user.FullName)

            if err := repository.UpdateUserByID(id, user, db); err != nil {
                log.Println("Lỗi:", err)
            } else {
                fmt.Println("✓ Cập nhật thành công!")
            }

        case "4":
            fmt.Println("\n--- Xóa người dùng ---")
            fmt.Print("Nhập ID người dùng cần xóa: ")
            var id string
            fmt.Scanln(&id)

            if err := repository.DeleteUserByID(id, db); err != nil {
                log.Println("Lỗi:", err)
            } else {
                fmt.Println("✓ Xóa thành công!")
            }

        case "0":
            fmt.Println("Tạm biệt!")
            return

        default:
            fmt.Println("⚠ Lựa chọn không hợp lệ. Vui lòng thử lại.")
        }
    }
}
```

> **Tại sao dùng `bufio.NewScanner` thay vì `fmt.Scan`?**  
> `fmt.Scanln` bị lỗi khi đọc chuỗi có khoảng trắng (ví dụ: `Nguyen Gia Bao` sẽ bị cắt). `bufio.Scanner` đọc cả dòng nên phù hợp hơn cho input từ người dùng.
