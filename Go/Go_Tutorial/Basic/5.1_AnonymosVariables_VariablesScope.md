## 1. Anonymous Variables (Blank Identifier)

### 1.1. Blank Identifier là gì?

**Blank Identifier** (ký hiệu `_`) là một biến đặc biệt trong Go, được dùng để **bỏ qua** giá trị không cần thiết.

**Đặc điểm:**

- ✅ Không chiếm bộ nhớ
- ✅ Không thể đọc lại giá trị
- ✅ Dùng để bỏ qua return values
- ✅ Dùng để import package không sử dụng

### 1.2. Tại sao cần Blank Identifier?

**Vấn đề:** Go bắt buộc phải sử dụng tất cả biến đã khai báo.

```go
package main

import "fmt"

func GetValue() (int, int) {
    return 100, 150
}

func main() {
    a, b := GetValue()
    fmt.Println(a)
    // ❌ Compile error: b declared but not used
}
```

**Giải pháp:** Dùng `_` để bỏ qua giá trị không cần.

```go
func main() {
    a, _ := GetValue()  // Bỏ qua giá trị thứ 2
    fmt.Println(a)      // OK
}
```

### 1.3. Các cách sử dụng

#### **Use Case 1: Bỏ qua một số return values**

```go
package main

import "fmt"

func GetValue() (int, int) {
    return 100, 150
}

func main() {
    // Lấy cả 2 giá trị
    a, b := GetValue()
    fmt.Println("a:", a)  // 100
    fmt.Println("b:", b)  // 150
    
    // Chỉ lấy giá trị thứ 2
    _, c := GetValue()
    fmt.Println("c:", c)  // 150
    
    // Chỉ lấy giá trị thứ 1
    d, _ := GetValue()
    fmt.Println("d:", d)  // 100
}
```

**Output:**

```
a: 100
b: 150
c: 150
d: 100
```

#### **Use Case 2: Bỏ qua error (⚠️ Không khuyến nghị)**

```go
package main

import (
    "fmt"
    "strconv"
)

func main() {
    // ❌ Không khuyến nghị - Bỏ qua error
    num, _ := strconv.Atoi("123")
    fmt.Println(num)
    
    // ✅ Nên xử lý error
    num2, err := strconv.Atoi("abc")
    if err != nil {
        fmt.Println("Error:", err)
        return
    }
    fmt.Println(num2)
}
```

#### **Use Case 3: Iterate mà không cần index**

```go
package main

import "fmt"

func main() {
    fruits := []string{"Apple", "Banana", "Orange"}
    
    // Bỏ qua index, chỉ lấy value
    for _, fruit := range fruits {
        fmt.Println(fruit)
    }
}
```

**Output:**

```
Apple
Banana
Orange
```

#### **Use Case 4: Iterate mà không cần value**

```go
package main

import "fmt"

func main() {
    fruits := []string{"Apple", "Banana", "Orange"}
    
    // Chỉ lấy index, bỏ qua value
    for i, _ := range fruits {
        fmt.Printf("Index: %d\n", i)
    }
    
    // Hoặc ngắn gọn hơn
    for i := range fruits {
        fmt.Printf("Index: %d\n", i)
    }
}
```

#### **Use Case 5: Check type assertion**

```go
package main

import "fmt"

func main() {
    var val interface{} = "Hello"
    
    // Chỉ check type, không cần value
    if _, ok := val.(string); ok {
        fmt.Println("val is string")
    }
}
```

#### **Use Case 6: Import package chỉ để chạy init()**

```go
package main

import (
    "fmt"
    _ "database/sql/driver"  // Chỉ chạy init(), không dùng
)

func main() {
    fmt.Println("Program started")
}
```

### 1.4. Ví dụ thực tế

**Ví dụ: Đọc file**

```go
package main

import (
    "fmt"
    "os"
)

func main() {
    // Bỏ qua số bytes đã đọc
    data := make([]byte, 100)
    _, err := os.Stdin.Read(data)
    if err != nil {
        fmt.Println("Error:", err)
        return
    }
    
    fmt.Println("Data:", string(data))
}
```

**Ví dụ: Database query**

```go
package main

import (
    "database/sql"
    "fmt"
)

func main() {
    db, err := sql.Open("mysql", "user:pass@/dbname")
    if err != nil {
        panic(err)
    }
    
    var name string
    var age int
    
    // Bỏ qua ID column
    err = db.QueryRow("SELECT id, name, age FROM users WHERE id = ?", 1).
        Scan(&_, &name, &age)  // Bỏ qua id
    
    if err != nil {
        fmt.Println("Error:", err)
        return
    }
    
    fmt.Printf("Name: %s, Age: %d\n", name, age)
}
```

## 2. Variable Scope

### 2.1. Scope là gì?

**Scope** (phạm vi) là vùng code mà biến có thể được truy cập.

**3 loại scope trong Go:**

```
┌─────────────────────────────────────┐
│ Package Scope (toàn bộ package)    │
│  ┌──────────────────────────────┐  │
│  │ Function Scope (trong hàm)   │  │
│  │  ┌───────────────────────┐   │  │
│  │  │ Block Scope (trong {})│   │  │
│  │  └───────────────────────┘   │  │
│  └──────────────────────────────┘  │
└─────────────────────────────────────┘
```

### 2.2. Quy tắc Scope

**Quy tắc 1:** Biến chỉ truy cập được trong scope của nó và các scope con.

**Quy tắc 2:** Inner scope có thể "che" (shadow) outer scope.

**Quy tắc 3:** Go bắt buộc phải sử dụng biến đã khai báo (trừ package-level).

## 3. Local Variables

### 3.1. Local Variable là gì?

**Local Variable** là biến được khai báo **bên trong function** hoặc **block**.

**Đặc điểm:**

- ✅ Chỉ tồn tại khi function/block được thực thi
- ✅ Bị hủy khi function/block kết thúc
- ✅ Không thể truy cập từ bên ngoài
- ✅ Phải được sử dụng (nếu không → compile error)

### 3.2. Ví dụ cơ bản

```go
package main

import "fmt"

func GetValue() int {
    a := 100  // Local variable
    b := 150  // Local variable
    return a + b
}

func main() {
    c := GetValue()  // c = 250
    fmt.Println("The value is", c)
    
    // ❌ Không thể truy cập a, b ở đây
    // fmt.Println(a)  // Compile error: undefined: a
}
```

**Output:**

```
The value is 250
```

### 3.3. Function Parameters cũng là Local

```go
package main

import "fmt"

func Add(x, y int) int {  // x, y là local variables
    sum := x + y          // sum cũng là local
    return sum
}

func main() {
    result := Add(10, 20)
    fmt.Println("Result:", result)
    
    // ❌ Không thể truy cập x, y, sum
    // fmt.Println(x)  // Compile error
}
```

### 3.4. Block Scope

```go
package main

import "fmt"

func main() {
    x := 10  // Function scope
    
    if x > 5 {
        y := 20  // Block scope - chỉ trong if
        fmt.Println("x:", x)  // OK
        fmt.Println("y:", y)  // OK
    }
    
    fmt.Println("x:", x)  // OK
    // fmt.Println("y:", y)  // ❌ Error: y không tồn tại
}
```

### 3.5. Loop Scope

```go
package main

import "fmt"

func main() {
    for i := 0; i < 3; i++ {  // i chỉ tồn tại trong loop
        fmt.Println("i:", i)
    }
    
    // ❌ Không thể truy cập i
    // fmt.Println(i)  // Compile error
}
```

**Common mistake:**

```go
package main

import "fmt"

func main() {
    for i := 0; i < 3; i++ {
        // OK
    }
    
    // ❌ Lỗi - i không tồn tại
    // for j := i; j < 5; j++ { }
    
    // ✅ Đúng - Khai báo i bên ngoài
    var i int
    for i = 0; i < 3; i++ {
        // ...
    }
    
    // OK - i vẫn tồn tại
    for j := i; j < 5; j++ {
        fmt.Println(j)
    }
}
```

## 4. Global Variables

### 4.1. Global Variable là gì?

**Global Variable** (hay Package-level variable) là biến được khai báo **bên ngoài function**.

**Đặc điểm:**

- ✅ Truy cập được từ mọi function trong package
- ✅ Tồn tại suốt thời gian chạy chương trình
- ✅ Không bắt buộc phải sử dụng (khác local)
- ✅ Khởi tạo với zero value nếu không gán giá trị

### 4.2. Ví dụ cơ bản

```go
package main

import "fmt"

var d = 300  // Global variable

func main() {
    fmt.Println("The value is", d)
}
```

**Output:**

```
The value is 300
```

### 4.3. Global vs Local

```go
package main

import "fmt"

var globalVar = 100  // Global

func Function1() {
    fmt.Println("Function1:", globalVar)  // OK
}

func Function2() {
    fmt.Println("Function2:", globalVar)  // OK
}

func main() {
    localVar := 200  // Local
    
    Function1()  // 100
    Function2()  // 100
    
    fmt.Println("Main:", globalVar)   // 100
    fmt.Println("Main:", localVar)    // 200
}
```

**Output:**

```
Function1: 100
Function2: 100
Main: 100
Main: 200
```

### 4.4. Multiple Global Variables

```go
package main

import "fmt"

var (
    name    = "John"
    age     = 25
    isAdmin = true
)

func main() {
    fmt.Printf("Name: %s, Age: %d, Admin: %v\n", name, age, isAdmin)
}
```

**Output:**

```
Name: John, Age: 25, Admin: true
```

## 5. Package-level Variables

### 5.1. Exported vs Unexported

**Quy tắc:**

- Uppercase đầu → Exported (public)
- Lowercase đầu → Unexported (private)

**File: mypackage/vars.go**

```go
package mypackage

var PublicVar = 100   // Exported - Truy cập được từ package khác
var privateVar = 200  // Unexported - Chỉ trong package này
```

**File: main.go**

```go
package main

import (
    "fmt"
    "mypackage"
)

func main() {
    fmt.Println(mypackage.PublicVar)   // OK
    // fmt.Println(mypackage.privateVar)  // ❌ Error: unexported
}
```

### 5.2. Constants

```go
package main

import "fmt"

const Pi = 3.14159  // Package-level constant

func CalculateArea(radius float64) float64 {
    return Pi * radius * radius
}

func main() {
    area := CalculateArea(5)
    fmt.Printf("Area: %.2f\n", area)
}
```

## 6. Shadowing

### 6.1. Shadowing là gì?

**Shadowing** xảy ra khi biến trong **inner scope** có cùng tên với biến trong **outer scope**.

**Inner scope "che" outer scope.**

### 6.2. Ví dụ cơ bản

```go
package main

import "fmt"

var Pi = 3.14  // Global

func main() {
    var Pi = 4  // Local - Shadow global Pi
    
    fmt.Println("The value is", Pi)  // 4, không phải 3.14
}
```

**Output:**

```
The value is 4
```

### 6.3. Ví dụ phức tạp hơn

```go
package main

import "fmt"

var x = 10  // Package-level

func main() {
    fmt.Println("1. x =", x)  // 10
    
    x := 20  // Shadow package-level x
    fmt.Println("2. x =", x)  // 20
    
    {
        x := 30  // Shadow function-level x
        fmt.Println("3. x =", x)  // 30
    }
    
    fmt.Println("4. x =", x)  // 20
}
```

**Output:**

```
1. x = 10
2. x = 20
3. x = 30
4. x = 20
```

**Giải thích:**

```
┌─────────────────────────────┐
│ Package: x = 10            │
│  ┌──────────────────────┐  │
│  │ Function: x = 20     │  │
│  │  ┌───────────────┐   │  │
│  │  │ Block: x = 30 │   │  │
│  │  └───────────────┘   │  │
│  └──────────────────────┘  │
└─────────────────────────────┘
```

### 6.4. Shadowing với if/for

```go
package main

import "fmt"

func main() {
    x := 10
    
    if x > 5 {
        x := 20  // Shadow x
        fmt.Println("Inside if:", x)  // 20
    }
    
    fmt.Println("Outside if:", x)  // 10
    
    for i := 0; i < 2; i++ {
        x := 30  // Shadow x
        fmt.Println("Inside loop:", x)  // 30
    }
    
    fmt.Println("After loop:", x)  // 10
}
```

**Output:**

```
Inside if: 20
Outside if: 10
Inside loop: 30
Inside loop: 30
After loop: 10
```

### 6.5. Shadowing nguy hiểm

**❌ Bug tiềm ẩn:**

```go
package main

import (
    "fmt"
    "os"
)

func main() {
    file, err := os.Open("test.txt")
    if err != nil {
        fmt.Println("Error:", err)
        return
    }
    defer file.Close()
    
    // ❌ NGUY HIỂM - Shadow err
    data := make([]byte, 100)
    n, err := file.Read(data)  // Shadow outer err
    
    if err != nil {
        // Check inner err
    }
    
    fmt.Println("Read", n, "bytes")
    // Outer err vẫn nil, có thể bỏ qua lỗi!
}
```

**✅ Sửa:**

```go
func main() {
    file, err := os.Open("test.txt")
    if err != nil {
        fmt.Println("Error:", err)
        return
    }
    defer file.Close()
    
    // ✅ Dùng =, không := 
    data := make([]byte, 100)
    var n int
    n, err = file.Read(data)  // Không shadow
    
    if err != nil {
        fmt.Println("Read error:", err)
        return
    }
    
    fmt.Println("Read", n, "bytes")
}
```

## 7. Best Practices

### 7.1. Ưu tiên Local Variables

```go
// ✅ Good - Local
func CalculateTotal(prices []float64) float64 {
    total := 0.0  // Local
    for _, price := range prices {
        total += price
    }
    return total
}

// ❌ Bad - Global
var total float64

func CalculateTotal(prices []float64) float64 {
    total = 0.0  // Modify global - Nguy hiểm!
    for _, price := range prices {
        total += price
    }
    return total
}
```

### 7.2. Limit Scope

```go
// ✅ Good - Scope nhỏ nhất cần thiết
func ProcessData() {
    data := fetchData()
    
    if len(data) > 0 {
        result := process(data)  // Chỉ tồn tại trong if
        fmt.Println(result)
    }
}

// ❌ Bad - Scope quá rộng
func ProcessData() {
    data := fetchData()
    var result string  // Tồn tại cả khi không cần
    
    if len(data) > 0 {
        result = process(data)
        fmt.Println(result)
    }
}
```

### 7.3. Tránh Shadowing

```go
// ❌ Bad - Shadowing gây nhầm lẫn
func Process() error {
    err := doSomething()
    if err != nil {
        return err
    }
    
    // Shadow err
    data, err := fetchData()
    if err != nil {
        return err
    }
    
    return nil
}

// ✅ Good - Không shadow
func Process() error {
    err := doSomething()
    if err != nil {
        return err
    }
    
    // Reuse err
    var data []byte
    data, err = fetchData()
    if err != nil {
        return err
    }
    
    return nil
}
```

### 7.4. Global Variables - Khi nào dùng?

**✅ Dùng global khi:**

- Configuration
- Constants
- Singletons (database connection, logger)

**❌ Tránh global cho:**

- Temporary data
- Loop counters
- Function results

**Ví dụ:**

```go
package main

import "fmt"

// ✅ Good - Config
var (
    AppName    = "MyApp"
    AppVersion = "1.0.0"
)

// ✅ Good - Constant
const MaxConnections = 100

// ❌ Bad - Temporary data
// var tempData []byte

func main() {
    fmt.Printf("%s v%s\n", AppName, AppVersion)
}
```

### 7.5. Naming Conventions

```go
// Package-level
var DatabaseURL string      // Exported
var defaultTimeout = 30     // Unexported

// Local
func Process() {
    userID := 123           // camelCase
    isActive := true
    totalCount := 0
}
```

## 📚 Tổng kết

### Blank Identifier `_`

```go
// Bỏ qua return value
_, err := function()

// Bỏ qua index
for _, value := range slice { }

// Bỏ qua value
for index, _ := range slice { }
// Hoặc ngắn gọn
for index := range slice { }

// Import chỉ để init
import _ "package"
```

### Variable Scope

|Scope|Khai báo|Truy cập|Lifetime|
|---|---|---|---|
|**Package**|Ngoài function|Toàn package|Suốt chương trình|
|**Function**|Trong function|Trong function|Khi function chạy|
|**Block**|Trong `{}`|Trong block|Khi block chạy|

### Shadowing

```
Outer scope: x = 10
  Inner scope: x = 20  ← Shadow outer
    Block scope: x = 30  ← Shadow inner
  After block: x = 20
After inner: x = 10
```

### Best Practices

1. ✅ Dùng `_` để bỏ qua giá trị không cần
2. ✅ Ưu tiên local variables
3. ✅ Limit scope nhỏ nhất
4. ✅ Tránh shadowing
5. ✅ Global chỉ cho config/constants
6. ❌ Không bỏ qua error với `_`
7. ❌ Không dùng global cho temporary data
