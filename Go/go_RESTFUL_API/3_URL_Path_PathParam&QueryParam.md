Cấu trúc URL

URL (Uniform Resource Locator) là địa chỉ của một tài nguyên trên web, giống như địa chỉ nhà giúp chúng ta có thể đến những nơi mà mình cần đến
Trong API, URL được dùng để xác định hành động (như CRUD,...) và tài nguyên (nhân viên, sản phẩm)

URL có các thành phần như:
- Protocol
- Domain name
- post
- Path
- Parameters
- Fragment

---
**Các thành phần URL trong Endpoint**

Endpoint là phần chính của URL, xác định tài nguyên hoặc hành động mà API xử lý. Nó thường là đường dẫn sau domain
